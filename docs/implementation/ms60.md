## 1. Outcome and Scope

High-precision corner coordinates (MS58, MS59) cannot produce accurate real-world 3D model dimensions if the underlying metric mapping suffers from two common failure modes:
1. **Paper Standard Confusion:** In the Philippines, Short Bond (215.9 x 279.4 mm), A4 (210.0 x 297.0 mm), and Long Bond (215.9 x 330.2 mm) are all widely used. Under perspective foreshortening, apparent 2D pixel aspect ratios are distorted. If a customer uses Long Bond but the system assumes Short Bond, model dimensions and quotation prices are underestimated by approximately 15.4% across the vertical axis.
2. **Side Correspondence Inversion:** If the physical long side of the paper is paired with the horizontal axis instead of the vertical axis, the metric plane transform rotates by 90 degrees, inverting width and height and warping the 3D model into an unusable aspect ratio.

This milestone bridges click-guided localization directly to physical model dimensioning:
- **Homography-Based Perspective Unwarping:** Computes a normalized frontal-rectification homography that unwarps the detected paper quadrilateral into a front-parallel plane, recovering the true unwarped physical aspect ratio $\lambda = \text{length} / \text{width}$.
- **Intelligent Standard Auto-Suggestion:** Compares $\lambda$ against canonical Philippine paper ratios: Short (1.2941), A4 (1.4143), and Long (1.5294). If $\lambda$ matches one standard within $\pm 3.5\%$, it pre-selects that standard with an explicit match score, while still requiring user confirmation with a single tap.
- **Deterministic Side Correspondence & Orientation Correction:** Automatically aligns the paper's physical short and long dimensions to the wall's local orthogonal coordinate axes, providing an intuitive "Swap Width / Height" toggle for ambiguous orientations.
- **End-to-End Model Sizing and Quotation Parity:** Passes the unrounded millimeter transform into `scaleEstimation.ts`, `PerspectivePlanePicker.tsx`, and `ProductModelWorkspace.tsx`, ensuring that the 3D mesh geometry, floating HUD dimension callouts, structural guardrails, and quotation line items reflect the physical opening within a $\pm 2.0\%$ target error envelope.

## 3. Non-Negotiable Invariants

1. **Unwarped Metric Space Verification:** Aspect ratio matching must occur strictly in the front-rectified metric plane coordinates, never on raw image pixel dimensions.
2. **Explicit User Confirmation Gate:** An auto-suggested paper standard remains a recommendation. The customer must confirm the standard before the metric plane transform is promoted to `eligible_planar_estimate` per MS55.
3. **Exact Canonical Dimensions:** Canonical dimensions must remain immutable:
   - Short Bond: $215.9 \text{ mm} \times 279.4 \text{ mm}$ (ratio: $1.2941$)
   - A4 Standard: $210.0 \text{ mm} \times 297.0 \text{ mm}$ (ratio: $1.4143$)
   - Long Bond: $215.9 \text{ mm} \times 330.2 \text{ mm}$ (ratio: $1.5294$)
4. **Parity Across Visualization, Guardrails, and Pricing:** The unrounded millimeter dimensions derived from the paper reference must feed:
   - Three.js parametric mesh geometry in `ProductModelWorkspace.tsx`
   - Real-time bounding box HUD callouts in `PerspectivePlanePicker.tsx`
   - Engineering guardrails (NSCP 2015 deflection, roller capacity)
   - Quotation line items (`pricing_details.dimension_source = "planar_paper_estimate"`)
5. **Reversible Revision Invalidation:** Modifying the confirmed paper standard or swapping orientation invalidates dependent opening fits atomically, prompting one-tap re-confirmation without resetting finishes or scene layout.

## 4. Technical Design and Algorithmic Specification

### 4.1 Rectified Aspect Ratio Matching Algorithm

In `fastapi-service/paper_calibration.py` and `src/lib/visualization/paperAspectMatcher.ts`:

```text
Algorithm: Frontal Rectification and Standard Auto-Suggestion
Input: 4 ordered corner coordinates in workspace pixels: P0, P1, P2, P3

1. Compute Frontal Rectifying Homography:
   Map corners P0, P1, P2, P3 to normalized square vertices:
   Q0 = (0, 0), Q1 = (1, 0), Q2 = (1, 1), Q3 = (0, 1)
   H_norm = cv2.getPerspectiveTransform(P, Q)
   H_rect = inverse(H_norm)

2. Calculate Metric Edge Lengths in Rectified Space:
   Let side_a = distance(P0, P1) transformed through H_rect
   Let side_b = distance(P1, P2) transformed through H_rect
   Let side_c = distance(P2, P3) transformed through H_rect
   Let side_d = distance(P3, P0) transformed through H_rect
   
   metric_width_est = (side_a + side_c) / 2.0
   metric_height_est = (side_b + side_d) / 2.0
   
   unwarped_ratio = max(metric_width_est, metric_height_est) / min(metric_width_est, metric_height_est)

3. Match Against Philippine Standards:
   Target Ratios:
     R_short = 279.4 / 215.9 = 1.2941
     R_a4    = 297.0 / 210.0 = 1.4143
     R_long  = 330.2 / 215.9 = 1.5294

   Compute relative deviations:
     dev_short = abs(unwarped_ratio - R_short) / R_short
     dev_a4    = abs(unwarped_ratio - R_a4) / R_a4
     dev_long  = abs(unwarped_ratio - R_long) / R_long

   Find best match: min_dev = min(dev_short, dev_a4, dev_long)
   If min_dev <= 0.035 (3.5% tolerance):
     suggested_standard = corresponding standard
     confidence_match = 1.0 - min_dev
   Else:
     suggested_standard = null (ambiguous perspective distortion; require manual choice)
```

### 4.2 Deterministic Side Correspondence

To guarantee that opening width and opening height are not transposed:
1. Identify the principal physical orientation of the paper quadrilateral:
   - Calculate the angle of the longer rectified edge relative to the image vertical axis ($y$-down).
   - If $|\theta| \le 45^\circ$, the paper is in Portrait orientation on the wall.
   - If $|\theta| > 45^\circ$, the paper is in Landscape orientation on the wall.
2. In Portrait:
   - Short physical dimension ($215.9$ or $210.0$ mm) pairs with local horizontal vector.
   - Long physical dimension ($279.4$, $297.0$, or $330.2$ mm) pairs with local vertical vector.
3. In Landscape:
   - Long physical dimension pairs with local horizontal vector.
   - Short physical dimension pairs with local vertical vector.
4. User Override:
   - The confirmation modal provides an explicit toggle: `[⇄ Swap Width & Height]`. Tapping this toggle flips correspondence by 90 degrees and recalculates all preview readouts instantly.

### 4.3 Opening Sizing and Parametric Synchronization

When opening corners $C_0, C_1, C_2, C_3$ are fitted in `PerspectivePlanePicker.tsx`:
1. Each corner is transformed to metric plane millimeters via $H_{workspace\_mm}$:
   $M_k = H_{workspace\_mm} \cdot C_k$
2. Metric horizontal width: $W_{mm} = \frac{\text{dist}(M_0, M_1) + \text{dist}(M_3, M_2)}{2}$
3. Metric vertical height: $H_{mm} = \frac{\text{dist}(M_0, M_3) + \text{dist}(M_1, M_2)}{2}$
4. The unrounded values $(W_{mm}, H_{mm})$ update:
   - Active 3D model bounding box dimensions in `ProductModelWorkspace.tsx`.
   - Parametric extrusion rules for aluminum extrusions and glass infill.
   - Guardrail validation (such as Series 798 40kg sash limit and 2400mm width multi-panel trigger).
   - Saved quotation item metadata (`pricing_details.dimension_source = "planar_paper_estimate"`).

## 7. Risks and Mitigations

- **Risk: Severe perspective foreshortening makes Short Bond and A4 ratios overlap within noise margins.**  
  *Mitigation:* When the difference between Short (1.294) and A4 (1.414) falls within the uncertainty interval, the system marks the suggestion as ambiguous (`confidence < 0.85`) and highlights all three buttons equally, prompting explicit user selection.
- **Risk: Camera lens radial distortion (barrel/pincushion) bends straight paper edges into curves.**  
  *Mitigation:* OpenCV polynomial lens undistortion can be applied when camera EXIF calibration is available; for standard mobile cameras, edge line intersection (MS59) fits lines to the central edge sections where radial distortion curvature is minimized.
