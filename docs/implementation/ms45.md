## 1. Outcome and Scope

In the current GlassFit space upload intake (`src/features/visualization/components/ProductAwareUploadPage.tsx` and `UploadImage.tsx`), customers upload a space photo without calibration context. The backend relies solely on YOLOv8 object detections (such as people and furniture) and Depth Anything V2 relative depth maps to guess real-world scale (IMP-MS10). Because reference furniture varies widely in physical size and relative depth maps lack absolute metric scale, initial dimension estimates exhibit an error rate of 15% to 35% compared to actual measuring tape values.

`IMP-MS45` introduces a structured, dual-mode intake interface:

1. **Mode A: Quick Preview (Standard Upload):**
   - Retains the existing zero-friction upload path.
   - Transparently informs the customer that dimensions are ballpark estimates (approximately 75% to 85% accuracy) intended for aesthetic visualization.
   - Requires no physical markers or pre-upload preparation.

2. **Mode B: Precision Calibration (Wall Fiducial Paper):**
   - Offers customers seeking quote-ready accuracy an option to calibrate the scene with a standard sheet of paper taped to the installation wall.
   - Solicits the exact Philippine paper standard used:
     - **Short Bond Paper (US Letter):** 215.9 mm x 279.4 mm (8.5 in x 11.0 in)
     - **A4 Paper (ISO 216):** 210.0 mm x 297.0 mm (8.27 in x 11.69 in)
     - **Long Bond Paper (Philippine Folio):** 215.9 mm x 330.2 mm (8.5 in x 13.0 in)
   - Displays dedicated visual instructions detailing proper wall placement (taped flat, visible, upright, coplanar with the window/door opening).
   - Encodes calibration parameters into the multipart upload payload dispatched to the FastAPI computer vision microservice.

This document covers client-side intake UI, paper standard validation, guidance cards, and API dispatch contracts. Server-side CV detection is specified in `IMP-MS46`, and workspace dimension grounding is specified in `IMP-MS47`.

### 1.1 Non-Negotiable Invariants

1. **Non-Blocking User Experience:** Mode A (Quick Preview) must remain fully accessible with zero extra clicks required for casual users. Precision calibration is strictly opt-in.
2. **Explicit Paper Standard Definition:** The system must never guess between Short, A4, and Long paper. The user must select the paper standard explicitly to avoid a 10% to 15% dimensional scaling error.
3. **Zero WebXR or Continuous Camera Tracking:** All ingestion occurs through standard photo capture and file upload, adhering strictly to system constraint `BAN-AR-08`.
4. **Style Consistency:** Mode switches, segmented radio controls, and guideline cards must reuse existing design tokens from `src/app/globals.css` and established component conventions in `src/features/visualization/components/` (per `BAN-UI-09`).
5. **No Em-Dashes:** In compliance with `BAN-PUNCT-01`, all documentation, user-facing copy, and code comments must use hyphens, colons, or parentheses.

```typescript
export type CalibrationMode = "standard" | "paper_fiducial";

export type FiducialPaperStandard = "short" | "a4" | "long";

export interface PaperStandardDimensionsMm {
  widthMm: number;
  heightMm: number;
  label: string;
}

export const PAPER_STANDARD_METRICS: Record<FiducialPaperStandard, PaperStandardDimensionsMm> = {
  short: {
    widthMm: 215.9,
    heightMm: 279.4,
    label: 'Short Bond / Letter (8.5" x 11")',
  },
  a4: {
    widthMm: 210.0,
    heightMm: 297.0,
    label: 'A4 Standard (8.27" x 11.69")',
  },
  long: {
    widthMm: 215.9,
    heightMm: 330.2,
    label: 'Long Bond / Folio (8.5" x 13")',

export interface CalibrationIntakeOptions {
  mode: CalibrationMode;
  paperStandard?: FiducialPaperStandard;
}
```

### 4.2 Multipart FormData Payload

In `src/lib/imageApi.ts`, modify `analyzeImage()`:

```typescript
export async function analyzeImage(
  file: File,
  calibrationOptions?: CalibrationIntakeOptions,
): Promise<SpaceImageSession> {
  const formData = new FormData();
  formData.append("image", file);

  const mode = calibrationOptions?.mode ?? "standard";
  formData.append("calibration_mode", mode);

  if (mode === "paper_fiducial" && calibrationOptions?.paperStandard) {
    formData.append("paper_standard", calibrationOptions.paperStandard);
  }

  // Dispatch POST /analyze-image
  // ...
}
```

### 4.3 SpaceImageSession Metadata Extension

Extend `SpaceImageSession` in `src/lib/imageApi.ts`:

## 5. Step-by-Step Implementation Plan

1. **Step 1: Domain Types & Constants**
   - Define `CalibrationMode`, `FiducialPaperStandard`, and `PAPER_STANDARD_METRICS` in `src/lib/visualization/types.ts`.
   - Add unit tests verifying metric dimensions match international standards.

2. **Step 2: API Client Payload Serialization**
   - Update `analyzeImage` in `src/lib/imageApi.ts` to accept optional `CalibrationIntakeOptions`.
   - Append `calibration_mode` and `paper_standard` fields to `FormData`.

3. **Step 3: Mode & Paper Selection Component**
   - Create `src/features/visualization/components/CalibrationModeSelector.tsx` adhering to GlassFit design tokens (`rounded-[16px]`, cyan highlights, accessible buttons).
   - Integrate radio group state with keyboard navigation (Arrow keys, Space, Enter).

4. **Step 4: Guideline Component Dynamic Swapping**
   - Enhance `src/features/visualization/components/GuideLine.tsx` to accept an active `mode` prop.
   - Render fiducial wall placement cards when `mode === "paper_fiducial"`.

5. **Step 5: Upload Page Integration**
   - Wire `CalibrationModeSelector` into `src/features/visualization/components/ProductAwareUploadPage.tsx`.
   - Bind selected calibration options to the `analyzeImage()` invocation.
   - Maintain full backwards compatibility: defaulting to `"standard"` if unselected.

## 8. Risks and Mitigations

| Risk | Severity | Mitigation |
|---|---|---|
| User selects Short Bond but tapes Long Bond | Medium | Display millimeter and inch dimensions directly beneath each button label so users can double-check with their paper packaging. |
| User is overwhelmed by choices on the upload page | Low | Quick Preview is selected by default with clear badges, ensuring casual users can proceed in one click without choosing anything. |
| User tapes paper on a side wall instead of the target wall | Medium | Card 3 of the guideline explicitly warns against side walls with a red "Avoid" icon and visual comparison. |
