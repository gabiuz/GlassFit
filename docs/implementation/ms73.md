## 1. Outcome and Scope

When customers configure architectural windows with security grilles in the 3D visualization workspace (`ProductModelWorkspace.tsx`), they adjust opening dimensions (Width and Height) to fit their real-world client space. As dimensions expand or contract, the security grille dynamically extends its structural bars to maintain architectural strength and security spacing.

Previously, quotation and estimation workflows suffered from two critical shortcomings:
1. When opening dimensions changed, the quotation summary either treated the grille as a flat area rate or applied a rough vertical-only heuristic, ignoring horizontal divider rails and intermediate ties. If a customer widened an opening by 600mm, the price delta did not reflect the additional physical linear meters of aluminum profiles required.
2. In the consultation handoff and PDF generated for Philippine SME fabricators, the quotation displayed only a generic line item: `"Security Grille: ₱3,240.00"`. Fabricators were left with zero information regarding the exact number of vertical bars, horizontal bars, individual cut lengths, or total linear meters of profile extrusion needed for material procurement.

`IMP-MS73` closes the loop across the customer visualization workspace, quotation modal, and consultation PDF:
- **Dynamic 3D Workspace Linear Sizing & Recalculation:** As customers adjust width and height sliders, `ProductModelWorkspace.tsx` calls `calculateGrilleLinearBOM()` in real time (< 50ms). The 3D Three.js canvas dynamically repeats the bar patterns, and the parameter dock displays the updated linear metrics (e.g. `"7 Vertical Pickets @ 1160mm, 6 Horizontal Rails @ 350mm - 12.4m Total Extrusion"`).
- **Finish-Sensitive Linear Pricing:** When the customer toggles aluminum finishes (Analok Bronze, Powder Coated White, Mill Finish Aluminum, or Matte Black), the system updates PBR shaders on the canvas and simultaneously looks up finish-specific extrusion rates per linear meter, updating the quotation subtotal in < 16ms.
- **Detailed Itemized Quotation Breakdown (`MeasurementConfirmationModal.tsx`):** In the quotation measurement confirmation modal, the customer and estimator see a transparent itemization:
  - Perimeter mounting rails: Top and bottom rails, left and right jambs.
  - Vertical structural bars: Piece count, individual cut length in millimeters, and total linear meters.
  - Horizontal cross rails / tie bars: Piece count, individual cut length in millimeters, and total linear meters.
  - Direct material cost, scrap allowance, fabrication labor floor, and contractor gross margin.
- **Fabricator Consultation PDF Parity (`quotationPdfGenerator.ts`):** In the downloadable PDF handoff, the fixture specification table includes an explicit cutting list callout:
  `"Security Grille: 7 vertical bars (1160mm), 12 horizontal bars (350mm), total 17.12 linear meters in Powder Coated White"`. This equips fabricators with precise extrusion cutting quantities while keeping customer presentation clean and professional.
- **Zero Hallucinated Dependencies & 60 FPS Performance:** Recalculations run on lightweight pure mathematical functions without blocking UI thread rendering or camera controls.

## 3. Non-Negotiable Invariants

1. **Exact 3D Visual and Calculation Parity:** The piece count and cut lengths displayed in the quotation modal and printed in the consultation PDF must match the 3D visual assembly rendered on the Three.js canvas to the exact integer piece and within 0.5mm length.
2. **Sub-50ms Quotation Recalculation:** As the customer continuously drags dimension sliders in the workspace, the dynamic grille linear calculation must complete in under 50 milliseconds, ensuring zero UI lag or dropped animation frames.
3. **Finish-Rate Synchronization:** Selecting an aluminum finish for the grille must simultaneously update both the 3D PBR shader on canvas and the linear meter unit rate in the pricing engine.
4. **Single Final Price Authority:** While the quotation modal and PDF provide itemized cut list quantities for fabrication clarity, the final quotation total must remain a single, binding monetary sum per `BRD-M5`.
5. **Zero Em-Dashes:** In strict compliance with `BAN-PUNCT-01`, all labels, modal text, PDF notes, and code comments must use hyphens, colons, or parentheses. Never use em-dashes.
6. **Strict Type Safety:** Zero usage of `any` across TypeScript interfaces, calculation hooks, and PDF formatters per `BAN-TYPE-05`.
7. **Design Token Parity:** All UI additions to `ProductModelWorkspace.tsx` and `MeasurementConfirmationModal.tsx` must reuse established Tailwind CSS tokens from `src/app/globals.css` (`rounded-[16px]`, `rounded-[20px]`, `border-[#c3c3c3]`, `bg-[#0f1422]`, `text-[#07b6d3]`) per `BAN-UI-09`.

## 4. Technical Design & User Experience Architecture

### 4.1 Dynamic Workspace Sizing Integration (`ProductModelWorkspace.tsx`)

In `src/features/visualization/components/ProductModelWorkspace.tsx`, connect opening dimension state (`workspaceDimensions.widthMm`, `workspaceDimensions.heightMm`) and finish selection (`addonFinish`) to `calculateGrilleLinearBOM()`:

```typescript
// Derive real-time linear grille BOM when security grille add-on is active
const activeGrilleBOM = useMemo(() => {
  if (selectedAddon !== "grill") return null;

  // Resolve finish-specific raw material rate from catalog or defaults
  const finishKey = addonFinish || baseFinish || "analok";
  const matchedMaterial = grilleRawMaterials.find(
    (m) => m.finish_type.toLowerCase() === finishKey.toLowerCase()
  ) || defaultGrilleMaterial;

  return calculateGrilleLinearBOM({
    widthMm: workspaceDimensions.widthMm,
    heightMm: workspaceDimensions.heightMm,
    patternType: hostProductGrillePattern || "staggered_brick",
    grilleRawMaterial: {
      id: matchedMaterial.id,
      material_code: matchedMaterial.material_code,
      description: matchedMaterial.description,
      unit_price: matchedMaterial.unit_price,
      waste_allowance: matchedMaterial.waste_allowance,
    },
    includePerimeterFrame: true,
  });
}, [
  selectedAddon,
  addonFinish,
  baseFinish,
  workspaceDimensions.widthMm,
  workspaceDimensions.heightMm,
  grilleRawMaterials,
  hostProductGrillePattern,
  defaultGrilleMaterial,
]);
```

if (item.addonType === "grill" && item.grilleBOM) {

  specs.push(specText);
