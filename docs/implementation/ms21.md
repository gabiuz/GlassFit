## 1. Executive Summary & Problem Context

GlassFit estimates customized architectural glass and aluminum fixtures (sliding windows, awning windows, doors, and partitions) for Philippine homeowners and small-to-medium enterprise (SME) fabricators. In initial milestones (such as MS-1 and MS-5), estimation was modeled as a theoretical Bill-of-Materials (BOM) deriving direct material costs from wholesale supplier prices and applying separate waste allowances, labor floors, and contractor margins.

### 1.1 The Business Need and Client Pricing Reality
R.R.D. Aluminum and Glass Works (the capstone project's operational enterprise partner) operates on an established, standardized client pricing structure codified in `docs/plans/pricing_model.md`. Key characteristics of this model include:

1. **Direct R.R.D. Base Pricing (No Supplier Markup Computation):**  
   R.R.D. does not require customer-facing software to calculate wholesale-to-retail markups at runtime. Instead, R.R.D. establishes a standardized base price for each stock unit (e.g. ₱720 for a standard 6-meter 1" x 1" aluminum extrusion; ₱864 for a 4 ft x 6 ft clear float glass sheet). The system must directly accept and store this R.R.D. base price and derive linear meter or square-area rates directly from it.

2. **Aluminum Special Color Rule (x2 Multiplier):**  
   Standard aluminum finishes are **White** and **Analok**. Any special or powder-coated color (e.g. AL 1001 through AL 1020, Champagne, Peacock Blue, Matte Black) requires custom powder coating treatment and carries a standardized **x2 multiplier** on the standard product base price.

3. **Glass Premium Classification & Single-Application Multiplier (x2 Multiplier):**  
   Glass materials are categorized into Standard and Premium tiers:
   - **Glass Types:** Regular, Frosted, and Mirror are Standard. **Tempered** and **Reflective** are Premium.
   - **Glass Colors:** Clear and Bronze are Standard. **Silver** and **Blue** are Premium.
   - **The Single-Application Invariant:** If the customer selects a premium glass type OR a premium glass color, a **x2 premium multiplier** is triggered. Crucially, this multiplier is applied **exactly once**, even if both the glass type and glass color are premium (e.g. Tempered Silver glass triggers a single x2 multiplier, never x4).

4. **Glass Thickness Surcharge Matrix:**  
   Standard default glass thickness is **6mm** (+₱0 surcharge). 3mm glass is banned as structurally unsuitable for architectural window and door openings. Thicker glass options incur discrete surcharges:
   - **8mm:** +₱400 for Standard Glass; +₱600 for Premium Glass.
   - **12mm:** +₱1,000 for Standard Glass; +₱1,200 for Premium Glass.

5. **Non-Technical Administrative Usability Challenge:**  
   The workshop administrators at R.R.D. are not software engineers. The existing administrative materials interface (`src/features/admin/materials/MaterialModal.tsx`) requires entering technical parameters: alphanumeric material codes with regex constraints, unit prices per linear meter, and decimal waste allowances (e.g. `0.12`). This introduces cognitive friction and data entry errors. The administrative experience must be redesigned so that non-technical users can enter standard stock lengths (6 meters) or sheet sizes (4 ft x 6 ft) with automatic rate derivation, or upload bulk material inventories via a clean, human-friendly spreadsheet template without touching code or formulas.

## 3. Mathematical Pricing Architecture & Domain Invariants

All monetary values are calculated internally in integer centavos (1 PHP = 100 centavos) to prevent floating-point rounding drift, and converted to decimal PHP with standard two-decimal precision at display and persistence boundaries.

### 3.1 Aluminum Profile Pricing (R.R.D. Base Rates)
In accordance with user directives, GlassFit uses the **R.R.D. Price** directly:

1. **Standard Stock Length:**  
   Every standard regular aluminum extrusion profile in the Philippines has a stock length of:
   ```
   L_stock = 6.0 meters
   ```

2. **R.R.D. Price per Meter Calculation:**  
   Given the administrative R.R.D. base price for a full 6-meter stock profile (`P_stock_rrd`):
   ```
   R_meter = P_stock_rrd / 6.0
   ```

3. **Required Aluminum Extrusion Cost:**  
   For a component requiring a total linear length `L_req` (in meters):
   ```
   C_aluminum_base = L_req * R_meter
   ```

4. **Reference Base Rates (docs/plans/pricing_model.md Section 2.3):**

| Aluminum Profile Size | Stock Length | R.R.D. Stock Price (PHP) | Derived R.R.D. Rate per Meter |
|---|---|---|---|
| 1" x 1" | 6 meters | ₱720.00 | ₱120.00 / m |
| 1" x 2" | 6 meters | ₱1,040.00 | ₱173.33 / m |
| 1" x 3" | 6 meters | ₱1,600.00 | ₱266.67 / m |
| 1-3/4" x 3" | 6 meters | ₱1,800.00 | ₱300.00 / m |
| 1-3/4" x 4" | 6 meters | ₱2,400.00 | ₱400.00 / m |

### 3.2 Aluminum Color Multiplier Logic
Aluminum finishes are classified into two deterministic categories:

1. **Standard Colors:**
   - **White**
   - **Analok**
   - Pricing Rule: `M_aluminum_color = 1.0` (Standard base price).

2. **Special / Powder-Coated Colors:**
   - Any color other than White or Analok, including:
     - Metallic Silver (AL 1001), Bright Silver (AL 1002), Champagne Silver (AL 1003)
     - Champagne Gold (AL 1004), Bright Gold (AL 1005), Jade Silver (AL 1006)
     - Blue Silver (AL 1007), Copper (AL 1008), Black (AL 1009), Sparkling Black (AL 1010)
     - Pure White (AL 1011), Ivory White (AL 1012), Finland Green (AL 1013)
     - Leaf Green (AL 1014), Forest Green (AL 1015), Light Blue (AL 1016)
     - Postal Blue (AL 1017), Glossy Blue (AL 1018), Dark Blue (AL 1019)
     - Coffee (AL 1020), Champagne, Peacock Blue
   - Pricing Rule: `M_aluminum_color = 2.0` (Special Color Price = Standard Product Price x 2).

### 3.3 Glass Material Costing
Glass is procured and stocked by R.R.D. as whole sheets:

1. **Standard Whole Sheet Area:**  
   Given stock sheet dimensions in feet (`W_ft` and `H_ft`):
   ```
   Area_sheet_sqft = W_ft * H_ft
   ```
   Standard commercial sheet benchmark: `4 ft x 6 ft = 24.0 sq.ft.`

2. **R.R.D. Price per Square Foot:**  
   Given the administrative R.R.D. price for a whole glass sheet (`P_sheet_rrd`):
   ```
   R_sqft = P_sheet_rrd / Area_sheet_sqft
   ```
   Benchmark example: `₱864.00 / 24 sq.ft. = ₱36.00 / sq.ft.`

3. **Metric Area Conversion for 3D Engine:**  
   Because the GlassFit Three.js canvas and measurement inputs operate in millimeters and meters:
   ```
   1 square meter = 10.7639104 square feet
   R_sqm = R_sqft * 10.7639104
   ```

4. **Required Glass Material Cost:**  
   For an aperture requiring glass surface area `Area_sqm`:
   ```
   C_glass_base = Area_sqm * R_sqm
   ```

### 3.4 Glass Premium Classification and the Single-Application Multiplier Invariant
Glass materials are classified across two independent dimensions (Type and Color):

1. **Classification Schema:**

| Specification Dimension | Standard Tier (Multiplier: 1.0x) | Premium Tier (Triggers 2.0x Multiplier) |
|---|---|---|
| Glass Type | Regular, Frosted, Mirror | Tempered, Reflective |
| Glass Color | Clear, Bronze | Silver, Blue |

2. **The Single-Application Invariant (CRITICAL):**  
   If either the selected glass type OR the selected glass color belongs to the Premium tier, the glass premium flag evaluates to `true`.  
   The price multiplier `M_glass_premium` is set to `2.0`.  
   Under no circumstances may the multiplier be compounded or squared (e.g. `2.0 * 2.0 = 4.0` is strictly prohibited).

   ```typescript
   const isPremiumType = glassType === "Tempered" || glassType === "Reflective";
   const isPremiumColor = glassColor === "Silver" || glassColor === "Blue";
   const isGlassPremium = isPremiumType || isPremiumColor;

   // Invariant: Multiplier is exactly 2.0 if either is premium, otherwise 1.0
   const glassMultiplier = isGlassPremium ? 2.0 : 1.0;
   ```

### 3.5 Glass Thickness Rules and Surcharge Matrix
GlassFit strictly regulates selectable glass thicknesses for architectural openings:
- **3mm Glass:** Excluded and prohibited from product selection (per R.R.D. workshop standard; 3mm is restricted to picture frames and non-structural glazing).
- **Available Thicknesses:** 6mm, 8mm, and 12mm.

Thickness surcharges are applied as an additive flat fee based on whether the glass is Standard or Premium:

| Nominal Thickness | Standard Glass (Type and Color Standard) | Premium Glass (Type or Color Premium) |
|---|---|---|
| **6mm** (Default Base) | +₱0.00 | +₱0.00 |
| **8mm** | +₱400.00 | +₱600.00 |
| **12mm** | +₱1,000.00 | +₱1,200.00 |

```typescript
export function getThicknessSurcharge(thicknessMm: 6 | 8 | 12, isGlassPremium: boolean): number {
  if (thicknessMm === 6) return 0;
  if (thicknessMm === 8) return isGlassPremium ? 600 : 400;
  if (thicknessMm === 12) return isGlassPremium ? 1200 : 1000;
  throw new Error(`Unsupported glass thickness: ${thicknessMm}mm. Allowed: 6mm, 8mm, 12mm.`);
}
```

### 3.6 Overall End-to-End Quotation Calculation Sequence
To ensure consistent results across both catalog base-price products and custom parametric BOM models, the pricing sequence executes in four deterministic steps:

1. **Step 1: Determine Standard Product Base Price (`P_standard`):**  
   Derived from the catalog base price or base parametric BOM calculation (framing at standard rates, standard glass, hardware, and accessories).

2. **Step 2: Evaluate Aluminum Color Multiplier (`M_color`):**  
   - If the selected color is a Special Powder-Coated finish (AL 1001 through AL 1020, Champagne, Peacock Blue, etc.), set `M_color = 2.0`.
   - If the selected color is White or Analok, set `M_color = 1.0`.
   - `P_after_color = P_standard * M_color`.

3. **Step 3: Evaluate Glass Premium Multiplier (`M_glass`):**  
   - If `glassType` is in `[Tempered, Reflective]` OR `glassColor` is in `[Silver, Blue]`, set `isGlassPremium = true` and `M_glass = 2.0`.
   - If both `glassType` and `glassColor` are Standard, set `isGlassPremium = false` and `M_glass = 1.0`.
   - **Single-Application Rule:** When applied at the product base level, the multiplier applies once per client pricing rules.
   - `P_after_glass = P_after_color * (isGlassPremium && M_color === 1.0 ? 2.0 : 1.0)`.

4. **Step 4: Apply Glass Thickness Surcharge (`S_thickness`):**  
   - Lookup the surcharge in the thickness matrix based on `(thicknessMm, isGlassPremium)`.
   - `P_final = P_after_glass + S_thickness`.

#### Benchmark Calculation Verification Scenarios (from docs/plans/pricing_model.md)

1. **Scenario A (Standard Product + Special Color):**  
   - Standard Sliding Window Base Price: ₱4,000.00  
   - Aluminum Color: AL 1009 Black (Special Powder-Coated)  
   - Glass: Regular Clear 6mm (Standard)  
   - Calculation: `₱4,000.00 * 2.0 = ₱8,000.00` + `₱0 (6mm)` = **₱8,000.00**

2. **Scenario B (Standard Product + Premium Glass + 8mm Thickness):**  
   - Standard Sliding Window Base Price: ₱5,000.00  
   - Aluminum Color: Analok (Standard)  
   - Glass Type: Tempered (Premium)  
   - Glass Color: Silver (Premium)  
   - Thickness: 8mm  
   - Step 1: Color is Standard -> `₱5,000.00`  
   - Step 2: Glass is Premium (Tempered + Silver triggers single 2.0x multiplier) -> `₱5,000.00 * 2.0 = ₱10,000.00`  
   - Step 3: Thickness surcharge for 8mm Premium Glass -> `+₱600.00`  
   - Final Price: `₱10,000.00 + ₱600.00 = ` **₱10,600.00**

3. **Scenario C (Standard Product + Standard Glass + 12mm Thickness):**  
   - Standard Product Base Price: ₱5,000.00  
   - Aluminum Color: White (Standard)  
   - Glass Type: Regular (Standard)  
   - Glass Color: Clear (Standard)  
   - Thickness: 12mm  
   - Multipliers: None (`1.0x`)  
   - Thickness Surcharge: `+₱1,000.00` (12mm Standard)  
   - Final Price: `₱5,000.00 + ₱1,000.00 = ` **₱6,000.00**

## 5. Non-Technical Admin Raw Material Management & Upload UX Specification

### 5.1 Persona and Usability Constraints
- **Primary Persona:** R.R.D. workshop manager or administrative assistant.
- **Technical Literacy:** Low to moderate. Comfortable with spreadsheets (Excel/Google Sheets) and basic web forms, but intimidated by formulas, code syntax, regex validation errors, or database keys.
- **Usability Mandates:**
  1. **No Code Typing:** Never require the user to formulate codes like `mat_al_798_head_pcw`. The system automatically generates codes based on the chosen category, size, and color.
  2. **No Manual Unit Division:** Users enter standard purchasing units (e.g. ₱720 per 6m bar or ₱864 per sheet). The system automatically divides by 6 or computes square footage.
  3. **Instant Visual Feedback:** Live helper pills immediately show the derived rate: `"₱720 ÷ 6m = ₱120.00 / meter"`.
  4. **Plain Language Terminology:** Replace terms like `waste_allowance` and `span_ratio` with plain terms like `Standard Stock Price (6 meters)` and `Usable Rate`.
  5. **Pre-flight Error Prevention:** Highlight missing numbers or invalid values with friendly yellow/red badges before committing data.

## 6. User Experience & Interaction Contracts

### 6.1 Administrator Ingestion User Flow

The administrative material workflow provides two clear pathways from the `/admin/materials` dashboard:

1. **Option A: Single Material Entry via "Add Material":**
   - Step 1: Admin clicks the "Add Material" button in the top action bar.
   - Step 2: Selects the material category (Aluminum Framing, Glass Infill, Hardware, or Consumables).
   - Step 3: For Aluminum, enters the profile size (e.g. 1" x 2") and selects finish (Analok).
   - Step 4: Enters the selling price for a 6-meter stock bar (e.g. ₱1,040.00).
   - Step 5: System calculates and renders the real-time helper chip: `₱173.33 / meter`.
   - Step 6: Admin clicks "Save Material"; row is persisted to `public.raw_materials` and immediately appears in the catalog table.

2. **Option B: Bulk Ingestion via "Import Spreadsheet":**
   - Step 1: Admin clicks the "Import Spreadsheet" button.
   - Step 2: Downloads the pre-formatted easy CSV template (`glassfit_materials_template.csv`).
   - Step 3: Fills in material inventory using Excel or Google Sheets.
   - Step 4: Drops the completed file into the upload dropzone.
   - Step 5: Client-side pre-flight parser processes the rows, computes unit rates, and populates the review table.
   - Step 6: Admin reviews parsed items and green validation checkmarks.
   - Step 7: Clicks "Import Items"; batch server action persists all valid rows atomically.

### 6.2 Customer Product Configuration Flow (Real-Time Pricing)

When a customer or sales representative customizes a product in the Visualization Canvas or Measurement Confirmation Modal (`DSD-UI7`), price updates calculate reactively:

1. **Dimension Entry & Base Calculation:**  
   Customer inputs dimensions (e.g. 1400mm width x 1200mm height) for a Series 798 Sliding Window.  
   - Standard Base Price: Computed as `₱5,000.00`.

2. **Aluminum Finish Selection:**  
   Customer selects AL 1009 Black (Special Powder-Coated finish).  
   - Special Color Multiplier triggered: `2.0x`.  
   - Subtotal becomes `₱10,000.00`.  
   - A friendly UI badge appears: `Special Powder-Coated Finish (x2)`.

3. **Glass Specification Selection:**  
   Customer selects Tempered Silver glass (Tempered is Premium Type; Silver is Premium Color).  
   - System evaluates `isGlassPremium = true`.  
   - Single-Application Rule enforced: Because both type and color are premium, the multiplier is applied once, not compounded.

4. **Glass Thickness Selection:**  
   Customer selects 8mm glass thickness.  
   - System queries thickness matrix: 8mm Premium Glass surcharge = `+₱600.00`.  
   - Final Price computed dynamically: `₱10,000.00 + ₱600.00 = ₱10,600.00`.  
   - Measurement modal updates the quotation estimate in real time with zero latency.

## 8. Migration, Backward Compatibility, and Rollback Strategy

### 8.1 Database Migration Safety (`008_rrd_pricing_model.sql`)
1. **Reversible Schema Operations:** Columns added to `public.raw_materials` are nullable or have sensible default values (`stock_length_meters = 6.000`, `sheet_width_ft = 4.00`, `sheet_height_ft = 6.00`).
2. **Non-Destructive Execution:** Existing product components and quotations referencing `raw_materials` continue to resolve without table locking or data loss.
3. **Rollback Plan:**
   ```sql
   -- Rollback migration: 008_rrd_pricing_model_down.sql
   ALTER TABLE "public"."raw_materials"
     DROP COLUMN IF EXISTS "stock_length_meters",
     DROP COLUMN IF EXISTS "stock_price_rrd",
     DROP COLUMN IF EXISTS "sheet_width_ft",
     DROP COLUMN IF EXISTS "sheet_height_ft",
     DROP COLUMN IF EXISTS "is_premium_trigger",
     DROP COLUMN IF EXISTS "pricing_tier",
     DROP COLUMN IF EXISTS "supported_thicknesses";
   ```

### 8.2 Preserving Quotation Immutability
In accordance with `IMP-MS17` and `IMP-MS20`, previously saved consultation quotations and signed booking links (`public.quotation_estimates`) contain immutable JSONB snapshots (`QuotationDocumentSnapshotV1`). Modifying raw material rates or multiplier logic affects only future and active configurator sessions. Historical quotations remain permanently frozen.
