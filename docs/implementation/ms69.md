## 1. Outcome and Scope

In the GlassFit client-space visualization workspace (`src/features/visualization/components/ProductModelWorkspace.tsx`), customers interactively position, scale, and evaluate 3D glass and aluminum architectural fixtures against real smartphone photos of their home or office. Customers can currently adjust opening dimensions, change framing finishes and glass tints (via `IMP-MS66`), and toggle optional bottom sills (`includeSill`).

However, many residential and commercial window installations in the Philippines require functional secondary attachments:
1. **Insect Screens:** To permit ventilation while preventing insect intrusion.
2. **Security Grills:** To provide physical intrusion protection and child safety.

While an administrator may configure both Screen and Grill attachments as compatible options for a window template (per `IMP-MS67`), physical window frame channels and exterior mounting clearances typically prevent installing both a full-surface insect screen and an exterior security grill simultaneously on the same opening plane. Customers must therefore be able to choose one attachment or the other, or omit both, while observing the exact visual appearance and separate financial impact of their decision.

`IMP-MS69` delivers this customer-facing add-on experience:
- **Ergonomic Workspace Add-on Controller:** When the active product has compatible add-on attachments configured by the administrator, renders an accessible toggle selector in the parameter dock alongside the existing Sill toggle. If the product has no compatible add-ons configured, the control gracefully hides.
- **Strict Mutual Exclusion Invariant:** Enforces that a customer can select either the Screen, the Grill, or neither (`None`), but can never enable both simultaneously. Activating the Screen immediately deactivates the Grill, and vice versa.
- **Real-Time 3D Shading on Space Photo Canvas:** Mounts or unmounts the procedural 3D add-on front layer (from `IMP-MS68`) on the user's space photo canvas in under 16ms without resetting camera orbit, corner homography fits, or YOLOv8 foreground occlusion masks.
- **Dedicated Parametric Add-on Pricing Engine:** Calculates the separate cost of the chosen add-on based on its specific bill-of-materials (linear frame extrusion, mesh surface area or repeating bar count, corner hardware, fabrication labor floor, and contractor margin).
- **Instantaneous HUD & Dock Synchronization:** Synchronizes the floating price HUD badge and bottom dock total in under 50ms whenever the customer changes add-on options.
- **Quotation Modal & Relational Persistence Parity:** Itemizes the selected add-on as a distinct line item in the Quotation Measurement Modal (`MeasurementConfirmationModal.tsx`), freezes the add-on specification and rate into Supabase (`product_configurations` and `quotation_items.pricing_details`), and prints the add-on details on the downloadable Consultation PDF handoff.

## 3. Non-Negotiable Invariants

1. **Strict Mutual Exclusion Invariant:** A customer can NEVER select both Screen and Grill attachments at the same time on a single product. The selection state is strictly ternary: `None`, `Screen`, or `Grill`. Selecting Screen must immediately unmount the Grill; selecting Grill must immediately unmount the Screen.
2. **Conditional UI Rendering:** If an administrator did not configure any compatible add-ons for a product in Step 5 (`product_compatible_addons` is empty), no add-on toggle controls may be rendered in the customer workspace. If only Screen is configured, the toggle offers `None` and `Screen`. If only Grill is configured, the toggle offers `None` and `Grill`.
3. **Sub-50ms Dynamic Price Synchronization:** Toggling between add-on options must recalculate the separate add-on BOM and update the workspace bottom dock and floating HUD price tag in under 50 milliseconds via client-side calculation.
4. **Zero Occlusion & Homography Degradation:** Toggling add-on attachments on the 3D model must update only the procedural front-layer group. It must never re-fetch GLB assets, reload the room photo, clear 4-point perspective fits, or corrupt SegFormer ADE20K foreground occlusion masks.
5. **Frozen Quotation Provenance:** Once a quotation estimate is confirmed, the selected add-on type, add-on product ID, add-on item name, and exact frozen price must be permanently saved in `quotation_items.pricing_details`. Future changes to add-on catalog rates must never alter historical quotation records.
6. **Separate Pricing Transparency:** The customer-facing quotation modal and consultation PDF must clearly distinguish the base window fixture price from the separate add-on attachment price, ensuring full cost transparency.
7. **Zero Em-Dashes:** In strict compliance with `BAN-PUNCT-01`, all user interface labels, option descriptions, helper text, and code comments must use hyphens, colons, or parentheses. Never use em-dashes.
8. **Strict Type Safety:** Zero usage of `any` across TypeScript interfaces, state hooks, and pricing functions per `BAN-TYPE-05`.
9. **UI Design Token Parity:** All buttons, pills, toggles, and modals must reuse established Tailwind CSS tokens from `src/app/globals.css` (`rounded-[10px]`, `rounded-[20px]`, `border-[#c3c3c3]`, `bg-[#0f1422]`, `text-[#07b6d3]`) per `BAN-UI-09`.

### 4.2 Dedicated Add-on Pricing Engine (`src/lib/pricing/addonPricingEngine.ts`)

Create `src/lib/pricing/addonPricingEngine.ts`:

```typescript
export interface AddonPricingInput {
  addonType: "screen" | "grill";
  widthMm: number;
  heightMm: number;
  finishType?: string;
  customProfileRate?: number; // PHP per linear meter
  customMeshRate?: number; // PHP per square meter
}

export interface AddonBOMResult {
  addonType: "screen" | "grill";
  addonName: string;
  directMaterialCost: number;
  wasteAllowanceCost: number;
  laborCost: number;
  contractorMargin: number;
  finalAddonPrice: number;
  breakdown: Array<{
    item: string;
    quantity: number;
    unit: string;
    unitPrice: number;
    subtotal: number;
  }>;
}

const SCRAP_ALUMINUM = 0.12; // 12% offcut allowance
const SCRAP_MESH = 0.10; // 10% mesh cut-off allowance
const CONTRACTOR_MARGIN_RATE = 0.25; // 25% margin

export function calculateAddonBOM(input: AddonPricingInput): AddonBOMResult {
  const widthM = input.widthMm / 1000;
  const heightM = input.heightMm / 1000;
  const breakdown: AddonBOMResult["breakdown"] = [];

  if (input.addonType === "screen") {
    // 1. Frame Extrusions (Perimeter: 2 * (W + H))
    const frameLinearM = 2 * (widthM + heightM);
    const frameNetRate = input.customProfileRate ?? 145.0; // PHP/m for screen channel extrusion
    const frameGrossCost = frameLinearM * (1 + SCRAP_ALUMINUM) * frameNetRate;

    breakdown.push({
      item: "Screen Frame Extrusion (Aluminum)",
      quantity: Math.round(frameLinearM * (1 + SCRAP_ALUMINUM) * 100) / 100,
      unit: "m",
      unitPrice: frameNetRate,
      subtotal: Math.round(frameGrossCost * 100) / 100,
    });

    // 2. Insect Wire Mesh (Area: W * H)
    const meshAreaSqm = widthM * heightM;
    const meshNetRate = input.customMeshRate ?? 220.0; // PHP/sqm for vinyl-coated fiberglass / wire mesh
    const meshGrossCost = meshAreaSqm * (1 + SCRAP_MESH) * meshNetRate;

    breakdown.push({
      item: "Insect Wire Mesh Screen",
      quantity: Math.round(meshAreaSqm * (1 + SCRAP_MESH) * 100) / 100,
      unit: "sqm",
      unitPrice: meshNetRate,
      subtotal: Math.round(meshGrossCost * 100) / 100,
    });

    // 3. Hardware (4 Corner Keys + Spline Rubber)
    const cornerKeysCost = 80.0; // 4 pcs @ 20.00
    const splineCost = frameLinearM * 15.0; // Rubber spline gasket
    const hardwareSubtotal = cornerKeysCost + splineCost;

    breakdown.push({
      item: "Spline & Corner Key Hardware",
      quantity: 1,
      unit: "set",
      unitPrice: Math.round(hardwareSubtotal * 100) / 100,
      subtotal: Math.round(hardwareSubtotal * 100) / 100,
    });

    const materialSubtotal = frameGrossCost + meshGrossCost + hardwareSubtotal;
    const laborCost = Math.max(350.0, materialSubtotal * 0.20);
    const margin = (materialSubtotal + laborCost) * CONTRACTOR_MARGIN_RATE;
    const finalPrice = Math.round((materialSubtotal + laborCost + margin) * 100) / 100;

    return {
      addonType: "screen",
      addonName: "Extruded Aluminum Insect Screen",
      directMaterialCost: materialSubtotal,
      wasteAllowanceCost: frameGrossCost - (frameLinearM * frameNetRate) + (meshGrossCost - (meshAreaSqm * meshNetRate)),
      laborCost: Math.round(laborCost * 100) / 100,
      contractorMargin: Math.round(margin * 100) / 100,
      finalAddonPrice: finalPrice,
      breakdown,
    };
  } else {
    // Security Grille Pricing
    // 1. Perimeter Frame
    const frameLinearM = 2 * (widthM + heightM);
    const frameNetRate = 185.0; // PHP/m for tubular mounting frame
    const frameGrossCost = frameLinearM * (1 + SCRAP_ALUMINUM) * frameNetRate;

    breakdown.push({
      item: "Grille Mounting Perimeter Frame",
      quantity: Math.round(frameLinearM * (1 + SCRAP_ALUMINUM) * 100) / 100,
      unit: "m",
      unitPrice: frameNetRate,
      subtotal: Math.round(frameGrossCost * 100) / 100,
    });

    // 2. Repeating Structural Bars (Vertical Pickets at 140mm pitch)
    const colCount = Math.max(1, Math.round(input.widthMm / 140));
    const totalBarLinearM = colCount * heightM;
    const barNetRate = 160.0; // PHP/m for square tube bars
    const barGrossCost = totalBarLinearM * (1 + SCRAP_ALUMINUM) * barNetRate;

    breakdown.push({
      item: `Security Grille Bars (${colCount} pickets)`,
      quantity: Math.round(totalBarLinearM * (1 + SCRAP_ALUMINUM) * 100) / 100,
      unit: "m",
      unitPrice: barNetRate,
      subtotal: Math.round(barGrossCost * 100) / 100,
    });

    // 3. Mounting Anchors & Fasteners
    const anchorCost = 150.0;
    breakdown.push({
      item: "Heavy-Duty Wall Mounting Anchors",
      quantity: 1,
      unit: "set",
      unitPrice: anchorCost,
      subtotal: anchorCost,
    });

    const materialSubtotal = frameGrossCost + barGrossCost + anchorCost;
    const laborCost = Math.max(600.0, materialSubtotal * 0.25);
    const margin = (materialSubtotal + laborCost) * CONTRACTOR_MARGIN_RATE;
    const finalPrice = Math.round((materialSubtotal + laborCost + margin) * 100) / 100;

    return {
      addonType: "grill",
      addonName: "Architectural Security Window Grille",
      directMaterialCost: materialSubtotal,
      wasteAllowanceCost: (frameGrossCost - frameLinearM * frameNetRate) + (barGrossCost - totalBarLinearM * barNetRate),
      laborCost: Math.round(laborCost * 100) / 100,
      contractorMargin: Math.round(margin * 100) / 100,
      finalAddonPrice: finalPrice,
      breakdown,
    };
  }
}
```
