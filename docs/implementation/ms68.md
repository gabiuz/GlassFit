## 1. Outcome and Scope

In standard GlassFit product authoring, administrators upload individual 3D `.glb` component meshes for window frames, sash rails, and glass panels. While the base window model can be parametrically scaled and configured, optional attachments such as insect screens and window security grills pose unique geometric and architectural challenges:
1. **Decoupled Architecture (Not in Uploaded 3D Model):** Screens and grills must not be baked into the host product's uploaded `.glb` files. If every window required separate 3D models with baked-in screens or grills, catalog asset storage would triple, and administrators would have to manually model dozens of mesh variations for every frame profile.
2. **Dynamic Screen Frame Dimensional Matching:** An insect screen features an extruded aluminum perimeter frame (top, bottom, left, right profiles) enclosing a taut wire or fiberglass mesh. As a user adjusts opening width and height, the outer screen frame must match the host product dimensions exactly, and the mesh infill must continuously fill the entire frame aperture without sagging, stretching distortion, or gaps.
3. **Procedural Pattern Repetition for Security Grills:** Unlike a simple scaled box, a window security grill consists of an outer mounting perimeter and repeating structural bars (vertical picket tubes, horizontal crossbars, or colonial grid modules). Scaling a static 3D model would distort bar thicknesses (causing bars to look unnaturally fat or thin). Instead, the engine must procedurally tile and repeat the grill pattern across both width and height, maintaining uniform bar cross-sections and realistic spacing as opening dimensions expand or contract.
4. **Front-Layer Compositing:** Both attachments sit on top of the host fixture as a front layer (offset forward along the opening's Z-axis). This physical layering prevents visual z-fighting with the window frame and glass infill while replicating real-world exterior or interior surface mounting.

`IMP-MS68` implements this modular 3D parametric add-on engine:
- **Procedural Screen Mesh & Frame Generator:** Constructs a lightweight, parametric 4-piece extruded aluminum frame with a tightly stretched wire mesh infill plane whose outer dimensions continuously match the host product width and height to within 0.1mm.
- **Procedural Grill Pattern Repetition Engine:** Implements algorithmic grid tiling that computes optimal bar counts based on standard architectural pitch (e.g., 120mm to 150mm center-to-center spacing), dynamically repeating vertical and horizontal bars to span the exact opening dimensions.
- **Deterministic Front-Layer Z-Offset:** Automatically offsets add-on attachments along the local +Z axis (+18mm for screen frames, +22mm for security grills), ensuring clean depth separation from the host sash and glass panes.
- **Sub-16ms Reactivity:** Employs efficient Three.js `InstancedMesh` and procedural `BufferGeometry` generation, recalculating add-on geometry in under 16 milliseconds (maintaining 60 FPS) during slider interaction.
- **Admin Step 6 Validation Sandbox Integration:** Embeds an interactive add-on preview controller in `/admin/products/[id]/setup` (Step 6), allowing administrators to test dimensional scaling, pattern repetition, and front-layer alignment before product publication.

Customer-facing workspace selection, mutual-exclusion toggles, dynamic quotation recalculation, and consultation PDF handoffs are specified in `IMP-MS69`.

## 3. Non-Negotiable Invariants

1. **Exact Dimensional Bounding Match:** The outer boundary (width and height) of the procedural screen frame and security grill must strictly match the host product aperture width (`widthMm`) and height (`heightMm`) at all slider values. Any dimensional deviation greater than 0.5mm is strictly prohibited.
2. **Constant Bar Cross-Section Invariant (Grills):** Expanding or shrinking window dimensions must never stretch, squash, or distort the cross-sectional dimensions of individual grill bars. Individual bar widths must remain constant (e.g., exactly 16mm x 16mm or 12mm diameter), with dimension changes absorbed exclusively by repeating pattern counts and proportional pitch spacing.
3. **Full Frame Infill Invariant (Screens):** The screen mesh plane must always span from inner frame lip to inner frame lip across 100% of the interior aperture. No visible gaps or border clipping are permitted.
4. **Deterministic Front-Layer Z-Offset:** To avoid coplanar z-fighting with the host window sash and glass, add-on attachments must maintain a positive Z-offset (+18mm for screen, +22mm for grill) relative to the forward face of the window frame.
5. **Real-Time 60 FPS Performance:** Recalculating and updating procedural add-on geometry during continuous slider dragging must complete in under 16 milliseconds per frame without memory leaks or repeated WebGL context allocations.
6. **Zero External 3D Library Dependencies:** Procedural geometry must be constructed using native Three.js primitives (`BufferGeometry`, `InstancedMesh`, `MeshStandardMaterial`) without importing external modeling libraries per `BAN-DIAG-03` and Section 1 of `AGENTS.md`.
7. **Zero Em-Dashes:** In compliance with `BAN-PUNCT-01`, all user-facing labels, option descriptions, tooltips, and code comments must use hyphens, colons, or parentheses. Never use em-dashes.
8. **Strict Type Safety:** Zero usage of `any` across TypeScript interfaces, geometry helpers, and builder parameters per `BAN-TYPE-05`.

## 4. Technical Design & 3D Procedural Architecture

### 4.1 Modular Add-on Geometry Generator (`src/lib/visualization/addonGeometryBuilder.ts`)

Create `src/lib/visualization/addonGeometryBuilder.ts` to procedurally generate screen and grill 3D assemblies:

```typescript
import * as THREE from "three";

export interface AddonGeometryConfig {
  frameWidthMm?: number; // Face width of screen/grill frame profile (default: 25mm)
  frameDepthMm?: number; // Profile depth along Z-axis (default: 12mm)
  grillBarWidthMm?: number; // Cross-section of repeating bars (default: 16mm)
  nominalBarPitchMm?: number; // Target spacing between grill bars (default: 140mm)
  zOffsetMm?: number; // Forward offset in front of window (default: 18mm for screen, 22mm for grill)
  finishColor?: string; // Hex color for aluminum frame/bars
}

const MM_TO_METERS = 0.001;

/**
 * Procedurally generates an extruded 4-sided aluminum screen frame
 * with an interior insect wire mesh infill plane.
 */
export function buildParametricScreenGroup(
  widthMm: number,
  heightMm: number,
  config: AddonGeometryConfig = {},
  frameMaterial: THREE.Material,
  meshMaterial: THREE.Material
): THREE.Group {
  const group = new THREE.Group();
  group.name = "Addon_Screen_Assembly";

  const frameWidth = (config.frameWidthMm ?? 25) * MM_TO_METERS;
  const frameDepth = (config.frameDepthMm ?? 12) * MM_TO_METERS;
  const zOffset = (config.zOffsetMm ?? 18) * MM_TO_METERS;

  const widthM = widthMm * MM_TO_METERS;
  const heightM = heightMm * MM_TO_METERS;

  // 1. Outer Frame Extrusions (Top, Bottom, Left, Right rails)
  const topRailGeo = new THREE.BoxGeometry(widthM, frameWidth, frameDepth);
  const topRail = new THREE.Mesh(topRailGeo, frameMaterial);
  topRail.position.set(0, heightM / 2 - frameWidth / 2, zOffset);
  topRail.castShadow = true;

  const bottomRailGeo = new THREE.BoxGeometry(widthM, frameWidth, frameDepth);
  const bottomRail = new THREE.Mesh(bottomRailGeo, frameMaterial);
  bottomRail.position.set(0, -heightM / 2 + frameWidth / 2, zOffset);
  bottomRail.castShadow = true;

  const innerHeightM = Math.max(0, heightM - 2 * frameWidth);
  const sideJambGeo = new THREE.BoxGeometry(frameWidth, innerHeightM, frameDepth);

  const leftJamb = new THREE.Mesh(sideJambGeo, frameMaterial);
  leftJamb.position.set(-widthM / 2 + frameWidth / 2, 0, zOffset);
  leftJamb.castShadow = true;

  const rightJamb = new THREE.Mesh(sideJambGeo, frameMaterial);
  rightJamb.position.set(widthM / 2 - frameWidth / 2, 0, zOffset);
  rightJamb.castShadow = true;

  group.add(topRail, bottomRail, leftJamb, rightJamb);

  // 2. Interior Wire Mesh Plane (fills frame opening)
  const innerWidthM = Math.max(0, widthM - 2 * frameWidth);
  if (innerWidthM > 0 && innerHeightM > 0) {
    const meshPlaneGeo = new THREE.PlaneGeometry(innerWidthM, innerHeightM);
    const meshPlane = new THREE.Mesh(meshPlaneGeo, meshMaterial);
    meshPlane.position.set(0, 0, zOffset);
    group.add(meshPlane);
  }

  return group;
}

/**
 * Procedurally generates a security window grill with an outer perimeter
 * and repeating vertical/horizontal bars spanning dynamic dimensions.
 */
export function buildParametricGrillGroup(
  widthMm: number,
  heightMm: number,
  config: AddonGeometryConfig = {},
  grillMaterial: THREE.Material
): THREE.Group {
  const group = new THREE.Group();
  group.name = "Addon_Grill_Assembly";

  const frameWidth = (config.frameWidthMm ?? 20) * MM_TO_METERS;
  const frameDepth = (config.frameDepthMm ?? 16) * MM_TO_METERS;
  const barWidth = (config.grillBarWidthMm ?? 14) * MM_TO_METERS;
  const nominalPitchMm = config.nominalBarPitchMm ?? 140;
  const zOffset = (config.zOffsetMm ?? 22) * MM_TO_METERS;

  const widthM = widthMm * MM_TO_METERS;
  const heightM = heightMm * MM_TO_METERS;

  // 1. Perimeter Frame (Matches window outer dimensions)
  const topGeo = new THREE.BoxGeometry(widthM, frameWidth, frameDepth);
  const topMesh = new THREE.Mesh(topGeo, grillMaterial);
  topMesh.position.set(0, heightM / 2 - frameWidth / 2, zOffset);

  const bottomMesh = new THREE.Mesh(topGeo, grillMaterial);
  bottomMesh.position.set(0, -heightM / 2 + frameWidth / 2, zOffset);

  const innerHeightM = Math.max(0, heightM - 2 * frameWidth);
  const sideGeo = new THREE.BoxGeometry(frameWidth, innerHeightM, frameDepth);

  const leftMesh = new THREE.Mesh(sideGeo, grillMaterial);
  leftMesh.position.set(-widthM / 2 + frameWidth / 2, 0, zOffset);

  const rightMesh = new THREE.Mesh(sideGeo, grillMaterial);
  rightMesh.position.set(widthM / 2 - frameWidth / 2, 0, zOffset);

  group.add(topMesh, bottomMesh, leftMesh, rightMesh);

  // 2. Pattern Repetition Engine: Vertical Bars
  const innerWidthM = Math.max(0, widthM - 2 * frameWidth);
  const innerWidthMm = innerWidthM / MM_TO_METERS;

  // Calculate integer bar count to ensure uniform pitch
  const colCount = Math.max(1, Math.round(innerWidthMm / nominalPitchMm));
  const actualPitchM = innerWidthM / (colCount + 1);

  const vBarGeo = new THREE.BoxGeometry(barWidth, innerHeightM, barWidth);
  for (let i = 1; i <= colCount; i++) {
    const xPos = -innerWidthM / 2 + i * actualPitchM;
    const vBar = new THREE.Mesh(vBarGeo, grillMaterial);
    vBar.position.set(xPos, 0, zOffset);
    vBar.castShadow = true;
    group.add(vBar);
  }

  // 3. Pattern Repetition Engine: Horizontal Tie Bars (if height exceeds 1000mm)
  if (heightMm > 1000) {
    const rowCount = Math.max(1, Math.floor(heightMm / 800));
    const actualRowPitchM = innerHeightM / (rowCount + 1);
    const hBarGeo = new THREE.BoxGeometry(innerWidthM, barWidth, barWidth);

    for (let j = 1; j <= rowCount; j++) {
      const yPos = -innerHeightM / 2 + j * actualRowPitchM;
      const hBar = new THREE.Mesh(hBarGeo, grillMaterial);
      hBar.position.set(0, yPos, zOffset);
      hBar.castShadow = true;
      group.add(hBar);
    }
  }

  return group;
}
```

### 4.2 Specialized PBR Materials for Screens and Grills

In `src/lib/visualization/materialClassifier.ts`:
1. **Screen Frame Material:** Reuses `createMaterialPalette(finish)` to match the parent window's aluminum profile (e.g., Analok bronze `#221d1a` or Powder Coated White `#f5f6f8`).
2. **Screen Wire Mesh Shader Material:**
   - Procedural or alpha-tested grid texture:
     ```typescript
     export function createInsectScreenMaterial(): THREE.MeshStandardMaterial {
       const canvas = document.createElement("canvas");
       canvas.width = 64;
       canvas.height = 64;
       const ctx = canvas.getContext("2d")!;
       ctx.fillStyle = "rgba(0, 0, 0, 0)";
       ctx.fillRect(0, 0, 64, 64);
       ctx.strokeStyle = "#404040";
       ctx.lineWidth = 4;
       ctx.strokeRect(0, 0, 64, 64);

       const texture = new THREE.CanvasTexture(canvas);
       texture.wrapS = THREE.RepeatWrapping;
       texture.wrapT = THREE.RepeatWrapping;
       texture.repeat.set(80, 80);

       return new THREE.MeshStandardMaterial({
         map: texture,
         alphaMap: texture,
         transparent: true,
         opacity: 0.75,
         roughness: 0.8,
         metalness: 0.2,
         side: THREE.DoubleSide,
         depthWrite: false,
       });
     }
     ```
3. **Security Grill Material:** High-opacity architectural metal with subtle metallic sheen (`metalness: 0.4`, `roughness: 0.5`).
