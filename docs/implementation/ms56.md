## 1. Outcome and Scope

The width and height shown in the opening picker, parametric model controls, mesh geometry, quotation modal, and saved quotation must refer to the same accepted measurement and revision. Correct detection and perspective math are insufficient if another stage replaces those results with defaults, a stale scalar, or old dimensions.

Use the authoritative MS54 metric-corner result only when MS55 permits it. Preserve existing model configuration, finishes, glass choices, structural rules, and cross-product switching behavior.

## 3. Domain and State Contract

### 3.1 Proposed Measurement Record

| Field | Contract |
|---|---|
| `measurement_revision` | Changes whenever accepted corners, standard, physical edge correspondence, plane assignment, or image transform changes |
| `image_identity`, `image_width_px`, `image_height_px` | Bind geometry to the canonical workspace bitmap |
| `plane_id`, `calibration_revision` | Bind an opening to its applicable reference plane and transform |
| `opening_corners` | Four canonical normalized workspace-image corners |
| `width_mm`, `height_mm`, `edge_spans_mm` | Valid finite unrounded metric evaluator results |
| `source`, `eligibility`, `reason_codes` | Explicit origin and validation state |
| `reference_source`, `paper_standard`, `placement_assessment` | Auditable calibration inputs without claiming measured accuracy |
| `algorithm_version`, `coordinate_space`, `sensitivity_summary` | Reproducibility and quality context |

Validate at API ingestion, storage hydration, domain measurement, and server quotation boundaries. Do not accept client-supplied confidence as proof that measurement prerequisites passed. No new database column is assumed; use the existing quotation JSON metadata only after verifying the current schema and serializers. If schema changes prove necessary, plan a reversible migration before implementation.

### 3.2 Lifecycle Rules

1. Initial model defaults remain approximate until an actual opening is fitted or manual dimensions are entered. A default centered rectangle is not evidence of opening size.
2. Fitting an eligible opening commits its metric result, model width/height, mesh parameters, labels, and revision as one logical update. Do not blend template heights, relative depth, or scalar estimates into calibrated dimensions.
3. Corner dragging can show provisional measurements; commit only a complete valid result. Reject stale asynchronous calculations for a previous image, product, plane, or revision.
4. Changing paper inputs invalidates dependent accepted measurements. Preview updated values for affected overlays; commit eligible results atomically. Invalid results cannot leave a stale calibrated badge or current quotation dimensions behind.
5. Recompute only photo-derived overlays bound to the affected plane. Preserve manual tape dimensions, unrelated planes, product identity, finishes, and scene placement. Flag manual versus photo disagreement without silently replacing manual values.
6. Changing product, adding an overlay, or refreshing preserves the reference contract but does not invent an opening fit for the new product. Apply a shared plane only when the target assignment is valid.
7. Submitted or frozen quotation snapshots remain immutable. A changed measurement creates a new draft calculation requiring confirmation; no background recalculation mutates historical accepted prices or dimensions.

## 4. Presentation and Precision

Reuse current workspace HUD, edge callouts, model controls, measurement dialog, and design tokens. Avoid new palettes, arbitrary layout conventions, or additional UI libraries.

| State | Presentation |
|---|---|
| Eligible planar result | "Photo estimate: paper calibrated" with width/height and reference format |
| Corners reviewed | Describe reviewed paper boundaries separately; do not call the physical size verified |
| Placement unknown or mismatched | Explain the reason and show retake/manual actions; omit trusted metric badges |
| Manual tape dimensions | "Manual tape measurement" with the entered values |
| Approximate preview | Explicit approximate source; no fabricated accuracy percentage |
| Geometry outside product rules | Existing structural guardrail behavior; preserve the actual measured value and reason |

Keep enough numeric precision for the existing centimeter model interface, including fractional centimeters where supported. Use the established display convention without implying that display resolution is measurement accuracy. If the current parameter schema forces rounding, document the conversion and test its effect on model and quotation parity. Do not apply silent global 30-600 cm or 30-400 cm clamps from older calibration plans.

## 5. Quotation and Persistence Contract

The existing `pricing_details.dimension_source` values must remain readable. Define new writes explicitly during implementation:

| Current outcome | Proposed new-write source | Compatibility rule |
|---|---|---|
| Eligible MS54/MS55 photo measurement | `planar_paper_estimate` | Add to validators, pricing types, booking adapters, admin display, and document rendering together |
| User-supplied tape dimensions | Existing `manual_tape` | Preserve manual precedence and validation |
| Heuristic preview | Existing applicable heuristic value | Never substitute manual or calibrated source labels |
| Legacy `calibrated_visual` or `verified_calibrated_visual` | Retain on existing snapshots | Hydrated editor data must revalidate before being used for a new trusted estimate |

Confirm the actual heuristic union value from the repository before editing types; this specification does not invent it. Preserve unrelated JSON fields when adding a versioned calibration provenance object. Persist dimensions, image/plane/revision references, format, placement declaration, algorithm version, and source with the confirmed quotation item. Do not embed room image bytes or detector candidate lists in pricing metadata.

On refresh, older scalar-only sessions, unknown coordinate frames, corrupted matrices, and incomplete calibration data downgrade to approximate or needs-review state. Missing data cannot default to user confirmation. Quota fallback storage may omit expensive photo data, but if required calibration evidence is lost, downgrade eligibility explicitly.

## 6. Step-by-Step Implementation Plan

1. Implement the versioned measurement record and eligibility adapter using MS54/MS55 contracts.
2. Replace active and placed-overlay scalar sizing with the shared metric evaluator; update model dimensions and labels atomically.
3. Add revision invalidation and manual-measurement precedence to session updates, persistence, refresh, and product switching.
4. Update every quotation source reader/writer and server validator as one compatibility change. Preserve frozen snapshots and current RLS boundaries.
5. Reconcile MS43 guardrails and all unit conversions with the physical measurement result.
6. Register QAD-TC71 and update upstream persistence and UI descriptions during implementation only.

## 7. Verification and Acceptance Criteria

| Test ID | Scenario | Expected outcome | Severity |
|---|---|---|---|
| QAD-TC71.1 | Fit an eligible opening | Picker, controls, mesh input dimensions, and quotation agree at documented rounding tolerance | P0 |
| QAD-TC71.2 | Adjust reference after several products are placed | Matching photo-derived overlays update together; finishes and manual dimensions persist | P0 |
| QAD-TC71.3 | Invalid recalibration or plane change | Stale calibrated dimensions cannot be confirmed into a new quotation | P0 |
| QAD-TC71.4 | Add/change/edit product and refresh | Image, plane, source, and revision survive without treating new defaults as measured | P0 |
| QAD-TC71.5 | Legacy or quota-truncated session | Honest needs-review/approximate state; existing quotation remains readable | P0 |
| QAD-TC71.6 | Measurement crosses a structural threshold | Existing structural rules run on the actual converted dimensions | P0 |
| QAD-TC71.7 | Marker changes after quotation submission | Historical snapshot and negotiated values remain unchanged | P0 |

Extend existing grounding, session permanence, measurement confirmation, quotation document, and booking reflection tests with behavioral assertions. MS57 supplies the end-to-end physical benchmark.

## 8. Risks and Mitigations

Changing a reference may legitimately change several draft dimensions and prices. Make the affected draft revision visible and require the existing measurement confirmation before a new quotation is saved. Source metadata must communicate that paper calibration remains a photo-based estimate, not a fabrication measurement certificate.

## 9. Implementation Record (October 19, 2026)

- Added a versioned, schema-validated measurement record containing the normalized opening, canonical image frame, target plane, reference correspondence, calibration and measurement revisions, millimeter edge spans, MS55 placement declaration, algorithm version, and provisional sensitivity diagnostics.
- New photo writes use `planar_paper_estimate`. Both tape dimensions retain `manual_tape`; approximate previews use `heuristic` (existing default initialization also retains `default_heuristic`). Legacy source values remain readable on historical snapshots and require fresh evidence for new drafts.
- Opening fits commit the accepted result to model dimensions, renderer parameters, source labels, and provenance together. New products start without an accepted fit. Matching draft planes recalculate together; manual values and independently recorded unrelated planes persist. A tape/photo difference is recorded as `photo_disagreement_mm` without overwriting tape values.
- Editable sessions revalidate on hydration. Missing image evidence, scalar-only calibration, invalid correspondence, corrupted matrices, and incomplete placement downgrade to approximate. The quota fallback cannot retain trusted dimensions when its workspace image is omitted.
- Quotation summary, booking flow, canonical draft validation, JSON pricing metadata, legacy reconstruction, and shared customer/admin/PDF rendering preserve source and provenance. New drafts reproduce photo dimensions on the server; confidence is not evidence. Historical snapshots and negotiation amounts are not recalculated.
- Millimeter values and centimeter model inputs remain unrounded for photo estimates, including structural thresholds and pricing. Existing integer-centimeter conversion remains limited to the explicit tape-entry path. Centimeter display rounds to three decimal places where needed; existing edge/HUD labels round to integer millimeters (maximum display difference 0.5 mm). Display resolution does not establish physical accuracy.
- Verified existing JSONB storage in migrations `001_backend_core.sql` (`pricing_details`) and `006_canonical_quotation_and_negotiated_price.sql` (`quotation_document_snapshot`). No new database column, migration, dependency, or RLS change is required.
