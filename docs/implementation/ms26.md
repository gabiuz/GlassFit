## 1. Executive Summary & Problem Context

In the GlassFit administrative workbench (`/admin/bookings`), authorized personnel triage client booking requests, review parameterized fenestration quotations, assess site access conditions, negotiate per-item fabrication prices, and append professional installation and mobilization labor fees prior to ocular confirmation.

### 1.1 The Reported Defect & Numerical Manifestation

Under Milestone 24 (`IMP-MS24`), customer self-service quotations were scoped strictly to raw product fabrication costs, delegating installation and delivery labor to the administrative booking phase (`updateBookingLaborCharge`). Under Milestone 17 (`IMP-MS17`) and Milestone 25 (`IMP-MS25`), product pricing is negotiated on an itemized basis (`updateItemNegotiatedPrice`).

When an administrator combines both actions on a booking request, the calculation pipeline breaks down completely:

1. **Step 1 (Product Price Negotiation):** An administrator edits a product fixture whose calculated baseline is PHP 2,844.58, negotiating the final item price down to **PHP 2,800.00**. The fixture card confirms:
   - Final item price: `₱2,800.00`
2. **Step 2 (Labor Fee Entry):** The administrator clicks "Add Labor Fee" and enters **PHP 600.00** for site installation.
3. **Step 3 (Unexpected Outcome):** Instead of displaying an effective grand total of **PHP 3,400.00** (`2,800.00 + 600.00`), the system outputs **PHP 3,444.58**.
4. **Step 4 (Distorted Quotation Breakdown):** Upon inspecting the quotation summary and consultation PDF preview, the line items contradict each other:
   - Final item price (in fixture specs card): `₱2,800.00`
   - Raw product fabrication subtotal: `₱2,785.64`
   - Professional Installation & Site Labor (Admin Confirmed): `₱658.94`
   - Grand total: `₱3,444.58`

The administrator explicitly set the raw product fabrication price to PHP 2,800.00 and the labor fee to PHP 600.00. The system must deterministically honor these inputs: the raw product fabrication subtotal must be PHP 2,800.00, the labor fee must be PHP 600.00, and the grand total must be PHP 3,400.00.

### 1.2 Root Cause Analysis

Tracing the state transitions across `src/lib/booking/bookingActions.ts`, `src/features/admin/bookings/adminBookingMapper.ts`, `src/features/admin/bookings/BookingsContent.tsx`, and `src/lib/pricing/quotationPdfGenerator.ts` reveals three interrelated defects:

```
[Defect 1: bookingActions.ts]
updateBookingLaborCharge reads only `total_estimated_amount` (2,844.58)
Ignores `item_price_overrides` (2,800.00)
Adds 600.00 to 2,844.58 -> 3,444.58
Overwrites `negotiated_amount` with 3,444.58, clobbering item overrides

[Defect 2: Data Model State Collisions]
Both item overrides and labor fee fight over single scalar column `negotiated_amount`
No explicit column exists to persist `admin_labor_charge` independently
updateItemNegotiatedPrice overwrites `negotiated_amount`, wiping out labor fee
updateBookingLaborCharge overwrites `negotiated_amount`, ignoring item prices

[Defect 3: quotationPdfGenerator.ts & BookingsContent.tsx Inverted Baselines]
PDF generator computes laborDiff = effectiveFinalPrice - pricing.directMaterialsSubtotal
directMaterialsSubtotal (2,785.64) is an immutable BOM material cost, not product price
3,444.58 - 2,785.64 = 658.94 (creates phantom 58.94 variance)
PDF renders directMaterialsSubtotal (2,785.64) as "Raw product fabrication subtotal"
Contradicts the fixture card above which displays "Final item price: 2,800.00"
```

#### Root Cause 1: `updateBookingLaborCharge` Ignores Negotiated Item Overrides
In `src/lib/booking/bookingActions.ts` (lines 769-773):
```typescript
const rawProductPrice = Number(current.total_estimated_amount);
const labor = parsed.data.laborAmount;
const newEffectiveGrandTotal = labor === null ? null : Math.round((rawProductPrice + labor) * 100) / 100;
```
`current.total_estimated_amount` represents the un-negotiated, initial calculated estimate from the time of quotation creation (in this case, PHP 2,844.58).
When the administrator negotiated the fixture price to PHP 2,800.00, that override was stored in `item_price_overrides`. However, `updateBookingLaborCharge` never inspected `item_price_overrides` or `quotation_document_snapshot`. It added the PHP 600.00 labor charge directly to the un-negotiated baseline (`2,844.58 + 600.00 = 3,444.58`), completely discarding the negotiated PHP 2,800.00 product price.

#### Root Cause 2: Storage Collision on `quotation_estimates.negotiated_amount`
The relational database table `public.quotation_estimates` does not possess a dedicated column for administrative labor charges. Consequently:
- `updateItemNegotiatedPrice` evaluates the sum of item effective prices (e.g. PHP 2,800.00) and writes that sum to `negotiated_amount`. Any previously entered labor fee is erased.
- `updateBookingLaborCharge` adds labor to raw product baseline and writes the resulting grand total (e.g. PHP 3,444.58) to `negotiated_amount`. The system can no longer distinguish what portion of `negotiated_amount` represents the product price versus the labor fee.
- Because both workflows mutate the same scalar column without an explicit labor storage field, they clobber each other in circular fashion.

#### Root Cause 3: Inverted Comparison and Direct Materials Substitution in PDF Generation
In `src/lib/pricing/quotationPdfGenerator.ts` (lines 90-97):
```typescript
const laborDiff = Math.max(0, metadata.effectiveFinalPrice - metadata.pricing.directMaterialsSubtotal);
const laborRow = metadata.isPriceModified && laborDiff > 0
  ? `<tr><td>Professional Installation &amp; Site Labor (Admin Confirmed)</td><td>${money(laborDiff)}</td></tr>`
  : `<tr><td>Installation &amp; Site Labor</td><td style="font-style:italic;color:#64748b;">To be assessed upon consultation</td></tr>`;
```
And in the HTML substitution:
```typescript
`<h2>Configuration and final prices</h2>${fixtures}<table class="total-table"><tr><td>Raw product fabrication subtotal</td><td>${money(metadata.pricing.directMaterialsSubtotal)}</td></tr>${laborRow}<tr class="grand-total-row"><td>Grand total</td><td>${money(metadata.effectiveFinalPrice)}</td></tr></table>`
```
Two severe errors occur here:
1. `metadata.pricing.directMaterialsSubtotal` (PHP 2,785.64) is the direct material cost from the BOM calculation (aluminum extrusions, glass sheets, hardware). It excludes fabrication scrap allowances, shop labor, or negotiated prices. The PDF generator formats `directMaterialsSubtotal` under the label "Raw product fabrication subtotal", substituting PHP 2,785.64 in place of the negotiated product price of PHP 2,800.00.
2. The confirmed labor fee is derived via subtraction: `effectiveFinalPrice - metadata.pricing.directMaterialsSubtotal` (`3,444.58 - 2,785.64 = 658.94`). The residual difference of PHP 58.94 between the original total estimate (PHP 2,844.58) and direct materials (PHP 2,785.64) is erroneously lumped into the labor charge, inflating it from PHP 600.00 to PHP 658.94.

## 3. Architecture & Domain Mathematical Invariants

### 3.1 Domain Decomposition: Product Fabrication Subtotal vs Site Labor Fee

Every quotation in GlassFit consists of two strictly decoupled financial tiers:

1. **Effective Product Fabrication Subtotal ($P_{\text{product}}$):**
   - For canonical quotations with item breakdowns:
     $$P_{\text{product}} = \sum_{i=1}^{N} \text{effectiveSubtotal}_i$$
     Where $\text{effectiveSubtotal}_i$ is the negotiated item price if an override exists in `item_price_overrides`, or the calculated BOM subtotal if unmodified.
   - For legacy quotations without item breakdowns:
     $$P_{\text{product}} = \text{total\_estimated\_amount}$$
     (or the legacy total price override if negotiated).
2. **Administrative Site Installation & Labor Charge ($L_{\text{admin}}$):**
   - An optional fee evaluated and confirmed by administrative personnel during consultation review.
   - Persisted explicitly in `quotation_estimates.admin_labor_charge`.
   - Equals `0.00` (or `null`) if pending assessment or omitted.
3. **Effective Grand Total ($G_{\text{total}}$):**
   $$G_{\text{total}} = P_{\text{product}} + (L_{\text{admin}} \mathbin{\text{or}} 0.00)$$

### 3.2 Additive Totals & Independence Invariant

The modification of $P_{\text{product}}$ and $L_{\text{admin}}$ must be commutative and non-destructive:

$$\begin{aligned}
\text{Action}(P_{\text{product}} \to P') &\implies G_{\text{total}} = P' + L_{\text{admin}} \\
\text{Action}(L_{\text{admin}} \to L') &\implies G_{\text{total}} = P_{\text{product}} + L'
\end{aligned}$$

- Negotiating an item price ($P_{\text{product}}$) must never erase or modify the confirmed labor charge ($L_{\text{admin}}$).
- Entering or updating a labor charge ($L_{\text{admin}}$) must never alter or ignore item price overrides ($P_{\text{product}}$).
- Setting a fixture to PHP 2,800.00 and adding PHP 600.00 labor must deterministically yield:
  - Product Fabrication Subtotal: `PHP 2,800.00`
  - Professional Installation & Site Labor: `PHP 600.00`
  - Effective Grand Total: `PHP 3,400.00`

### 3.3 State Preservation Invariant

The relational persistence layer must maintain both variables independently:
- `item_price_overrides`: JSONB capturing item-level price adjustments.
- `admin_labor_charge`: NUMERIC(12,2) capturing confirmed installation labor.
- `negotiated_amount`: NUMERIC(12,2) storing the authoritative grand total ($G_{\text{total}}$) whenever either $P_{\text{product}}$ is modified or $L_{\text{admin}}$ is non-null. When both are in their default unmodified state, `negotiated_amount` is `null`.

### 3.4 Presentation and PDF Consistency Invariant

Across all interfaces (`BookingsContent.tsx`, `/admin/bookings`, customer consultation view `/q/[referenceCode]`, and PDF generator `quotationPdfGenerator.ts`):
1. **Raw Product Fabrication Subtotal** must always display $P_{\text{product}}$ (the sum of effective fixture prices). It must never display the raw direct material cost (`directMaterialsSubtotal`).
2. **Professional Installation & Site Labor** must display $L_{\text{admin}}$ when confirmed, or `"To be assessed upon consultation"` when null or zero. It must never be derived via synthetic subtraction against direct materials.
3. **Grand Total** must display $G_{\text{total}} = P_{\text{product}} + (L_{\text{admin}} \mathbin{\text{or}} 0.00)$.

### 4.1 Migration File: `supabase/migrations/009_quotation_admin_labor_charge.sql`

```sql
-- Migration: 009_quotation_admin_labor_charge.sql
-- Description: Add explicit admin_labor_charge column to quotation_estimates to decouple site labor from product negotiation
-- Upstream Specifications: docs/prd-glassfit.md, docs/erd-glassfit.md, docs/implementation/ms26.md
-- Traceability: PRD-F10, PRD-F14, SDD-C8, ERD-E13, QAD-TC42

ALTER TABLE public.quotation_estimates
  ADD COLUMN IF NOT EXISTS admin_labor_charge NUMERIC(12,2) DEFAULT NULL;

COMMENT ON COLUMN public.quotation_estimates.admin_labor_charge IS
  'Explicit administrative site installation and mobilization labor fee confirmed upon booking review';

-- Add check constraint enforcing nonnegative labor charges within supported range
ALTER TABLE public.quotation_estimates
  ADD CONSTRAINT quotation_admin_labor_charge_range_check
  CHECK (admin_labor_charge IS NULL OR admin_labor_charge BETWEEN 0.00 AND 9999999999.99);

-- Backfill existing quotations where negotiated_amount exceeded calculated final price:
-- If quotation_estimates had a negotiated_amount greater than the calculated product total,
-- the difference represents a legacy confirmed labor charge.
DO $$
DECLARE
  quote RECORD;
  calc_total NUMERIC(12,2);
  diff NUMERIC(12,2);
BEGIN
  FOR quote IN
    SELECT quotation_id, total_estimated_amount, negotiated_amount, quotation_document_snapshot, item_price_overrides
    FROM public.quotation_estimates
    WHERE negotiated_amount IS NOT NULL
  LOOP
    calc_total := quote.total_estimated_amount;
    IF quote.negotiated_amount > calc_total THEN
      diff := quote.negotiated_amount - calc_total;
      UPDATE public.quotation_estimates
      SET admin_labor_charge = diff
      WHERE quotation_id = quote.quotation_id;
    END IF;
  END LOOP;
END $$;
```

```typescript
export function deriveQuotationPricingFromItems(
  snapshot: QuotationDocumentSnapshotV1,
  overrides: QuotationItemPriceOverridesV1 | null,
  adminLaborCharge: number | null = null,
): QuotationPricingView {
  const overrideMap = new Map((overrides?.entries ?? []).map((entry) => [entry.itemId, entry]));
  const itemPricing = snapshot.items.map((item) => deriveItemPricing(item, overrideMap.get(item.itemId)));
  
  const calculatedCents = itemPricing.reduce((sum, item) => sum + Math.round(item.calculatedSubtotal * 100), 0);
  const effectiveProductCents = itemPricing.reduce((sum, item) => sum + Math.round(item.effectiveSubtotal * 100), 0);
  const laborCents = adminLaborCharge !== null ? Math.round(adminLaborCharge * 100) : 0;
  const grandTotalCents = effectiveProductCents + laborCents;
  
  const hasItemOverrides = itemPricing.some((item) => item.isPriceModified);
  const hasLabor = adminLaborCharge !== null && laborCents > 0;
  const isPriceModified = hasItemOverrides || hasLabor;

  return {
    itemPricing,
    calculatedFinalPrice: calculatedCents / 100,
    effectiveProductSubtotal: effectiveProductCents / 100,
    adminLaborCharge: adminLaborCharge !== null ? laborCents / 100 : null,
    negotiatedFinalPrice: isPriceModified ? grandTotalCents / 100 : null,
    effectiveFinalPrice: grandTotalCents / 100,
    isPriceModified,
  };
}
```

### 5.3 Server Actions Refactoring (`src/lib/booking/bookingActions.ts`)

#### 5.3.1 `updateBookingLaborCharge`
In `src/lib/booking/bookingActions.ts`, refactor `updateBookingLaborCharge` to read `item_price_overrides` and evaluate the true effective product subtotal:

```typescript
// src/lib/booking/bookingActions.ts

export async function updateBookingLaborCharge(
  input: UpdateBookingLaborInput
): Promise<UpdateNegotiatedPriceResult> {
  const admin = await requirePermission("manage_bookings");
  const parsed = UpdateBookingLaborInputSchema.safeParse(input);
  if (!parsed.success) {
    return { ok: false, code: "VALIDATION_ERROR", message: parsed.error.issues[0]?.message ?? "Invalid labor charge input" };
  }

  const supabase = await createSupabaseServerClient();
  const { data: current, error: readError } = await supabase
    .from("quotation_estimates")
    .select("quotation_id, total_estimated_amount, quotation_document_snapshot, item_price_overrides, admin_labor_charge, updated_at")
    .eq("quotation_id", parsed.data.quotationId)
    .maybeSingle();

  if (readError) return { ok: false, code: "PERSISTENCE_ERROR", message: "Unable to read quotation" };
  if (!current) return { ok: false, code: "NOT_FOUND", message: "Quotation not found" };
  if (!areTimestampsEquivalent(current.updated_at, parsed.data.expectedUpdatedAt)) {
    return { ok: false, code: "CONFLICT", message: "This quotation was updated in another session. Review the latest values and try again." };
  }

  // 1. Resolve Effective Product Subtotal
  let effectiveProductSubtotal: number;
  const snapshotResult = QuotationDocumentSnapshotV1Schema.safeParse(current.quotation_document_snapshot);
  const existingOverrides = QuotationItemPriceOverridesV1Schema.safeParse(current.item_price_overrides);

  if (snapshotResult.success) {
    const itemPricingResult = deriveQuotationPricingFromItems(
      snapshotResult.data,
      existingOverrides.success ? existingOverrides.data : null,
      null
    );
    effectiveProductSubtotal = itemPricingResult.effectiveProductSubtotal;
  } else {
    effectiveProductSubtotal = Number(current.total_estimated_amount);
  }

  // 2. Compute Reconciled Grand Total
  const labor = parsed.data.laborAmount;
  const laborCents = labor === null ? 0 : Math.round(labor * 100);
  const productCents = Math.round(effectiveProductSubtotal * 100);
  const grandTotalCents = productCents + laborCents;
  const newGrandTotal = grandTotalCents / 100;

  if (newGrandTotal > 9_999_999_999.99) {
    return { ok: false, code: "VALIDATION_ERROR", message: "Effective quotation total exceeds supported range" };
  }

  const hasItemOverrides = existingOverrides.success && existingOverrides.data.entries.length > 0;
  const isModified = hasItemOverrides || (labor !== null && labor > 0);
  const now = new Date().toISOString();

  // 3. Persist Labor Charge and Reconciled Grand Total
  const { data: updated, error } = await supabase
    .from("quotation_estimates")
    .update({
      admin_labor_charge: labor,
      negotiated_amount: isModified ? newGrandTotal : null,
      negotiated_by: isModified ? admin.profileId : null,
      negotiated_at: isModified ? now : null,
    })
    .eq("quotation_id", parsed.data.quotationId)
    .eq("updated_at", current.updated_at)
    .select("updated_at")
    .maybeSingle();

  if (error) return { ok: false, code: "PERSISTENCE_ERROR", message: "Unable to save labor charge" };
  if (!updated) return { ok: false, code: "CONFLICT", message: "This quotation changed before the price could be saved." };

  revalidateBookingPaths();
  return {
    ok: true,
    quotationId: parsed.data.quotationId,
    calculatedFinalPrice: Number(current.total_estimated_amount),
    effectiveProductSubtotal,
    adminLaborCharge: labor,
    negotiatedFinalPrice: isModified ? newGrandTotal : null,
    effectiveFinalPrice: newGrandTotal,
    isPriceModified: isModified,
    negotiatedBy: isModified ? admin.profileId : null,
    negotiatedAt: isModified ? now : null,
    updatedAt: updated.updated_at,
  };
}
```

  const { data: current, error: readError } = await supabase
    .from("quotation_estimates")
    .select("quotation_id, quotation_document_snapshot, item_price_overrides, admin_labor_charge, updated_at")
    .eq("quotation_id", parsed.data.quotationId)
    .maybeSingle();

  if (readError) return { ok: false, code: "PERSISTENCE_ERROR", message: "Unable to read quotation" };
  if (!current) return { ok: false, code: "NOT_FOUND", message: "Quotation not found" };
  if (!areTimestampsEquivalent(current.updated_at, parsed.data.expectedUpdatedAt)) {
    return { ok: false, code: "CONFLICT", message: "This quotation was updated in another session. Review the latest values and try again." };
  }

  const snapshotResult = QuotationDocumentSnapshotV1Schema.safeParse(current.quotation_document_snapshot);
  if (!snapshotResult.success) return { ok: false, code: "UNSUPPORTED_QUOTATION", message: "Per-item editing requires a valid canonical quotation." };

  const matches = snapshotResult.data.items.filter((item) => item.itemId === parsed.data.itemId);
  if (matches.length === 0) return { ok: false, code: "ITEM_NOT_FOUND", message: "Quotation item not found" };
  if (matches.length !== 1) return { ok: false, code: "UNSUPPORTED_QUOTATION", message: "Quotation item identity is ambiguous" };

  const existingResult = QuotationItemPriceOverridesV1Schema.safeParse(current.item_price_overrides);
  if (current.item_price_overrides !== null && !existingResult.success) return { ok: false, code: "UNSUPPORTED_QUOTATION", message: "Stored item overrides are invalid" };

  const now = new Date().toISOString();
  const calculatedCents = Math.round(matches[0].calculatedSubtotal * 100);
  const requestedCents = parsed.data.negotiatedSubtotal === null ? null : Math.round(parsed.data.negotiatedSubtotal * 100);
  const nextEntry = requestedCents === null || requestedCents === calculatedCents ? null : {
    itemId: parsed.data.itemId,
    negotiatedSubtotal: requestedCents / 100,
    negotiatedBy: admin.profileId,
    negotiatedAt: now,
  } satisfies QuotationItemPriceOverride;

  const prior = new Map((existingResult.success ? existingResult.data.entries : []).map((entry) => [entry.itemId, entry]));
  if (nextEntry) prior.set(nextEntry.itemId, nextEntry); else prior.delete(parsed.data.itemId);

  const entries = snapshotResult.data.items.flatMap((item) => { const entry = prior.get(item.itemId); return entry ? [entry] : []; });
  const overrideDocument = entries.length ? { schemaVersion: 1 as const, entries } : null;

  // Derive pricing preserving existing administrative labor charge
  const currentLabor = current.admin_labor_charge !== null ? Number(current.admin_labor_charge) : null;
  const pricing = deriveQuotationPricingFromItems(snapshotResult.data, overrideDocument, currentLabor);

  if (pricing.effectiveFinalPrice > 9_999_999_999.99) {
    return { ok: false, code: "VALIDATION_ERROR", message: "Effective quotation total exceeds the supported range" };
  }

  const isModified = pricing.isPriceModified;
  const negotiatedBy = isModified ? admin.profileId : null;
  const negotiatedAt = isModified ? now : null;

  const { data: updated, error } = await supabase
    .from("quotation_estimates")
    .update({
      item_price_overrides: overrideDocument,
      negotiated_amount: isModified ? pricing.effectiveFinalPrice : null,
      negotiated_by: negotiatedBy,
      negotiated_at: negotiatedAt,
    })
    .eq("quotation_id", parsed.data.quotationId)
    .eq("updated_at", current.updated_at)
    .select("updated_at")
    .maybeSingle();

  if (error) return { ok: false, code: "PERSISTENCE_ERROR", message: "Unable to save item price" };
  if (!updated) return { ok: false, code: "CONFLICT", message: "This quotation changed before the price could be saved." };

  revalidateBookingPaths();
  const item = pricing.itemPricing.find((candidate) => candidate.itemId === parsed.data.itemId);
  if (!item) return { ok: false, code: "ITEM_NOT_FOUND", message: "Quotation item not found" };

  return { ok: true, quotationId: parsed.data.quotationId, item, pricing, negotiatedBy, negotiatedAt, updatedAt: updated.updated_at };
}
