## 1. Outcome and Scope

When automated paper detection struggles due to low contrast, shadow gradients, or complex room clutter (such as electrical distribution panels, window panes, door trim, and floor tiles), full-image global contour search frequently abstains (`detection_outcome: "ambiguous"`) or fails to isolate the sheet. Conversely, the existing 4-point manual pin mapping requires placing all four pins individually with a 2.5x loupe, which introduces user friction and takes 30 to 60 seconds per capture.

This milestone introduces **Click-Guided Interactive Paper Localization (Single-Tap Snap)**. The customer taps or clicks once anywhere on the physical paper sheet in the space photograph. The system consumes this normalized seed coordinate `(seed_x, seed_y)` to constrain the contour search space:
1. It immediately filters candidate proposals to the convex quadrilateral enclosing the seed coordinate.
2. If global proposals failed to capture the sheet, it executes localized region-of-interest (ROI) adaptive segmentation seeded at the click point, extracting the containing paper boundary and snapping the four corners automatically.
3. The mapped corners populate the existing confirmation gateway (`PaperDetectionConfirmationModal`), allowing one-tap approval while retaining full manual corner pin editing as a fallback.

This milestone provides the localization intake layer. It hands the four snapped corners to [MS59](ms59.md) for sub-pixel edge alignment, [MS60](ms60.md) for aspect ratio verification and model sizing, and [MS61](ms61.md) for benchmark validation. It does not bypass MS55 plane coplanarity checks or invent physical paper dimensions.

## 3. Non-Negotiable Invariants

1. **Seed Point Spatial Containment:** A candidate quadrilateral is valid under click-guided mode if and only if the seed point lies strictly inside its convex perimeter (`cv2.pointPolygonTest(poly, (seed_x, seed_y), False) >= 0`) or within an adaptive proximity tolerance of 1.5% image diagonal.
2. **Deterministic Fallback Cascade:** If no valid quadrilateral contains or borders the seed point, the service returns explicit abstention (`detection_outcome: "not_found"`, `rejection_reasons: ["seed_point_outside_valid_boundary"]`). The system must never snap to an unrelated rectangle on another wall or floor.
3. **Preservation of Coordinate Contracts:** Seed coordinates sent by the client and corner points returned by the service must reside in the canonical normalized workspace image frame `[0.0, 1.0]` per MS54.
4. **Zero Metric Assumptions:** Localization from a click does not infer physical paper size (Short, A4, Long) or verify that the paper is coplanar with the opening. Physical format review (MS53/MS60) and plane confirmation (MS55) remain mandatory.
5. **Component and Token Reuse:** All UI adjustments must reuse existing Tailwind CSS design tokens, emerald/sky status badges, and presentation components in `src/components/` per BAN-UI-09.

## 4. Technical Design and Algorithmic Specification

### 4.1 Backend: Seed-Guided Contour Extraction Pipeline

The CV service implements a two-tier resolution strategy in `fastapi-service/paper_calibration.py`:

```text
Tier 1: Fast Proposal Spatial Query
  Input: image_bgr, seed_point (seed_x_px, seed_y_px)
  Check existing proposals from multi-mask candidate pipeline
  Filter: pointPolygonTest(candidate_poly, seed_point, measureDist=False) >= 0
  If match found with score >= MIN_CLICK_GUIDED_SCORE (0.72):
    Select best enclosing candidate
    Return candidate with reference_source = "click_guided"

Tier 2: Localized Seed-Based Adaptive Segmentation (Fallback if Tier 1 misses)
  Define dynamic ROI around seed_point:
    roi_width = clamp(0.35 * image_width, 160, 0.65 * image_width)
    roi_height = clamp(0.35 * image_height, 160, 0.65 * image_height)
    crop image around seed_point with boundary clamping
  Apply Local Contrast Enhancement:
    CLAHE (clipLimit=3.0, tileGridSize=(8, 8))
    Bilateral filter (d=7, sigmaColor=50, sigmaSpace=50) for edge-preserving smoothing
  Multi-Threshold Local Extraction:
    Local Otsu thresholding
    Local adaptive Gaussian thresholding (blockSize=25, C=4)
    Morphological gradient and Canny edge detection (low=20, high=70)
  Seed Connected Component / Flood-Fill:
    Flood-fill mask seeded at local (seed_x_roi, seed_y_roi) with loDiff=12, upDiff=12
    Extract external boundary of filled component
  Quadrilateral Approximation:
    approxPolyDP with adaptive epsilon: [0.015, 0.025, 0.035, 0.045] * perimeter
    Enforce 4 vertices, convexity (isContourConvex), and non-zero area
    Refine corners via _order_corners() and map back to canonical image frame
```

### 4.3 Frontend User Experience Flow

```text
1. User enters PaperDetectionConfirmationModal or FiducialPaperPickerModal.
2. If initial automatic detection abstained or selected the wrong rectangle:
   - User sees banner: "Automatic detection uncertain. Tap directly on the paper sheet to snap corners automatically."
   - A crosshair cursor is active over the image canvas.
3. User clicks / taps on the paper sheet:
   - A pulsing emerald circular ripple animates at the clicked coordinate.
   - Client sends seed coordinate to the analysis endpoint.
   - System receives snapped quadrilateral within 250ms.
4. Smooth corner pin animation:
   - Four numbered pins (1: Top-Left, 2: Top-Right, 3: Bottom-Right, 4: Bottom-Left) animate from the seed point outward to the detected corners.
   - An emerald translucent overlay highlights the snapped paper area.
5. User Review:
   - If corners align with the paper sheet: User clicks "Confirm Reference".
   - If one corner requires minor adjustment: User drags the specific pin; the 2.5x loupe activates seamlessly.
   - If the snap was completely incorrect: User clicks "Clear / Retake" or switches to full manual mode.
```

## 5. Step-by-Step Implementation Plan

1. **CV Backend Seed Localization Engine (`fastapi-service/paper_calibration.py`):**
   - Implement `_extract_seed_constrained_candidate(image_bgr, seed_px, proposals)` to evaluate enclosing polygons from existing proposals.
   - Implement `_extract_local_roi_candidate(image_bgr, seed_px)` using local CLAHE, adaptive thresholding, and seed-connected component extraction.
   - Integrate both helpers into `detect_paper_fiducial()` when `seed_point` is provided.
   - Tag successful results with `reference_source = "click_guided"`.

2. **API Endpoint Route & Schema Binding (`fastapi-service/main.py`):**
   - Update `POST /analyze-image` to accept optional `seed_x: float = Form(None)` and `seed_y: float = Form(None)`.
   - Add unit tests validating seed coordinate boundary clamping (`[0.0, 1.0]`) and non-finite number rejection.

3. **Frontend API Client (`src/lib/imageApi.ts` & `src/lib/visualization/paperReference.ts`):**
   - Update `analyzeImage()` to pass `seed_x` and `seed_y` in the multipart form payload when provided in options.
   - Add helper `requestClickGuidedPaperDetection(file, seedPoint, currentStandard)`.

4. **Modal Interaction & Visual Snapping (`src/features/visualization/components/`):**
   - Update `PaperDetectionConfirmationModal.tsx` and `FiducialPaperPickerModal.tsx` with an interactive "Tap to Snap" toggle.
   - Render click indicator ripple and animate corner pin transitions to newly detected coordinates.
   - Maintain full compatibility with existing 2.5x circular loupe and touch controls.

5. **Session State & Invalidation (`src/lib/visualization/visualizationSession.tsx`):**
   - Record `reference_source = "click_guided"` in calibration metadata.
   - Trigger proper calibration revision invalidation whenever a new seed point is tapped.

## 7. Risks and Mitigations

- **Risk: User clicks on the boundary line instead of the paper interior.**  
  *Mitigation:* The seed inclusion test checks both interior (`pointPolygonTest > 0`) and contour proximity with a small pixel buffer (`measureDist <= 12px`), preventing failure when tapping near the edge.
- **Risk: Low local contrast between white paper and white painted wall.**  
  *Mitigation:* Local CLAHE amplification with bilateral filtering enhances subtle edge gradients that are flattened by global thresholding. If edge contrast is truly zero, the system gracefully prompts manual loupe pinning without hanging.
- **Risk: Client sends rapid multiple clicks.**  
  *Mitigation:* Implement client-side debounce (300ms) and abort previous in-flight CV requests using standard `AbortController`.
