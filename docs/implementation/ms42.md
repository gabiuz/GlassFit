## 1. Authorized Requirement

In the GlassFit photo-based visualization workspace (`/visualize/[productId]/workspace`), clients customize and place 2D and 3D glass and aluminum fixtures (such as sliding windows, awning windows, casement doors, and shower enclosures) directly into photos of their actual physical rooms.

During room photo pre-flight and analysis (`PRD-F4`, `SDD-C3`), the FastAPI microservice executes YOLOv8 object segmentation, returning detected room furnishings and architectural elements (such as chairs, couches, dining tables, beds, refrigerators, and potted plants) with pixel-space bounding boxes and confidence scores in `spaceImageSession.objects`.

### 1.1 Current Behavior

1. In the current GlassFit production workspace (`ProductModelWorkspace.tsx`), detected objects are utilized solely within the "Object Aware Occlusion" accordion subsection (`PRD-F8`, lines 3531 to 3572), where users can toggle "Put Product Behind" to render segmented foreground masks in front of the 3D model.
2. If a customer drags, scales, or perspective-fits a window or door directly over an existing room obstacle (for example, placing a floor-to-ceiling glass sliding door over an existing couch, desk, or countertop), the system provides zero spatial collision feedback on the canvas.
3. Users only realize a product conflicts with existing fixtures after generating a quotation or upon consultation with an estimator, increasing revision cycles and site survey friction.

### 1.2 Reference Behavior in MVP (`glassfit-mvp`)

In `C:\Users\reyna\glassfit-mvp`:
1. `src/lib/placementWarnings.ts` evaluated bounding box intersections (`checkOverlap`) between the active overlay transform and `detectedObjects` from YOLOv8.
2. When overlap was detected, it returned warning objects:
   `{ id: 'overlap_...', level: 'caution', message: 'Placement overlaps a detected couch. The product may obstruct this object.', relatedObjects: ['couch'] }`.
3. The warning was rendered in `src/components/PlacementWarningPanel.tsx`, which was a collapsible container in the right-hand inspection sidebar.

### 1.3 Required Behavior

GlassFit requires an upgraded, spatial implementation of the obstruction advisory feature:

1. **Exact-Location On-Canvas Tooltip:**
   - The warning must not be buried inside an accordion or isolated in a distant sidebar.
   - A floating warning tooltip must appear on the canvas stage, anchored directly at the coordinate where the product model and the detected object intersect.
   - If multiple objects are obstructed, the tooltip anchors at the primary active intersection, or displays an indicator for the obstructed element.

2. **Non-Technical Single-Sentence Message:**
   - The message text must be short, plain-language, and easily understood by any homeowner or client without technical or architectural jargon.
   - Format: Exactly 1 concise sentence (e.g., "This product may overlap or block the couch in your room." or "This product might obstruct the detected table.").

3. **Dismissible via "X" Close Button:**
   - The tooltip must feature a visible, accessible close button ("x").
   - Clicking or keyboard-activating the close button dismisses the tooltip for that specific obstruction during the current editing interaction.
   - The dismissal does not permanently disable warnings if the user moves the product to obstruct a different object.

4. **Strict Soft-Warning Invariant (Zero Workflow Impact):**
   - The tooltip is purely informational (advisory).
   - It must never disable or block the "Add to Quote", "Apply Product", "Save Snapshot", "Confirm Dimensions", or "Send Booking" actions.
   - It requires no forced waiver, introduces no modal trap, and leaves quotation pricing and BOM calculations completely unaffected.

No database migration, backend microservice mutation, or new third-party dependency is authorized. This document is an implementation specification; no application code is to be executed or committed during planning.

## 4. Architectural, Geometric & Interaction Design

### 4.1 Coordinate Space Transformations

Let:
- $W_{img}, H_{img}$ be the natural dimensions of the uploaded photo (`workspaceImage.width`, `workspaceImage.height`).
- $W_{disp}, H_{disp}$ be the live display dimensions of the canvas element (`canvasDisplaySize.width`, `canvasDisplaySize.height`).
- Scale factors:
  $$S_x = \frac{W_{disp}}{W_{img}}, \quad S_y = \frac{H_{disp}}{H_{img}}$$

For a detected object with YOLO bounding box $B_{obj}^{raw} = [x_{min}, y_{min}, x_{max}, y_{max}]$:
$$B_{obj}^{disp} = [x_{min} \cdot S_x, \; y_{min} \cdot S_y, \; x_{max} \cdot S_x, \; y_{max} \cdot S_y]$$

For the active product overlay:
- If standard 2D placement:
  $$cx = \frac{W_{disp}}{2} + \text{overlayPosition.x}, \quad cy = \frac{H_{disp}}{2} + \text{overlayPosition.y}$$
  $$B_{ov}^{disp} = \left[cx - \frac{\text{overlaySize.width}}{2}, \; cy - \frac{\text{overlaySize.height}}{2}, \; cx + \frac{\text{overlaySize.width}}{2}, \; cy + \frac{\text{overlaySize.height}}{2}\right]$$
- If perspective-fitted:
  $$B_{ov}^{disp} = \left[\min_i(p_i.x \cdot W_{disp}), \; \min_i(p_i.y \cdot H_{disp}), \; \max_i(p_i.x \cdot W_{disp}), \; \max_i(p_i.y \cdot H_{disp})\right]$$

### 4.2 Bounding Box Collision & Intersection Centroid

Two bounding boxes $A = [x1_a, y1_a, x2_a, y2_a]$ and $B = [x1_b, y1_b, x2_b, y2_b]$ intersect if:
$$x1_a < x2_b \land x2_a > x1_b \land y1_a < y2_b \land y2_a > y1_b$$

When intersection occurs:
$$I = \left[\max(x1_a, x1_b), \; \max(y1_a, y1_b), \; \min(x2_a, x2_b), \; \min(y2_a, y2_b)\right]$$
$$\text{Width}_I = I.x2 - I.x1, \quad \text{Height}_I = I.y2 - I.y1$$
$$\text{Area}_I = \text{Width}_I \times \text{Height}_I$$

**Noise Filter Threshold:**
To avoid flashing warnings on incidental touch points, an obstruction is only flagged if:
$$\text{Area}_I \ge 400\text{ px}^2 \quad \text{and} \quad \min(\text{Width}_I, \text{Height}_I) \ge 12\text{ px}$$

**Anchor Point for Tooltip:**
The tooltip points directly at the top-center of the intersection zone:
$$X_{anchor} = \frac{I.x1 + I.x2}{2}, \quad Y_{anchor} = I.y1$$

### 4.3 Tooltip Boundary Clamping

To prevent tooltips from being clipped at the canvas perimeter or obscured by top/bottom toolbars:
- Tooltip dimensions (estimated/measured): $W_{tip} \approx 280\text{ px}, \; H_{tip} \approx 56\text{ px}$.
- Margin from canvas boundary: $M = 12\text{ px}$.
- Horizontal position:
  $$X_{clamped} = \text{clamp}\left(X_{anchor} - \frac{W_{tip}}{2}, \; M, \; W_{disp} - W_{tip} - M\right)$$
- Vertical position:
  - Default: Position above the intersection ($Y_{anchor} - H_{tip} - 12\text{ px}$).
  - If $Y_{anchor} - H_{tip} - 12 < M$: Position below the intersection ($I.y2 + 12\text{ px}$).
  - Final clamped coordinate:
    $$Y_{clamped} = \text{clamp}\left(Y_{computed}, \; M, \; H_{disp} - H_{tip} - M\right)$$

### 4.4 Non-Technical Message Formulation

Messages must be immediately understandable by everyday clients. Technical labels from COCO dataset are normalized into friendly conversational terms:

| COCO Label | User-Facing Object Term | Generated 1-Sentence Warning Message |
|---|---|---|
| `couch` / `sofa` | couch | This product may overlap or block the couch in your room. |
| `chair` | chair | This product may overlap or block the chair in your room. |
| `dining table` / `table` | table | This product may overlap or block the table in your room. |
| `bed` | bed | This product may overlap or block the bed in your room. |
| `potted plant` | plant | This product may overlap or block the plant in your room. |
| `refrigerator` | refrigerator | This product may overlap or block the refrigerator in your room. |
| `tv` / `television` | television | This product may overlap or block the television in your room. |
| `sink` | sink | This product may overlap or block the sink in your room. |
| Fallback / other | nearby object | This product may overlap or block a nearby object in your room. |

Message Guidelines:
- Strict maximum of 1 sentence.
- Zero jargon (no mention of "YOLO", "bounding box", "coordinate space", "intersection depth", or "segmentation mask").
- Clear, respectful advisory tone ("may overlap or block").

### 4.5 Tooltip Dismissal Lifecycle

1. When an obstruction is detected, the warning key is formed: `warningKey = `${detectedObject.id}``.
2. A state variable `dismissedObstructionKeys` (`Set<string>`) tracks warnings the user has closed.
3. If `dismissedObstructionKeys.has(warningKey)`, the tooltip for that object is suppressed.
4. If the user moves the product so that the overlap with that object drops to zero ($\text{Area}_I = 0$), `warningKey` is removed from `dismissedObstructionKeys`. If the user later drags the product back over that same object, the warning can re-appear.
5. If the user clicks the "X" button on the tooltip, `warningKey` is added to `dismissedObstructionKeys` and the tooltip fades out immediately.

### 4.6 Strict Soft-Warning Invariant

| Action | With Active Obstruction Tooltip | Without Obstruction Tooltip | Difference |
|---|---|---|---|
| Drag / scale / rotate product | Fully enabled | Fully enabled | None |
| Perspective fit ("Fit to Opening") | Fully enabled | Fully enabled | None |
| Add to Quote / Apply Product | Fully enabled | Fully enabled | None |
| Open Measurement Modal | Fully enabled | Fully enabled | None |
| Calculate BOM Price | Exact standard formula | Exact standard formula | None |
| Save Snapshot & Proceed | Fully enabled | Fully enabled | None |
| Send Consultation Booking | Fully enabled | Fully enabled | None |

The tooltip is visual feedback only. Under no circumstances does it prevent, disable, or gate any subsequent user action.

### 5.1 Obstruction Detection Utility (`src/lib/visualization/obstructionWarnings.ts`)

Create a dedicated, fully typed utility file:

```typescript
import type { DetectedObject, WorkspaceImage } from "@/lib/imageApi";

export interface CanvasBox {
  x1: number;
  y1: number;
  x2: number;
  y2: number;
}

export interface ObstructionCandidate {
  id: string;
  objectId: string;
  objectLabel: string;
  friendlyLabel: string;
  message: string;
  intersectionBox: CanvasBox;
  anchorPoint: {
    x: number;
    y: number;
  };
  overlapArea: number;
}

const LABEL_MAP: Record<string, string> = {
  couch: "couch",
  sofa: "couch",
  chair: "chair",
  table: "table",
  "dining table": "table",
  bed: "bed",
  "potted plant": "plant",
  refrigerator: "refrigerator",
  tv: "television",
  television: "television",
  sink: "sink",
  desk: "desk",
  countertop: "counter",
};

export function formatObstructionMessage(label: string): string {
  const normalized = label.trim().toLowerCase();
  const friendly = LABEL_MAP[normalized] || "nearby object";
  return `This product may overlap or block the ${friendly} in your room.`;
}

export function computeIntersectionBox(a: CanvasBox, b: CanvasBox): CanvasBox | null {
  const x1 = Math.max(a.x1, b.x1);
  const y1 = Math.max(a.y1, b.y1);
  const x2 = Math.min(a.x2, b.x2);
  const y2 = Math.min(a.y2, b.y2);

  if (x1 < x2 && y1 < y2) {
    return { x1, y1, x2, y2 };
  }
  return null;
}

export interface FindObstructionsParams {
  overlayBox: CanvasBox;
  detectedObjects: DetectedObject[];
  workspaceImage: WorkspaceImage;
  canvasDisplayWidth: number;
  canvasDisplayHeight: number;
  dismissedKeys?: Set<string>;
}

export function findObstructionWarnings({
  overlayBox,
  detectedObjects,
  workspaceImage,
  canvasDisplayWidth,
  canvasDisplayHeight,
  dismissedKeys,
}: FindObstructionsParams): ObstructionCandidate[] {
  if (
    !detectedObjects ||
    detectedObjects.length === 0 ||
    !workspaceImage ||
    workspaceImage.width <= 0 ||
    workspaceImage.height <= 0 ||
    canvasDisplayWidth <= 0 ||
    canvasDisplayHeight <= 0
  ) {
    return [];
  }

  const scaleX = canvasDisplayWidth / workspaceImage.width;
  const scaleY = canvasDisplayHeight / workspaceImage.height;

  const candidates: ObstructionCandidate[] = [];

  for (const obj of detectedObjects) {
    if (!obj.bbox || obj.bbox.length !== 4) continue;
    const warningKey = obj.id;
    if (dismissedKeys && dismissedKeys.has(warningKey)) continue;

    const [ox1, oy1, ox2, oy2] = obj.bbox;
    const objBox: CanvasBox = {
      x1: ox1 * scaleX,
      y1: oy1 * scaleY,
      x2: ox2 * scaleX,
      y2: oy2 * scaleY,
    };

    const intersection = computeIntersectionBox(overlayBox, objBox);
    if (!intersection) continue;

    const width = intersection.x2 - intersection.x1;
    const height = intersection.y2 - intersection.y1;
    const area = width * height;

    // Reject incidental touch points below 400 square pixels or 12px min dimension
    if (area < 400 || width < 12 || height < 12) {
      continue;
    }

    const anchorPoint = {
      x: (intersection.x1 + intersection.x2) / 2,
      y: intersection.y1,
    };

    const friendlyLabel = LABEL_MAP[obj.label.toLowerCase()] || obj.label.toLowerCase();

    candidates.push({
      id: warningKey,
      objectId: obj.id,
      objectLabel: obj.label,
      friendlyLabel,
      message: formatObstructionMessage(obj.label),
      intersectionBox: intersection,
      anchorPoint,
      overlapArea: area,
    });
  }

  // Sort descending by overlap area so the most significant obstruction takes priority
  return candidates.sort((a, b) => b.overlapArea - a.overlapArea);
}
```

### 5.2 Obstruction Warning Tooltip Component (`src/features/visualization/components/ObstructionWarningTooltip.tsx`)

Create the presentation component:

```tsx
"use client";

import React, { useMemo } from "react";
import type { ObstructionCandidate } from "@/lib/visualization/obstructionWarnings";

interface ObstructionWarningTooltipProps {
  warning: ObstructionCandidate;
  canvasWidth: number;
  canvasHeight: number;
  onDismiss: (warningId: string) => void;
}

export function ObstructionWarningTooltip({
  warning,
  canvasWidth,
  canvasHeight,
  onDismiss,
}: ObstructionWarningTooltipProps) {
  // Approximate tooltip dimensions for boundary clamping
  const tooltipWidth = 280;
  const tooltipHeight = 56;
  const margin = 12;

  const position = useMemo(() => {
    const rawX = warning.anchorPoint.x;
    const rawY = warning.anchorPoint.y;

    // Center tooltip on anchor point, clamped to canvas bounds
    const halfW = tooltipWidth / 2;
    const left = Math.max(margin, Math.min(canvasWidth - tooltipWidth - margin, rawX - halfW));

    // Place 12px above intersection point; if too close to top, place below intersection
    let top = rawY - tooltipHeight - 12;
    if (top < margin) {
      top = warning.intersectionBox.y2 + 12;
    }
    top = Math.max(margin, Math.min(canvasHeight - tooltipHeight - margin, top));

    return { left, top };
  }, [
    warning.anchorPoint.x,
    warning.anchorPoint.y,
    warning.intersectionBox.y2,
    canvasWidth,
    canvasHeight,
  ]);

  return (
    <div
      role="status"
      aria-live="polite"
      className="absolute pointer-events-auto z-30 select-none animate-in fade-in duration-200"
      style={{
        left: `${position.left}px`,
        top: `${position.top}px`,
        width: `${tooltipWidth}px`,
      }}
    >
      <div className="flex items-center gap-2.5 px-3 py-2.5 bg-[#0f1422]/95 text-white backdrop-blur-md rounded-[14px] shadow-lg border border-amber-500/40 text-xs">
        {/* Warning Icon Badge */}
        <div className="shrink-0 size-5 rounded-full bg-amber-500/20 text-amber-400 flex items-center justify-center font-bold text-[11px]">
          !
        </div>

        {/* 1-Sentence Non-Technical Message */}
        <p className="flex-1 text-neutral-200 leading-snug font-normal text-[11px]">
          {warning.message}
        </p>

        {/* Dismiss Close Button */}
        <button
          type="button"
          onClick={(e) => {
            e.stopPropagation();
            onDismiss(warning.id);
          }}
          aria-label="Close obstruction warning"
          className="shrink-0 size-5 rounded-full hover:bg-white/10 flex items-center justify-center text-neutral-400 hover:text-white transition-colors cursor-pointer"

            className="size-3"
            viewBox="0 0 12 12"
            fill="none"
            stroke="currentColor"
            strokeWidth="1.75"

            strokeLinejoin="round"
            aria-hidden="true"
          >
            <path d="M2.5 2.5l7 7M9.5 2.5l-7 7" />
          </svg>

      </div>
    </div>

}

       overlayBox: currentOverlayCanvasBox,
       detectedObjects: spaceImageSession.objects,
       workspaceImage: spaceImageSession.workspaceImage,
       canvasDisplayWidth: canvasDisplaySize.width,
       canvasDisplayHeight: canvasDisplaySize.height,
       dismissedKeys: dismissedObstructionKeys,
     });
   }, [
     currentOverlayCanvasBox,
     spaceImageSession?.objects,
     spaceImageSession?.workspaceImage,
     canvasDisplaySize.width,
     canvasDisplaySize.height,
     dismissedObstructionKeys,
   ]);

   const primaryObstructionWarning = activeObstructionWarnings[0] ?? null;
   ```

4. **Dismiss Handler & Auto-Reactivation:**
   ```typescript
   const handleDismissObstruction = useCallback((warningId: string) => {
     setDismissedObstructionKeys((prev) => new Set([...prev, warningId]));
   }, []);

   // When overlay moves completely away from an object, un-dismiss it
   useEffect(() => {
     if (!currentOverlayCanvasBox || dismissedObstructionKeys.size === 0) return;
     if (!spaceImageSession?.objects || !spaceImageSession.workspaceImage) return;

     const allCurrentOverlaps = findObstructionWarnings({
       overlayBox: currentOverlayCanvasBox,
       detectedObjects: spaceImageSession.objects,
       workspaceImage: spaceImageSession.workspaceImage,
       canvasDisplayWidth: canvasDisplaySize.width,
       canvasDisplayHeight: canvasDisplaySize.height,
       dismissedKeys: new Set(), // pass empty to see raw overlaps
     });

     const currentOverlappingObjectIds = new Set(allCurrentOverlaps.map((w) => w.id));

     setDismissedObstructionKeys((prev) => {
       let changed = false;
       const next = new Set<string>();
       for (const key of prev) {
         if (currentOverlappingObjectIds.has(key)) {
           next.add(key);
         } else {
           changed = true; // Object is no longer overlapping; forget dismissal
         }
       }
       return changed ? next : prev;
     });
   }, [
     currentOverlayCanvasBox,
     spaceImageSession?.objects,
     spaceImageSession?.workspaceImage,
     canvasDisplaySize.width,
     canvasDisplaySize.height,
     dismissedObstructionKeys.size,
   ]);
   ```

5. **JSX Placement in Canvas Container:**
   Render immediately inside the canvas wrapper (adjacent to perspective toolbars, before gizmo controls):
   ```tsx
   {primaryObstructionWarning && isEditingProduct && (
     <ObstructionWarningTooltip
       warning={primaryObstructionWarning}
       canvasWidth={canvasDisplaySize.width}
       canvasHeight={canvasDisplaySize.height}
       onDismiss={handleDismissObstruction}
     />
   )}
   ```

## 6. Security, Performance, and Non-Blocking Invariant Guarantees

### 6.1 Strict Non-Blocking Workflow Invariant

The obstruction tooltip is categorized as an informational assistance signal:
1. It does not set any error flag in `VisualizationSessionState`.
2. It does not modify BOM pricing, hardware selections, or structural dimensions.
3. The "Save Snapshot" and "Add to Quote" handlers do not check `activeObstructionWarnings`.
4. It does not appear in export snapshots, quotation PDFs, or consultation booking messages.
5. Clients retain full autonomy to proceed even if an obstruction is flagged (for example, if the client plans to move the furniture out of the room before glass installation).

### 6.2 Rendering Performance & Computation Budget

- Bounding box collision uses simple scalar comparisons ($O(N)$, where $N \le 10$ detected objects).
- Total execution time is under $0.05\text{ ms}$ per frame, executing synchronously during standard React render passes without dragging latency or frame drops.
- Tooltip container uses GPU-accelerated CSS positioning (`left`, `top`) and does not re-render the Three.js 3D canvas.

### 6.3 Accessibility & WCAG Compliance

- Tooltip uses `role="status"` with `aria-live="polite"` so screen readers announce the warning without interrupting user speech.
- Close button has an explicit accessible label: `aria-label="Close obstruction warning"`.
- Contrast ratio between `#0f1422` slate surface, amber badge, and white text exceeds $4.5:1$, satisfying WCAG 2.1 Level AA requirements.
- The button can be focused via Tab and triggered with Enter or Space keys.
