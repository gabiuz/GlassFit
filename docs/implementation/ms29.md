## 1. Problem Context & Defect Catalog

### 1.1 Product Update Card: "View All" Overlap on Small Screens

**Affected file:** [`src/features/admin/components/ProductUpdates.tsx`](file:///d:/Developer/GlassFit/src/features/admin/components/ProductUpdates.tsx)

On the admin dashboard, the Product Update card header renders "Product Update" and a "View All" link in a single flex row with `justify-between`. At narrow viewport widths (below approximately 360px logical width), the two elements collide because:

- The heading uses `text-xl sm:text-2xl` and `whitespace-nowrap`.
- The "View All" link uses `whitespace-nowrap`.
- The parent row applies a fixed `gap-4` but no `flex-wrap` or `min-w-0` overflow strategy.

When the combined intrinsic width of both elements exceeds the card's padded content area, the "View All" link visually overlaps the heading text.

### 1.2 Admin Sidebar: Disappears on Long Page Scroll

**Affected files:**
- [`src/components/ui/AdminLayout.tsx`](file:///d:/Developer/GlassFit/src/components/ui/AdminLayout.tsx)
- [`src/components/ui/adminSidePanel.tsx`](file:///d:/Developer/GlassFit/src/components/ui/adminSidePanel.tsx)

On long content pages (such as the admin dashboard with multiple analytics cards, the bookings list with numerous requests, or the product catalog), scrolling down previously caused the sidebar navigation buttons to scroll out of view. In a sticky positioning model, when the layout container or viewport boundaries scroll, the sidebar elements could also slide underneath the sticky header or reach scroll boundaries.

The admin requires the sidebar navigation buttons ("Dashboard", "Product", "Raw Materials", "Booking", "Staff Accounts", "Settings") to remain permanently fixed and immediately accessible at all times, no matter how deep the user scrolls into page content.

### 1.3 Bookings Page: Unnecessary Refresh Button

**Affected file:** [`src/features/admin/bookings/BookingsContent.tsx`](file:///d:/Developer/GlassFit/src/features/admin/bookings/BookingsContent.tsx)

The Booking Request page header contained a teal refresh button that triggered `router.refresh()` via `handleManualRefresh`. This button is unnecessary because:

- Every mutation in the bookings page (status change, price negotiation, labor fee update) already calls `router.refresh()` after completion.
- The data is server-rendered on page load and refreshes automatically on navigation.
- The button consumes valuable header space alongside the search bar.

## 2. Implementation Plan

### 2.1 Fix: Product Update Card Responsive Header

**Target file:** [`src/features/admin/components/ProductUpdates.tsx`](file:///d:/Developer/GlassFit/src/features/admin/components/ProductUpdates.tsx)

1. Add `min-w-0` to the heading `<h2>` so it can shrink below its intrinsic width inside the flex row.
2. Replace `whitespace-nowrap` on the heading with `truncate` to gracefully clip the title when space is constrained, while keeping the "View All" link always fully visible.
3. Add `shrink-0` to the "View All" `<Link>` to prevent the link from being compressed; it must always remain fully readable and tappable.

### 2.2 Fix: Fixed Admin Sidebar on Desktop

**Target files:**
- [`src/components/ui/adminSidePanel.tsx`](file:///d:/Developer/GlassFit/src/components/ui/adminSidePanel.tsx)
- [`src/components/ui/AdminLayout.tsx`](file:///d:/Developer/GlassFit/src/components/ui/AdminLayout.tsx)

**Layout mechanics:**

1. **Desktop spacer in document flow:** Render a `<div className="hidden lg:block w-[300px] shrink-0" aria-hidden="true" />` inside `AdminSidePanel`. This reserves the 300px sidebar column width in the normal flex layout so the adjacent content container naturally starts at the correct horizontal position.
2. **Fixed viewport pinning:** Apply `lg:fixed lg:top-[106px] lg:left-0 lg:w-[300px] lg:h-[calc(100vh-106px)] lg:z-20 lg:overflow-y-auto` to the `<aside>` element. The sidebar is anchored exactly below the 106px sticky `AdminNavbar`, spans to the bottom of the viewport, and never moves when the admin scrolls through long pages.
3. **Internal scrollability:** The `overflow-y-auto` rule ensures that on compact vertical viewports, the sidebar can scroll independently within its fixed container without displacing the main layout.
4. **Mobile drawer preservation:** On mobile (`<lg`), the spacer remains `display: none` (`hidden`), and the `<aside>` maintains its existing full-height overlay drawer behavior with `fixed top-0 left-0 z-50 h-full` and slide transitions controlled by `isOpen`.

### 2.3 Fix: Remove Bookings Refresh Button

**Target file:** [`src/features/admin/bookings/BookingsContent.tsx`](file:///d:/Developer/GlassFit/src/features/admin/bookings/BookingsContent.tsx)

1. Remove the `RefreshCw` import from `lucide-react`.
2. Remove `handleManualRefresh` and prune unused `isRefreshing` from `useTransition()`.
3. Remove the `<button>` element for the manual refresh control.
4. Flatten the search bar wrapper so [`SearchBar`](file:///d:/Developer/GlassFit/src/components/shared/SearchBar.tsx) is a direct child of the header row with responsive width classes.
