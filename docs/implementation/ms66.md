## 1. Outcome and Scope

In the current GlassFit client-space visualization flow (`/visualize/[productId]` and `src/features/visualization/components/ProductModelWorkspace.tsx`), customers position and scale customized 3D glass and aluminum products against real photos of their home or commercial space. Customers can calibrate scale, adjust aperture width and height, modify yaw and pitch, remove optional bottom sills, and review quotation pricing.

However, all 3D product models in the workspace currently render with hardcoded, immutable default materials. Customers cannot choose alternative finishes or glass varieties. When a customer prefers Powder Coated White aluminum over dark Analok bronze, or requires safety-grade 6mm Tempered glass instead of standard annealed float glass, they have no means to:
1. **Visualize Alternative Finishes in Their Space:** See how different framing colors (Analok bronze, Powder Coated White, Mill aluminum) or glass tints (Clear Float, Tinted Bronze, Tempered) harmonize with their interior wall paint, floor tiles, and ambient room lighting.
2. **Observe Real-Time Cost Impact:** Understand the immediate price differential between basic and premium materials before booking an on-site ocular inspection, eliminating quotation surprises and post-consultation design abandonment.
3. **Persist Selections Through Quotation & Booking:** Ensure that customized material choices flow seamlessly into the Quotation Measurement Modal (`MeasurementConfirmationModal.tsx`), immutable quotation snapshots (`quotation_estimates`, `quotation_items`), and the downloadable Consultation PDF handoff document.

`IMP-MS66` delivers this complete customer-facing customization lifecycle:
- **Admin-Gated Material Customizer UI:** Exposes a sleek, accessible "Finishes & Materials" selector panel in the workspace. Customization options appear strictly when an administrator has configured multiple candidate materials for that product's components (per `IMP-MS64`). If only one material was configured, the selector gracefully displays the fixed specification without redundant interaction.
- **Client-Friendly Grouping:** Intelligently rolls up component-level materials into intuitive client-facing finish groups (e.g., "Aluminum Frame Finish" and "Glass Infill Option"), avoiding overwhelming the customer with 10 separate component dropdowns.
- **Real-Time Three.js PBR Shader Swapping:** Updates 3D mesh surface appearance dynamically on the user's room photo canvas, modifying color, metallic reflection, roughness, glass transmission, and tint opacity without disturbing perspective alignment or foreground occlusion masks.
- **Live HUD & Dock Price Synchronization:** Runs `calculateParametricBOM` client-side whenever the customer changes materials, updating the workspace bottom dock total, floating HUD badge, and variation snapshot recipes in real time.
- **End-to-End Quotation & PDF Parity:** Passes customer-selected material IDs into the quotation modal, itemized BOM line items, Supabase persistence layer (`product_configurations` and `quotation_items.pricing_details`), and the consultation PDF handoff.

## 3. Non-Negotiable Invariants

1. **Strict Admin Configuration Gating:** Customers are strictly restricted to choosing among raw materials that the administrator explicitly checked in Step 4 (`product_component_materials`). If an admin configured only a single material for a component or group, no interactive selector is rendered for that category.
2. **Zero Distortion of Scene Realism & Occlusion:** Material swaps must never trigger scene re-renders that reset the camera, clear the canvas, invalidate 4-point homography fits, or corrupt SegFormer ADE20K foreground occlusion masks.
3. **Instantaneous Price Feedback:** Switching any material option must update the floating HUD price tag and bottom dock total in under 50 milliseconds via client-side `calculateParametricBOM`.
4. **Frozen Quotation Provenance:** Once a quotation estimate is generated and confirmed, the selected material IDs, material codes, finish descriptions, and exact unit rates must be permanently frozen into `quotation_items.pricing_details`. Future changes to raw material prices in the admin catalog must never alter historical quotation snapshots.
5. **Clean Mobile & Desktop Responsiveness:** The material customizer must render as a docked side drawer on desktop viewports (>= 1024px) and as a thumb-safe swipeable bottom sheet on mobile screens (< 1024px) conforming to `DSD-UI4` and `DSD-UI15`.
6. **Design Token Parity:** All buttons, swatches, pills, and typography must reuse established Tailwind CSS tokens from `src/app/globals.css` (`rounded-[16px]`, `border-[#07b6d3]`, slate backgrounds) per `BAN-UI-09`.
7. **No Em-Dashes:** In compliance with `BAN-PUNCT-01`, all user-facing labels, option descriptions, tooltips, and code comments must use hyphens, colons, or parentheses. Never use em-dashes.
8. **Strict Type Safety:** Zero usage of `any` across TypeScript interfaces, hooks, and props per `BAN-TYPE-05`.

## 4. Technical Design & Data Architecture

### 4.1 Customer Material State Model

In `src/features/visualization/components/ProductModelWorkspace.tsx`:

```typescript
// ComponentKey -> RawMaterialId
export type CustomerMaterialSelections = Record<string, string>;

export interface MaterialCustomizationGroup {
  groupId: string;
  groupLabel: string; // e.g. "Aluminum Frame Finish", "Glass Infill Option"
  presentationCategory: "Framing" | "Glazing" | "Hardware";
  affectedComponentKeys: string[];
  options: Array<{
    materialId: string;
    materialCode: string;
    description: string;
    finishType: string;
    unitPrice: number;
    billingUnit: string;
    isDefault: boolean;
    swatchColor?: string;
    priceDeltaTotal: number; // In Philippine Pesos relative to default
  }>;
  selectedMaterialId: string;
}
```

### 4.2 Grouping & Rollup Heuristics

To prevent overwhelming customers with dozens of individual part selectors, the workspace aggregates candidate materials into intuitive consumer groups:

1. **Framing Group ("Aluminum Frame Finish"):**
   - Combines all components with `presentationCategory === "Framing"` (Head, Sill, Jambs, Rails, Stiles).
   - Finds common finish options shared across all framing components (e.g., Analok vs Powder Coated White).
   - Selecting a framing finish applies it across all framing components in that assembly.
2. **Glazing Group ("Glass Infill Option"):**
   - Combines all components with `presentationCategory === "Glazing"` (Sliding Glass, Fixed Glass).
   - Exposes glass options (e.g., 6mm Clear Float vs 6mm Tinted Bronze vs 6mm Tempered).
3. **Hardware Group ("Hardware & Accessories" - Optional):**
   - Only exposed if alternative hardware choices exist (e.g., Standard vs Heavy Duty Rollers).
4. **Individual Part Override Mode (Advanced):**
   - If an admin specifically marked parts with divergent material choices, an expandable "Advanced Part Finishes" accordion allows fine-grained per-part selection.

### 4.3 Three.js PBR Shader Swapping on Room Photo

When a customer switches a finish in `ProductModelWorkspace.tsx`:
1. The workspace passes the updated `selectedMaterials` map to the 3D model container.
2. The model traverse function identifies target meshes:
   ```typescript
   threeGroup.traverse((child) => {
     if (child instanceof THREE.Mesh && child.userData.componentKey) {
       const matId = selectedMaterials[child.userData.componentKey];
       const rawMat = rawMaterialsMap.get(matId);
       if (rawMat) {
         const pbr = resolvePBRProperties(rawMat);
         if (child.material instanceof THREE.MeshPhysicalMaterial || child.material instanceof THREE.MeshStandardMaterial) {
           child.material.color.copy(pbr.color);
           child.material.metalness = pbr.metalness;
           child.material.roughness = pbr.roughness;
           if (pbr.transmission !== undefined && child.material instanceof THREE.MeshPhysicalMaterial) {
             child.material.transmission = pbr.transmission;
             child.material.opacity = pbr.opacity ?? 1.0;
             child.material.transparent = pbr.transparent ?? false;
             child.material.ior = pbr.ior ?? 1.52;
           }
           child.material.needsUpdate = true;
         }
       }
     }
   });
   ```
3. Canvas invalidates and re-renders one frame. Camera matrix, perspective homography, and occlusion overlays remain strictly untouched.

### 4.4 Quotation Modal & Relational Persistence Integration

When the user opens `MeasurementConfirmationModal.tsx`:
1. Modal receives:
   - `dimensions`: `{ widthMm, heightMm }`
   - `selectedMaterials`: `CustomerMaterialSelections`
   - `rawMaterials`: `RawMaterial[]`
2. Modal constructs `ComponentPricingInput[]` with overridden materials and calculates `calculateParametricBOM`.
3. When confirmed, writes to Supabase:
   - `product_configurations.configuration_data`:
     ```json
     {
       "width_mm": 1800,
       "height_mm": 1500,
       "has_sill": true,
       "selected_materials": {
         "head_profile": "d4e2...",
         "sill_profile": "d4e2...",
         "sash_rail": "d4e2...",
         "glass_pane": "f8a1..."
       }
     }
     ```
   - `quotation_items`:
     ```json
     {
       "quotation_id": "...",
       "item_group_name": "Aluminum Framing",
       "pricing_details": {
         "material_code": "mat_al_798_head_pcw",
         "finish_type": "PowderCoatedWhite",
         "unit_price": 105.00,
         "waste_factor": 0.12,
         "computed_qty": 1.8,
         "subtotal": 211.68
       }
     }
     ```

## 5. UI & Interaction Specification (Customer Workspace & Quotation)

A collapsible floating drawer anchored on the right edge of the canvas:
- Header: "Finishes & Materials" with collapse/expand chevron.

  - **Frame Finish Section:**
    - Title: "Frame Finish"

  - **Glass Option Section:**
    - Title: "Glazing Option"
    - Swatch cards:
      - Clear Float: Translucent cyan tint, label "6mm Clear Float", badge `Included`.
      - Tinted Bronze: Warm amber translucent tint, label "6mm Tinted Bronze", badge `+₱650`.
      - Safety Tempered: Clear glass with safety shield badge, label "6mm Safety Tempered", badge `+₱2,100`.
- Footer:
  - Live Total Price Tag: `PHP 15,480.00`
  - Subtext: "Estimated fabrication price based on your selected finishes."

#### Mobile Layout (< 1024px)
A thumb-safe floating bottom pill:
- Pill Button: `[ Pallette Icon ] Finishes (Analok / Clear) - ₱14,200`
- Tapping opens a swipeable modal bottom sheet with drag handle, large tap targets (minimum 48px height), and high contrast typography conforming to WCAG 2.1 AA.

### 5.2 Measurement Confirmation Modal Update (`DSD-UI7`)

In `MeasurementConfirmationModal.tsx`:
1. **Selected Specification Card:**
   - Displays a clean visual summary of the chosen options:
     - "Frame Finish: Powder Coated White (Premium Finish)"
     - "Glass Infill: 6mm Clear Safety Tempered Glass"
     - "Dimensions: 1,800 mm (W) x 1,500 mm (H)"
2. **Itemized BOM Summary Table:**
   - Displays line items reflecting the chosen materials, their exact unit rates, waste allowances, and calculated subtotals.
   - Price differences from the default configuration are transparently itemized.

### 5.3 Consultation PDF Handoff Document Update

In the generated Consultation PDF document:
1. Product title is appended with the selected finish: e.g., `Series 798 2-Panel Sliding Window (Powder Coated White / Tempered Glass)`.
2. Specifications box includes explicit bullets:
   - Framing: Series 798 Architectural Extrusion - Powder Coated White
   - Glazing: 6mm Safety Tempered Clear Glass
   - Aperture: 1800 mm x 1500 mm
3. Total estimated price matches the workspace and quotation modal to the exact centavo.

## 7. Implementation Sequence

1. **Workspace Material State & Rollup Helper:**
   - In `src/features/visualization/`, create `src/lib/visualization/materialCustomization.ts` to group component materials into client-friendly finish categories.
2. **Build Workspace Finishes & Materials Panel:**
   - Create `src/features/visualization/components/MaterialCustomizerPanel.tsx` supporting desktop side drawer and mobile bottom sheet modes.
3. **Connect Real-Time 3D Shading in Workspace:**
   - In `ProductModelWorkspace.tsx`, connect `selectedMaterials` state to the active Three.js parametric model using `resolvePBRProperties`.
4. **Wire Real-Time HUD and Dock Price Calculation:**
   - Ensure `calculateParametricBOM` runs client-side whenever `selectedMaterials` changes, updating `PlacedOverlay.pricingSummary`.
5. **Update Measurement Confirmation Modal:**
   - Update `MeasurementConfirmationModal.tsx` to render customer-chosen materials and pass them to quotation submission actions.
6. **Update Quotation Persistence and Consultation PDF:**
   - Ensure server actions freeze `selected_materials` into `product_configurations` and `quotation_items.pricing_details`.
   - Update PDF consultation handoff generator to print selected finish names and specifications.
7. **Automated Testing & Static Verification:**
   - Create unit tests in `tests/unit/customerMaterialCustomization.test.ts` verifying grouping heuristics, pricing parity, and persistence payloads.
   - Run static checks: `npx tsc --noEmit`, `npm run lint`, `npm run build`.
