## 1. Outcome and Scope

When administrators upload a window security grille model in `/admin/products/[productId]/setup` (either as an add-on or a standalone architectural grille), the center grille infill consists of dozens of repeating structural metal elements: vertical pickets, continuous horizontal divider rails, or staggered horizontal ties.

Under the previous administrative workflow:
1. Decomposing the 3D model produced 20 to 50 individual sub-mesh nodes. The administrator was forced to manually click and map every single bar to assign materials and dimension drivers.
2. If the administrator avoided manual mapping by keeping the center grille as a single combined mesh, the system only offered `dimensionBinding = "AREA"`. This multiplied overall width by height (sqm) against a flat rate, which completely distorted pricing because grilles are made of linear profile tubes billed per linear meter (PHP/m).

`IMP-MS72` eliminates this administrative bottleneck:
- **`GRILLE_LINEAR` Dimension Binding:** Extends `DimensionBinding` enum to formally include `"GRILLE_LINEAR"`. Components mapped with this binding automatically interface with the linear grille pricing engine developed in `IMP-MS71`.
- **Single-Click Center Grille Material Assignment:** In `PartInspectorDrawer.tsx`, selecting the single "Center Grille" component allows the administrator to choose ONE raw material extrusion (e.g. "16mm x 16mm Square Tube Powder Coated White @ ₱165.00/m"). The system automatically binds this material across all constituent vertical and horizontal bars without requiring one-by-one part selection.
- **Automated Filename & Component Auto-Detection:** Updates `autoDetection.ts` so that uploaded files or 3D scene nodes named `center_grille`, `grill_bars`, `grill_middle`, `grille_infill`, `middle_bars`, `picket_lattice`, or `grill_assembly` are automatically recognized as `dimensionBinding: "GRILLE_LINEAR"`, categorized as `"Framing"`, and linked to linear extrusion raw materials.
- **Live 3D Bar Breakdown Card in Part Inspector:** When inspecting a grille component, the drawer renders a real-time analysis card displaying:
  - Detected pattern topology (Grid, Horizontal Louvers, Staggered Brick, or Custom 3D Mesh).
  - Vertical bar count, individual cut length, and total vertical linear meters.
  - Horizontal bar count, individual cut length, and total horizontal linear meters.
  - Instant direct material cost preview at the baseline aperture size.
- **Interactive Linear Cut List in Validation Sandbox (Step 4 / Step 6):** Embeds an interactive cut list and BOM table inside `ValidationWorkspaceSection.tsx`. As the administrator tests dimensional sliders (600mm to 2400mm width and height), the table updates in real time (< 16ms), demonstrating dynamic pattern repetition and accurate per-piece per-meter cost calculation before catalog publication.

## 3. Non-Negotiable Invariants

1. **Zero One-by-One Bar Mapping Invariant:** The administrative setup workflow must NEVER require an administrator to click, map, or assign materials to individual repeating grille bars. A single selection of the "Center Grille" component must configure the entire internal bar network.
2. **Linear Meter Billed Units Only:** When a component is configured with `dimensionBinding = "GRILLE_LINEAR"`, only raw materials with `billing_unit = "m"` (linear meter) may be bound as primary extrusion profiles. Area-billed (`sqm`) or piece-billed (`pc`) materials must be filtered out or flagged with a validation warning.
3. **Bi-Directional Dimension Sensitivity:** If the administrator adjusts either width or height in the validation sandbox, the dynamic grille calculation must instantly reflect changes in both horizontal bar counts/lengths and vertical bar counts/lengths.
4. **Strict Design Token Adherence:** All new UI elements in `PartInspectorDrawer.tsx` and `ValidationWorkspaceSection.tsx` must reuse existing design tokens from `src/app/globals.css` (`rounded-[16px]`, `rounded-[20px]`, `border-[#c3c3c3]`, `bg-[#0f1422]`, `text-[#07b6d3]`) per `BAN-UI-09`.
5. **Zero Em-Dashes:** All drawer headers, tooltips, validation messages, and code comments must strictly avoid em-dashes per `BAN-PUNCT-01`. Use hyphens, colons, or parentheses.
6. **Strict Type Safety:** Zero usage of `any` across TypeScript interfaces, component props, and state hooks per `BAN-TYPE-05`.

## 4. Technical Design & Component Architecture

### 4.1 Schema Mutation & Dimension Binding Extension (`src/lib/pricing/types.ts`)

Extend `DimensionBinding` to include `"GRILLE_LINEAR"`:

```typescript
export type DimensionBinding =
  | "WIDTH"
  | "HEIGHT"
  | "AREA"
  | "FIXED"
  | "GRILLE_LINEAR"; // Specialized linear meter engine for repeating grille bars
```

In `supabase/migrations/006_grille_linear_dimension_binding.sql`:

```sql
-- Migration: Add GRILLE_LINEAR to product_components dimension_binding check constraint
ALTER TABLE public.product_components
  DROP CONSTRAINT IF EXISTS product_components_dimension_binding_check;

ALTER TABLE public.product_components
  ADD CONSTRAINT product_components_dimension_binding_check
  CHECK (dimension_binding IN ('WIDTH', 'HEIGHT', 'AREA', 'FIXED', 'GRILLE_LINEAR'));
```

### 4.2 Auto-Detection Enhancements (`src/lib/admin/products/autoDetection.ts`)

Update `autoDetectComponentSettings()` to recognize grille center infills:

```typescript
// Grille middle bars, center infill, pickets, lattices, and louvers
if (
  name.includes("center_grille") ||
  name.includes("middle_bars") ||
  name.includes("grill_middle") ||
  name.includes("grill_bars") ||
  name.includes("grille_infill") ||
  name.includes("picket") ||
  name.includes("lattice") ||
  (name.includes("grill") && !name.includes("frame") && !name.includes("jamb") && !name.includes("rail")) ||
  (name.includes("grille") && !name.includes("frame") && !name.includes("jamb") && !name.includes("rail"))
) {
  return {
    dimensionBinding: "GRILLE_LINEAR",
    spanRatio: 1.0,
    isRemovable: false,
    togglePropertyKey: null,
    presentationCategory: "Framing",
    componentType: "Frame",
    suggestedMaterialCategory: "Aluminum",
  };
}
```
