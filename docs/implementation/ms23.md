## 1. Executive Summary & Problem Context

Architectural glass and aluminum installations (such as Series 798 3-panel sliding windows, heavy-duty awning windows, frameless shower enclosures, and floor-to-ceiling office partitions) are multi-faceted products. A single static thumbnail photo cannot convey the interior perspective, exterior profile view, hardware locking mechanisms, or corner joint details of a fixture.

### 1.1 The Current Single-Image Bottleneck
Under the existing implementation:
1. **Administrative Upload Restriction:**  
   In `CatalogAssetsSection.tsx`, the component state maintains a single `imageAsset` object. The HTML file input accepts only a single file (`multiple` is absent).
2. **Aggressive Server-Side Asset Deactivation:**  
   In `src/lib/admin/products/assetUpload.ts` (`confirmAssetUpload`), the server action executes an unconditional deactivation query:
   ```typescript
   await supabase
     .from("product_assets")
     .update({ status: "Inactive", is_primary: false })
     .eq("product_id", productId)
     .eq("asset_type", assetType)
     .eq("status", "Active");
   ```
   Uploading a new image automatically deactivates all previously uploaded images for that product.
3. **Customer Catalog Single-Image Restriction:**  
   The customer catalog data layer (`getActiveProducts.ts` and `getProductById.ts`) retrieves only the single asset marked with `is_primary = true`. The presentation components (`ProductCard.tsx` and `ProductDetails.tsx`) accept only a single `imageUrl` string, rendering a static photo with no pagination or navigation capability.

### 1.2 The Business and User Experience Need
To showcase fabrication quality and allow prospective customers to thoroughly inspect fixtures before booking a consultation:
- Administrators need the ability to upload a batch of high-resolution product photographs (e.g. front view, side profile, hardware close-up, and installed room shot).
- Both administrative staff and prospective customers need an intuitive, fluid carousel navigation interface. The user requirement dictates that images must be navigable using left and right arrow buttons that behave like an infinite marquee: there should be **no hard left or right boundaries** (no disabled arrows). When a user reaches the last image, clicking the right arrow loops back to the first image; clicking the left arrow on the first image wraps around to the last image.
- The multi-image experience must reflect seamlessly across all client touchpoints: the admin setup wizard, the public product catalog cards (`ProductCard.tsx`), and the detailed product inspector (`ProductDetails.tsx`).

## 3. Database Schema & Persistence Architecture

### 3.1 Relational Architecture in `public.product_assets` (`ERD-E8`)
Inspection of `supabase/migrations/complete_schema.sql` (lines 592 to 614 and 1132 to 1136) reveals that the database schema was intentionally designed to support multi-asset ordering:
- `display_order integer DEFAULT 1 NOT NULL`: Constrained by `CHECK (display_order >= 1)`.
- `is_primary boolean DEFAULT false NOT NULL`: Indicates the main product thumbnail.
- `product_assets_product_order_idx`: `CREATE INDEX ON product_assets (product_id, display_order) WHERE (status = 'Active')`.
- `product_assets_one_primary_per_type_idx`: `CREATE UNIQUE INDEX ON product_assets (product_id, asset_type) WHERE (is_primary = true AND status = 'Active')`.

### 3.2 Relational Invariant Rules
To satisfy the unique partial index `product_assets_one_primary_per_type_idx` while storing multiple active images:
1. **The Single-Primary Invariant:** Exactly **one** active asset per product with `asset_type = 'Catalog Image'` may have `is_primary = true`. This represents the cover thumbnail displayed in search results and initial card loads.
2. **The Non-Primary Gallery Invariant:** All other active catalog images for that product must have `is_primary = false`.
3. **Sequential Display Order:** Active images must have distinct, positive `display_order` integers (`1, 2, 3, ... N`). When an image is deleted, remaining images automatically re-index sequentially to maintain continuous ordering.
4. **Primary Reassignment on Deletion:** If the primary image (`is_primary = true`) is removed by the administrator, the image with the lowest remaining `display_order` is automatically promoted to `is_primary = true`.

### 3.3 Server Action Refactoring (`src/lib/admin/products/assetUpload.ts`)
The server actions must be enhanced with non-destructive multi-image methods:

```typescript
export interface MultiAssetUploadItem {
  assetId: string;
  objectKey: string;
  fileName: string;
  mimeType: string;
  byteSize: number;
  displayOrder: number;
  isPrimary: boolean;
}

export async function confirmCatalogImageBatch(
  productId: string,
  newAssets: MultiAssetUploadItem[]
): Promise<CatalogAssetRecord[]> {
  const adminCtx = await requirePermission("manage_products");
  const supabase = await createSupabaseServerClient();

  // 1. Fetch existing active catalog images to calculate display orders
  const { data: existingAssets } = await supabase
    .from("product_assets")
    .select("asset_id, display_order, is_primary")
    .eq("product_id", productId)
    .eq("asset_type", "Catalog Image")
    .eq("status", "Active")
    .order("display_order", { ascending: true });

  const currentCount = existingAssets?.length || 0;
  const hasExistingPrimary = existingAssets?.some((a) => a.is_primary) || false;

  // 2. Prepare insert payloads with continuous display_order
  const insertPayloads = newAssets.map((item, index) => {
    const isFirstOverall = !hasExistingPrimary && index === 0;
    return {
      asset_id: item.assetId,
      product_id: productId,
      created_by: adminCtx.profileId,
      updated_by: adminCtx.profileId,
      asset_type: "Catalog Image",
      r2_object_key: item.objectKey,
      file_name: item.fileName,
      mime_type: item.mimeType,
      byte_size: item.byteSize,
      display_order: currentCount + index + 1,
      is_primary: isFirstOverall ? true : item.isPrimary && !hasExistingPrimary,
      status: "Active",
    };
  });

  const { data, error } = await supabase
    .from("product_assets")
    .insert(insertPayloads)
    .select();

  if (error) {
    console.error("Failed to batch insert catalog images:", error);
    throw new Error(error.message);
  }

  revalidatePath(`/admin/products/${productId}/setup`);
  revalidatePath("/product");
  revalidatePath(`/product-details/${productId}`);

  return data as CatalogAssetRecord[];
}

export async function setPrimaryCatalogImage(
  productId: string,
  targetAssetId: string
): Promise<void> {
  const adminCtx = await requirePermission("manage_products");
  const supabase = await createSupabaseServerClient();

  // Step 1: Remove primary flag from current primary
  await supabase
    .from("product_assets")
    .update({ is_primary: false, updated_by: adminCtx.profileId })
    .eq("product_id", productId)
    .eq("asset_type", "Catalog Image")
    .eq("is_primary", true);

  // Step 2: Set target asset as primary
  const { error } = await supabase
    .from("product_assets")
    .update({ is_primary: true, updated_by: adminCtx.profileId })
    .eq("asset_id", targetAssetId);

  if (error) {
    throw new Error(`Failed to set primary asset: ${error.message}`);
  }

  revalidatePath(`/admin/products/${productId}/setup`);
  revalidatePath("/product");
}

export async function deleteCatalogImage(
  productId: string,
  assetId: string
): Promise<void> {
  const adminCtx = await requirePermission("manage_products");
  const supabase = await createSupabaseServerClient();

  // 1. Soft-delete the asset
  const { data: deleted } = await supabase
    .from("product_assets")
    .update({ status: "Inactive", is_primary: false, updated_by: adminCtx.profileId })
    .eq("asset_id", assetId)
    .select("is_primary")
    .single();

  // 2. If deleted asset was primary, promote the first remaining active asset
  if (deleted?.is_primary) {
    const { data: remaining } = await supabase
      .from("product_assets")
      .select("asset_id")
      .eq("product_id", productId)
      .eq("asset_type", "Catalog Image")
      .eq("status", "Active")
      .order("display_order", { ascending: true })
      .limit(1);

    if (remaining && remaining.length > 0) {
      await supabase
        .from("product_assets")
        .update({ is_primary: true, updated_by: adminCtx.profileId })
        .eq("asset_id", remaining[0].asset_id);
    }
  }

  revalidatePath(`/admin/products/${productId}/setup`);
  revalidatePath("/product");
}
```

## 4. UI Specification: Infinite Looping Marquee Carousel (`DSD-UI14`)

### 4.1 The Infinite Loop Navigation Invariant ("No Hard Right or Left")
The user requirement specifically mandates:
> "This can be navigated with left or right arrows and will be like a marquee so no hard right or left. This should also reflect in product catalog in customer side."

To satisfy this requirement:
1. **Boundary Elimination:** The left and right arrow buttons are **never disabled** when the gallery contains 2 or more images (`images.length > 1`).
2. **Modulo Arithmetic Wrap-Around:**
   - Clicking the Right Arrow on the last image (`index === images.length - 1`) wraps directly to `index 0`.
   - Clicking the Left Arrow on the first image (`index === 0`) wraps directly to `index === images.length - 1`.
   ```typescript
   const handleNext = (e?: React.MouseEvent) => {
     e?.stopPropagation();
     e?.preventDefault();
     setActiveIndex((prev) => (prev + 1) % images.length);
   };

   const handlePrev = (e?: React.MouseEvent) => {
     e?.stopPropagation();
     e?.preventDefault();
     setActiveIndex((prev) => (prev - 1 + images.length) % images.length);
   };
   ```
3. **Marquee Sliding Transition:**  
   The image container utilizes a horizontal sliding track (`flex transition-transform duration-300 ease-out`) with `transform: translateX(-${activeIndex * 100}%)`. Alternatively, for seamless looping without back-tracking, a circular three-element sliding window (`[prev, active, next]`) or CSS marquee clone is employed.
4. **Accessible Pagination Dots:**  
   Pill-shaped indicator dots reside at the bottom center of the carousel. Clicking any dot jumps directly to that image. Active dot expands (`w-5 bg-white`) while inactive dots remain circular (`w-1.5 bg-white/50`).

## 6. Component Blueprints for Admin & Customer UI

### 6.1 Admin Multi-Image Ingestion & Marquee Card (`CatalogAssetsSection.tsx`)
In Step 3 of the Admin Product Setup Wizard, the single image upload box is replaced by a multi-file drag-and-drop surface paired with an infinite marquee carousel viewer:

```typescript
"use client";

import React, { useState, useEffect } from "react";
import Image from "next/image";
import { ChevronLeft, ChevronRight, UploadCloud, X, Star, Loader2, Plus } from "lucide-react";
import type { CatalogAssetRecord } from "./types";
import { confirmCatalogImageBatch, deleteCatalogImage, setPrimaryCatalogImage } from "@/lib/admin/products/assetUpload";
import { generatePresignedUrl } from "@/lib/admin/products/assetUpload";
import { getR2AssetUrl } from "@/lib/r2";

interface MultiImageCatalogManagerProps {
  productId: string;
  initialAssets: CatalogAssetRecord[];
  onAssetsUpdated: (assets: CatalogAssetRecord[]) => void;
}

export function MultiImageCatalogManager({
  productId,
  initialAssets,
  onAssetsUpdated,
}: MultiImageCatalogManagerProps) {
  const [assets, setAssets] = useState<CatalogAssetRecord[]>(initialAssets);
  const [activeIndex, setActiveIndex] = useState(0);
  const [isUploading, setIsUploading] = useState(false);
  const [uploadError, setUploadError] = useState<string | null>(null);

  const activeAsset = assets[activeIndex] || null;
  const total = assets.length;

  const handleNext = (e?: React.MouseEvent) => {
    e?.stopPropagation();
    if (total <= 1) return;
    setActiveIndex((prev) => (prev + 1) % total);
  };

  const handlePrev = (e?: React.MouseEvent) => {
    e?.stopPropagation();
    if (total <= 1) return;
    setActiveIndex((prev) => (prev - 1 + total) % total);
  };

  const handleFiles = async (files: FileList | File[]) => {
    try {
      setIsUploading(true);
      setUploadError(null);

      const fileList = Array.from(files);
      const uploadedItems = [];

      for (let i = 0; i < fileList.length; i++) {
        const file = fileList[i];
        const { uploadUrl, assetId, objectKey } = await generatePresignedUrl(
          productId,
          "Catalog Image",
          file.name,
          file.type
        );

        const putRes = await fetch(uploadUrl, {
          method: "PUT",
          body: file,
          headers: { "Content-Type": file.type },
        });

        if (!putRes.ok) throw new Error(`Failed to upload ${file.name}`);

        uploadedItems.push({
          assetId,
          objectKey,
          fileName: file.name,
          mimeType: file.type,
          byteSize: file.size,
          displayOrder: assets.length + i + 1,
          isPrimary: assets.length === 0 && i === 0,
        });
      }

      const confirmed = await confirmCatalogImageBatch(productId, uploadedItems);
      const updated = [...assets, ...confirmed];
      setAssets(updated);
      onAssetsUpdated(updated);
    } catch (err: unknown) {
      console.error(err);
      setUploadError(err instanceof Error ? err.message : "Failed to upload images.");
    } finally {
      setIsUploading(false);
    }
  };

  const handleDelete = async (assetId: string) => {
    await deleteCatalogImage(productId, assetId);
    const updated = assets.filter((a) => a.asset_id !== assetId);
    setAssets(updated);
    onAssetsUpdated(updated);
    if (activeIndex >= updated.length) {
      setActiveIndex(Math.max(0, updated.length - 1));
    }
  };

  const handleMakePrimary = async (assetId: string) => {
    await setPrimaryCatalogImage(productId, assetId);
    const updated = assets.map((a) => ({
      ...a,
      is_primary: a.asset_id === assetId,
    }));
    setAssets(updated);
    onAssetsUpdated(updated);
  };

  return (
    <div className="flex flex-col gap-4 w-full">
      {/* Main Preview Container with Infinite Navigation */}
      {total > 0 ? (
        <div className="relative w-full aspect-square bg-[#f8fafc] rounded-[16px] border border-neutral-200 overflow-hidden group">
          {/* Active Image */}
          {activeAsset && (
            <div className="relative w-full h-full p-4 flex items-center justify-center">
              <Image
                src={getR2AssetUrl(activeAsset.r2_object_key) || ""}
                alt={activeAsset.file_name}
                fill
                unoptimized
                className="object-contain p-2 transition-all duration-300"
              />
            </div>
          )}

          {/* Primary Badge */}
          {activeAsset?.is_primary && (
            <div className="absolute top-3 left-3 px-2.5 py-1 rounded-full bg-[#07b6d3] text-white text-xs font-semibold flex items-center gap-1 shadow-sm z-20">
              <Star className="size-3 fill-current" /> Primary Thumbnail
            </div>
          )}

          {/* Infinite Marquee Controls: Left / Right Arrows (No Hard Boundaries) */}
          {total > 1 && (
            <>
              <button
                type="button"
                onClick={handlePrev}
                aria-label="Previous Image"
                className="absolute left-3 top-1/2 -translate-y-1/2 p-2 rounded-full bg-white/90 hover:bg-white text-neutral-700 hover:text-black shadow-md transition-transform hover:scale-110 z-20"
              >
                <ChevronLeft className="size-5" />
              </button>
              <button
                type="button"
                onClick={handleNext}
                aria-label="Next Image"
                className="absolute right-3 top-1/2 -translate-y-1/2 p-2 rounded-full bg-white/90 hover:bg-white text-neutral-700 hover:text-black shadow-md transition-transform hover:scale-110 z-20"
              >
                <ChevronRight className="size-5" />
              </button>
            </>
          )}

          {/* Quick Actions Overlay */}
          <div className="absolute top-3 right-3 flex items-center gap-1.5 z-20">
            {activeAsset && !activeAsset.is_primary && (
              <button
                type="button"
                onClick={() => handleMakePrimary(activeAsset.asset_id)}
                className="p-1.5 rounded-full bg-white/90 hover:bg-white text-neutral-600 hover:text-amber-500 shadow-sm transition-colors text-xs flex items-center gap-1 px-2.5 font-medium"
                title="Set as Primary Thumbnail"
              >
                <Star className="size-3.5" /> Make Primary
              </button>
            )}
            {activeAsset && (
              <button
                type="button"
                onClick={() => handleDelete(activeAsset.asset_id)}
                className="p-1.5 rounded-full bg-white/90 hover:bg-red-50 text-neutral-500 hover:text-red-500 shadow-sm transition-colors"
                title="Delete this image"
              >
                <X className="size-4" />
              </button>
            )}
          </div>

          {/* Bottom Counter & Indicators */}
          <div className="absolute bottom-3 inset-x-0 flex flex-col items-center gap-1.5 z-20 pointer-events-none">
            {total > 1 && (
              <div className="flex items-center gap-1 px-2 py-1 rounded-full bg-black/50 backdrop-blur-xs">
                {assets.map((_, idx) => (
                  <span
                    key={idx}
                    className={`h-1.5 rounded-full transition-all ${
                      idx === activeIndex ? "w-4 bg-white" : "w-1.5 bg-white/50"
                    }`}
                  />
                ))}
              </div>
            )}
            <span className="text-[11px] font-medium text-white px-2 py-0.5 rounded-md bg-black/40 backdrop-blur-xs">
              {activeIndex + 1} of {total}
            </span>
          </div>
        </div>
      ) : (
        /* Empty State Dropzone */
        <label className="w-full aspect-square border-2 border-dashed border-[#07b6d3]/40 rounded-[16px] bg-[#f5f5f5]/50 hover:bg-[#07b6d3]/5 flex flex-col items-center justify-center p-6 text-center cursor-pointer transition-colors group">
          <div className="p-4 rounded-full bg-white shadow-sm mb-4 group-hover:scale-105 transition-transform pointer-events-none">
            <UploadCloud className="size-6 text-[#07b6d3]" />
          </div>
          <p className="text-[#0f1422] font-medium mb-1 pointer-events-none">Click or drag images to upload</p>
          <p className="text-xs text-neutral-500 pointer-events-none">JPG, PNG, or WebP. Accepts multiple files.</p>
          <input
            type="file"
            multiple
            accept="image/png, image/jpeg, image/webp"
            className="hidden"
            onChange={(e) => e.target.files && handleFiles(e.target.files)}
          />
        </label>
      )}

      {/* Thumbnail Strip with Add More Button */}
      {total > 0 && (
        <div className="flex items-center gap-2 overflow-x-auto pb-1 max-w-full">
          {assets.map((item, idx) => (
            <button
              key={item.asset_id}
              type="button"
              onClick={() => setActiveIndex(idx)}
              className={`relative size-16 shrink-0 rounded-[10px] border-2 overflow-hidden transition-all ${
                idx === activeIndex
                  ? "border-[#07b6d3] ring-2 ring-[#07b6d3]/20 scale-105"
                  : "border-neutral-200 opacity-60 hover:opacity-100"
              }`}
            >
              <Image
                src={getR2AssetUrl(item.r2_object_key) || ""}
                alt={item.file_name}
                fill
                unoptimized
                className="object-cover"
              />
              {item.is_primary && (
                <div className="absolute top-0.5 left-0.5 size-3 rounded-full bg-[#07b6d3] flex items-center justify-center">
                  <Star className="size-2 text-white fill-current" />
                </div>
              )}
            </button>
          ))}

          {/* Add More Images Button */}
          <label className="size-16 shrink-0 rounded-[10px] border-2 border-dashed border-neutral-300 hover:border-[#07b6d3] hover:bg-[#07b6d3]/5 flex items-center justify-center cursor-pointer text-neutral-400 hover:text-[#07b6d3] transition-colors">
            {isUploading ? (
              <Loader2 className="size-5 animate-spin text-[#07b6d3]" />
            ) : (
              <Plus className="size-5" />
            )}
            <input
              type="file"
              multiple
              accept="image/png, image/jpeg, image/webp"
              className="hidden"
              disabled={isUploading}
              onChange={(e) => e.target.files && handleFiles(e.target.files)}
            />
          </label>
        </div>
      )}

      {uploadError && (
        <p className="text-xs text-red-500 font-medium bg-red-50 p-2 rounded">{uploadError}</p>
      )}
    </div>
  );
}
```

### 6.2 Customer Catalog Card Marquee (`ProductCard.tsx`)
In `src/features/product/components/ProductCard.tsx`, the card image area is upgraded to an infinite looping marquee carousel. When multiple images exist, left and right arrows allow the customer to cycle through images right inside the catalog grid without navigating away:

```typescript
"use client";

import { useState } from "react";
import Link from "next/link";
import Button from "@/components/shared/Button";
import Image from "next/image";
import { ChevronLeft, ChevronRight } from "lucide-react";
import type { CatalogProduct } from "@/lib/products/types";

export function ProductCard({ product }: { product: CatalogProduct }) {
  const { name, description, basePrice, imageUrl, imageUrls = [] } = product;

  // Use array of images if available, fallback to single imageUrl
  const images = imageUrls.length > 0 ? imageUrls : imageUrl ? [imageUrl] : ["/product_card_placeholder.png"];
  const [currentImgIndex, setCurrentImgIndex] = useState(0);

  const totalImages = images.length;

  // Infinite wrap-around marquee navigation (no hard left or right boundaries)
  const handleNext = (e: React.MouseEvent) => {
    e.stopPropagation();
    e.preventDefault();
    setCurrentImgIndex((prev) => (prev + 1) % totalImages);
  };

  const handlePrev = (e: React.MouseEvent) => {
    e.stopPropagation();
    e.preventDefault();
    setCurrentImgIndex((prev) => (prev - 1 + totalImages) % totalImages);
  };

  const activeSrc = images[currentImgIndex];
  const isExternalImage = activeSrc.startsWith("http");

  return (
    <div className="max-w-68.25 rounded-[10px] bg-white/50 shadow-[0px_0px_5px_0px_rgba(0,0,0,0.25)] w-full flex flex-col justify-between overflow-hidden group">
      {/* Image Carousel Area */}
      <div className="relative w-full h-[224px] overflow-hidden bg-neutral-100">
        <Image
          src={activeSrc}
          alt={`${name} - Image ${currentImgIndex + 1}`}
          fill
          className="object-cover transition-all duration-300"
          unoptimized={isExternalImage}
        />

        {/* Infinite Loop Arrow Controls (only displayed when multiple images exist) */}
        {totalImages > 1 && (
          <>
            <button
              type="button"
              onClick={handlePrev}
              aria-label="Previous product image"
              className="absolute left-2 top-1/2 -translate-y-1/2 p-1.5 rounded-full bg-white/80 hover:bg-white text-neutral-800 shadow-md opacity-0 group-hover:opacity-100 transition-opacity z-10 hover:scale-105"
            >
              <ChevronLeft className="size-4" />
            </button>
            <button
              type="button"
              onClick={handleNext}
              aria-label="Next product image"
              className="absolute right-2 top-1/2 -translate-y-1/2 p-1.5 rounded-full bg-white/80 hover:bg-white text-neutral-800 shadow-md opacity-0 group-hover:opacity-100 transition-opacity z-10 hover:scale-105"
            >
              <ChevronRight className="size-4" />
            </button>

            {/* Pagination Indicators */}
            <div className="absolute bottom-2 inset-x-0 flex items-center justify-center gap-1 z-10 pointer-events-none">
              {images.map((_, idx) => (
                <span
                  key={idx}
                  className={`h-1.5 rounded-full transition-all ${
                    idx === currentImgIndex ? "w-3 bg-white shadow-xs" : "w-1.5 bg-white/60"
                  }`}
                />
              ))}
            </div>
          </>
        )}
      </div>

      {/* Product Content Details (unchanged styling) */}
      <div className="flex flex-col p-5 gap-7.5 flex-1 justify-between">
        ...
      </div>
    </div>
  );
}
```
