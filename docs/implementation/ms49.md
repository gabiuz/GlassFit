## 1. Outcome and Scope

In the initial implementation of the paper fiducial workflow (IMP-MS47), manual corner pin confirmation updated only local component state (`useState`) within `ProductModelWorkspace.tsx`. This created a critical usability defect:

1. **State Erasure on Product Addition or Switch:** When a user clicked "Add Product" to place a second window or door into the room (or switched products via IMP-MS44), the workspace component re-rendered or staged new state. Because `spaceImageSession.calibrationMeta` in `visualizationSession.tsx` was never updated, the initial uncalibrated or `manual_pin_required` status was read anew, immediately opening the mapping modal again and wiping the user's previously calibrated scale factor.
2. **State Erasure on Quotation Navigation:** When a user navigated to `/quotation` to review budgetary line items and subsequently clicked "Back to Workspace", the component mounted fresh from `sessionStorage`, re-opening the mapping modal and requiring the user to map the paper corners repeatedly for the exact same room photo.
3. **Aggressive Modal Ingress:** Even when the backend computer vision service auto-detected paper or when users intended to rely on standard room heuristics, the mapping modal opened aggressively, interrupting user flow.

`IMP-MS49` resolves these state-loss defects by establishing an immutable, session-permanent calibration architecture and defining a non-intrusive fallback lifecycle:

- **Session Context Calibration Mutation:** Introduces `updateSessionCalibration(calibrationMeta, scaleSignal)` within `VisualizationSessionContext`, persisting calibrated status, metric scale (`scale_cm_per_px`), homography matrix, and corner coordinates directly into `spaceImageSession` and browser `sessionStorage`.
- **Preservation across Multi-Product Transitions:** Modifies `transitionSessionState()` in `src/lib/visualization/visualizationSession.tsx` to strictly retain `spaceImageSession.calibrationMeta` and `scaleEstimation` across all overlay modes (`add`, `change`, `edit`). Newly added products immediately inherit the active calibrated scale.
- **Strict Fallback Lifecycle:**
  - When auto-detection succeeds (`status === "calibrated"`), the manual pin modal never displays on workspace entry.
  - When auto-detection returns `status === "manual_pin_required"`, the modal opens only on initial entry for that room photo.
  - Once confirmed or skipped, the state is permanently saved as `"calibrated"` or `"heuristic_fallback"`, never re-prompting on subsequent product additions or quotation navigation.
- **On-Demand Adjustment:** A non-intrusive *"Adjust Marker"* action in the top-left canvas HUD enables users to re-open the pin modal at any time to fine-tune corners without disturbing placed fixtures.

### 1.1 Non-Negotiable Invariants

1. **Session Permanence:** Once a room session is marked calibrated, this status must persist across product additions, product switching, and quotation review round-trips. Pinning is executed at most once per room session.
2. **Automatic Success Bypasses Mapping:** When automatic paper detection succeeds (`status === "calibrated"`), the customer must never be presented with the manual pin modal on workspace entry.
3. **Storage Quota Resilience:** Calibration metadata serialization must be compact (under 2KB) and resilient to `sessionStorage` quota pressure, surviving tiered image stripping without dropping calibration state.
4. **Component & Token Reuse:** The interactive pin modal must reuse established UI patterns from `PerspectivePlanePicker.tsx` and `ManualOcclusionPointPicker.tsx`, including touch proxies, magnifier loupes, corner clamping, and responsive SVG handles (`BAN-UI-09`).
5. **No Em-Dashes:** In compliance with `BAN-PUNCT-01`, all documentation, code comments, and copy must use hyphens, colons, or parentheses.
6. **No Box Diagrams in Code Blocks:** All UI layouts and state transition tables must use standard Markdown tables and ordered prose (`BAN-DIAG-03`).

## 2. Verified Starting Point & Defect Root Cause

| Area / File | Defect Mechanism | Required Implementation Consequence |
|---|---|---|
| `src/features/visualization/components/ProductModelWorkspace.tsx` | `handlePaperPinConfirm` calls `setActiveCalibrationMeta` and `setActiveScaleSignal` (local `useState` hooks), but never calls an action on `useVisualizationSession()`. | Connect workspace to session context; invoke `updateSessionCalibration(updatedMeta, updatedSignal)` on confirm and skip; initialize `showPaperPinPicker` only when uncalibrated in the session. |
| `src/lib/visualization/visualizationSession.tsx` | `VisualizationSessionContextValue` lacks a method to mutate `spaceImageSession.calibrationMeta` post-upload. | Add `updateSessionCalibration` to context; update `createPreparedSpaceImageState`, `transitionSessionState`, and `serializeVisualizationSession` to preserve calibration metadata. |
| `src/lib/visualization/visualizationSession.tsx` | `serializeVisualizationSession` includes `spaceImageSession`, but if `spaceImageSession.calibrationMeta` is undefined or stripped in lightweight fallbacks, state is lost. | Ensure `calibrationMeta` is explicitly serialized across all storage fallback tiers. |
| `src/features/visualization/components/FiducialPaperPickerModal.tsx` | Modal lacks an explicit "Skip to Quick Preview" handler that sets a permanent heuristic fallback status. | Implement "Skip to Quick Preview" button that updates session calibration status to `"heuristic_fallback"`, permanently silencing re-prompts. |

## 3. Session State Architecture & State Lifecycle Contracts

### 3.1 Extended Session Context Interface

In `src/lib/visualization/visualizationSession.tsx`:

```typescript
export interface CalibrationMetadata {
  mode: CalibrationMode;
  paperStandard: FiducialPaperStandard | null;
  status: "calibrated" | "manual_pin_required" | "heuristic_fallback" | "not_requested";
  confidence: number;
  homographyMatrix?: number[][] | null;
  detectedCorners?: [number, number][] | null;
}

export type VisualizationSessionContextValue = VisualizationSessionState & {
  // Existing session methods...
  setPreparedSpaceImage: (productId: string, session: SpaceImageSession) => void;
  transitionWorkspaceProduct: (options: TransitionWorkspaceProductOptions) => void;
  // New session permanence action:
  updateSessionCalibration: (
    calibrationMeta: CalibrationMetadata,
    scaleSignal: ScaleEstimationSignal,
  ) => void;
  // ...
};
```

### 3.2 State Lifecycle Transitions

The calibration lifecycle across session operations is defined as follows:

| Ingress / Action | Initial State | Trigger / Operation | Resulting Session State | UI Behavior |
|---|---|---|---|---|
| Image Upload | New Image | FastAPI CV detection succeeds (`conf >= 0.65`) | `calibrationMeta.status = "calibrated"`, `scale_cm_per_px` stored | Workspace opens directly; HUD displays "Calibrated Scale"; pin modal is hidden |
| Image Upload | New Image | FastAPI CV detection uncertain (`conf < 0.65`) | `calibrationMeta.status = "manual_pin_required"` | Workspace opens; pin modal appears once; HUD displays fallback preview |
| User Pins Corners | `manual_pin_required` | User drags 4 corners in modal and clicks "Confirm" | `calibrationMeta.status = "calibrated"`, metric scale recalculated and saved | Modal closes; session commits to storage; HUD switches to emerald "Calibrated Scale" badge |
| User Skips Pinning | `manual_pin_required` | User clicks "Skip to Quick Preview" | `calibrationMeta.status = "heuristic_fallback"` | Modal closes; session commits to storage; HUD displays "Heuristic Scale"; no further prompts |
| Add Second Product | `calibrated` | User clicks "Add Product" (IMP-MS44) | `calibrationMeta.status = "calibrated"` preserved; scale inherited | Workspace stages new product; calibrated scale factor applies immediately; pin modal does not appear |
| Navigate to Quotation | `calibrated` | User proceeds to `/quotation` and returns | State hydrates from `sessionStorage` with `status = "calibrated"` | Workspace restores; calibrated scale remains active; pin modal does not appear |
| HUD "Adjust Marker" | `calibrated` | User clicks "Adjust Marker" link in HUD | `showPaperPinPicker = true` (user-initiated) | Pin modal opens with current corners; user can adjust or cancel without losing placed layers |

## 4. UI & Interaction Specification

### 4.1 Workspace Calibration HUD Indicator

In `src/features/visualization/components/ProductModelWorkspace.tsx`, render a non-intrusive calibration status pill in the top-left canvas overlay:

| Calibration State | Visual Styling | Displayed Content and Actions |
|---|---|---|
| **Calibrated Precision** (`status === "calibrated"`) | Emerald background (`bg-emerald-500/10 border border-emerald-500/30 text-emerald-600 dark:text-emerald-400`), backdrop blur | Green check circle icon, text: "Calibrated Scale: ±2-5% Precision", followed by an "Adjust Marker" text link |
| **Heuristic Preview** (`status === "heuristic_fallback"`) | Neutral background (`bg-neutral-900/60 border border-neutral-500/20 text-white/90`), backdrop blur | Info icon, text: "Heuristic Scale: Ballpark Preview", followed by a "Pin Paper" text link if paper was uploaded |

### 4.2 Interactive Fallback Pinning Modal (`FiducialPaperPickerModal.tsx`)

The modal is rendered only when `showPaperPinPicker` is true:

| Modal Section | Visual Tokens and Controls | Operational Behavior |
|---|---|---|
| **Header** | High-contrast title "Pin Your Taped Paper Corners", close button | Dismisses user-initiated adjustment without altering saved session state |
| **Paper Standard Selector** | Segmented radio group (Short Bond, A4 Standard, Long Bond) | Changes target physical dimensions in millimeters, immediately re-evaluating preview scale |
| **Interactive Canvas** | Room photo display with SVG handles and touch proxies | Allows dragging 4 corners; magnifier loupe provides 2x zoomed sub-pixel precision |
| **Footer Actions** | "Reset to Center", "Skip to Quick Preview", "Confirm & Calibrate" | Reset centers handles; Skip permanently sets `heuristic_fallback`; Confirm saves calibration and closes |

## 5. Step-by-Step Implementation Plan

1. **Step 1: Session Context Calibration Mutation Action**
   - In `src/lib/visualization/visualizationSession.tsx`, implement `updateSessionCalibration(calibrationMeta, scaleSignal)`.
   - Update `writeStoredVisualizationSession` and `serializeVisualizationSession` to ensure `calibrationMeta` is never stripped during session sanitization.

2. **Step 2: Cross-Product Transition Preservation**
   - Update `transitionSessionState()` in `src/lib/visualization/visualizationSession.tsx` to verify `spaceImageSession.calibrationMeta` and `scaleEstimation` are strictly preserved across `add`, `change`, and `edit` product operations.

3. **Step 3: Workspace Lifecycle Hook Integration**
   - In `src/features/visualization/components/ProductModelWorkspace.tsx`, connect to `useVisualizationSession()`.
   - Initialize `showPaperPinPicker` to `true` strictly when `spaceImageSession?.calibrationMeta?.status === "manual_pin_required"` on initial entry.
   - Update `handlePaperPinConfirm` and `handlePaperPinSkip` to call `updateSessionCalibration()`.

4. **Step 4: HUD Indicator and Adjust Marker Action**
   - Connect the HUD "Adjust Marker" button to `setShowPaperPinPicker(true)`.
   - Connect the fallback "Pin Paper" button to `setShowPaperPinPicker(true)`.

5. **Step 5: Automated Regression and Persistence Testing**
   - Write comprehensive unit tests in `tests/unit/calibrationSessionPermanence.test.ts` verifying that calibration survives product transitions and quotation navigation round-trips.

## 8. Risks and Mitigations

| Risk | Severity | Mitigation |
|---|---|---|
| Session storage quota exceeded due to large room image URL | Low | `writeStoredVisualizationSession` includes tiered storage fallbacks that strip large image data URLs while strictly preserving metadata, `calibrationMeta`, and `scaleEstimation`. |
| User accidentally clicks "Skip to Quick Preview" | Low | The workspace HUD provides a persistent "Pin Paper" action link allowing users to restore paper calibration at any time. |
| Browser tab refreshed during workspace editing | Low | Session storage restores `calibrationMeta` and `scaleEstimation` on mount, ensuring refreshed tabs retain active calibration. |
