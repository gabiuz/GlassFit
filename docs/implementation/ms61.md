## 1. Outcome and Scope

To answer the core engineering and user question: *"Will clicking the paper to detect and automatically map it be accurate?"*, GlassFit requires an objective, reproducible benchmark protocol. Visual inspection alone cannot distinguish between a model that merely "looks plausible" and a model whose parametric width and height accurately correspond to physical reality.

This milestone establishes the **Comparative Fiducial Accuracy Benchmark Protocol**. It extends the MS57 offline evaluation harness (`scripts/ms57/`) to benchmark three distinct calibration modalities across the physical test dataset:
1. **Full-Automatic Detection (MS53):** Zero user interaction; scans the entire room photograph for fiducial candidates.
2. **Click-Guided Snap Detection (MS58-MS60):** Single tap inside the paper boundary; executes seed-constrained localized segmentation, sub-pixel edge intersection, and rectified aspect ratio matching.
3. **Manual 4-Corner Pinning (MS47):** Full manual placement of four corner pins using the 2.5x loupe.

Each modality is evaluated against physical tape-measured ground truth for both target aperture axes (width and height), evaluating localization error (corner RMSE in pixels), metric accuracy (absolute error in millimeters and relative error in percentage), intake duration (time to confirmation in seconds), and failure recovery rates.

## 3. Non-Negotiable Invariants

1. **Independent Physical Ground Truth:** Ground truth for aperture width and height must be established with a physical steel measuring tape, measured across top/bottom and left/right edges to account for opening out-of-squareness. Predicted model dimensions must never serve as ground truth.
2. **Deterministic Seed Point Simulation:** In automated benchmarking, simulated clicks are generated deterministically (such as the centroid of the annotated ground truth sheet or random samples with fixed PRNG seeds), preventing cherry-picked test results.
3. **Strict Separation of Development and Holdout Datasets:** Tuning of edge snapping thresholds or aspect ratio matching tolerances must occur exclusively on development captures. The holdout dataset (minimum 20 captures across 5 openings and 3 devices) is evaluated once per release candidate.
4. **Honest Reporting of Abstentions:** If click-guided mode fails to find a valid quadrilateral around the seed point, it must be recorded as an abstention, not omitted from coverage denominators.
5. **No Em-Dashes or Code Diagrams:** Maintain strict compliance with repository documentation standards (BAN-PUNCT-01, BAN-DIAG-03).

## 4. Benchmark Architecture and Metric Definitions

### 4.1 Comparative Test Matrix

The benchmark evaluates each photo in the physical evaluation dataset across all three modalities:

| Modality ID | Modality Name | Input Parameters | User Interaction | Primary Failure Mode Tested |
|---|---|---|---|---|
| MOD-AUTO | Full-Automatic Detection | Space image only | 0 taps (fully autonomous) | Distractor confusion, low global contrast, candidate ambiguity |
| MOD-CLICK | Click-Guided Snap Detection | Space image + Seed point $(x_{seed}, y_{seed})$ | 1 tap inside sheet | Weak local edge contrast, boundary fold, shadow gradients |
| MOD-MANUAL | Manual 4-Corner Pinning | Space image + 4 manually placed pins | 4 drag interactions with 2.5x loupe | Human pointer imprecision, fatigue, display touch quantization |

### 4.2 Quantitative Evaluation Metrics

For every test capture $i$ and each modality $m$:

1. **Corner Localization RMSE ($E_{corner}$ in pixels):**
   $$E_{corner} = \sqrt{\frac{1}{4} \sum_{k=0}^{3} \| P_{pred, k} - P_{annotated, k} \|^2}$$
2. **Metric Absolute Error ($E_{abs}$ in millimeters):**
   $$E_{abs, W} = | W_{predicted} - W_{tape} |, \quad E_{abs, H} = | H_{predicted} - H_{tape} |$$
3. **Metric Relative Error ($E_{rel}$ in percentage):**
   $$E_{rel, W} = 100 \times \frac{| W_{predicted} - W_{tape} |}{W_{tape}}, \quad E_{rel, H} = 100 \times \frac{| H_{predicted} - H_{tape} |}{H_{tape}}$$
4. **Mean Time to Confirmation (MTTC in seconds):**
   Measures user interaction duration from modal open to reference confirmation.
5. **Localization Coverage ($C_{loc}$ in percentage):**
   Percentage of eligible photos where the modality successfully extracted a valid convex quadrilateral without user abstention.

## 5. Comparative Empirical Release Gates

To certify that Click-Guided Snap Detection (MS58-MS60) is ready for production and delivers superior real-world accuracy, the following statistical gates must pass simultaneously on the held-out physical dataset:

| Release Gate Metric | Full-Automatic Target | Click-Guided Target (MS58-MS60) | Manual Pinning Target | Pass Criteria / Rationale |
|---|---|---|---|---|
| Localization Coverage ($C_{loc}$) | $\ge 75.0\%$ | $\ge 92.0\%$ | $100.0\%$ (user forced) | Click guidance must eliminate distractor abstentions in cluttered scenes. |
| Corner Localization RMSE ($E_{corner}$) | $\le 4.5$ px | $\le 2.2$ px | $\le 3.5$ px (touch drift) | Sub-pixel edge intersection (MS59) must outperform human finger touch precision. |
| Median Relative Error ($E_{rel, med}$) | $\le 2.5\%$ | $\le 1.8\%$ | $\le 2.2\%$ | Click-guided mode must achieve typical aperture sizing accuracy under 2.0%. |
| 95th Percentile Relative Error ($E_{rel, p95}$) | $\le 5.5\%$ | $\le 3.8\%$ | $\le 4.5\%$ | Ensures extreme outlier errors remain bounded below 4.0%. |
| Maximum Relative Error ($E_{rel, max}$) | $\le 7.0\%$ | $\le 5.0\%$ | $\le 6.0\%$ | No accepted planar measurement deviates by more than 5.0% on width or height. |
| Mean Time to Confirmation (MTTC) | $< 3.0$ s | $< 6.0$ s | $> 35.0$ s | 1 tap delivers full manual accuracy with an 80%+ reduction in interaction time. |
| Coplanar Safety (MS55 Invariant) | $0$ false promotions | $0$ false promotions | $0$ false promotions | Non-coplanar or handheld paper must never be promoted to trusted metric status. |

## 6. Step-by-Step Implementation Plan

1. **Benchmark CLI Extension (`scripts/ms57/run_benchmark.py`):**
   - Add argument `--mode [auto|click_guided|manual|compare_all]`.
   - Implement simulated seed point generator: extracts centroid $(\bar{x}, \bar{y})$ of annotated sheet polygon from `manifest.json`.
   - Implement perturbed seed simulation: tests clicks at 25%, 50%, and 75% offsets from centroid to verify seed robustness.

2. **Metrics Aggregation & Comparison Reporter (`scripts/ms57/comparator.py`):**
   - Compute comparative tables contrasting auto, click-guided, and manual across all five metrics.
   - Generate summary markdown report output to `tests/private/ms61/comparative_report.md`.

3. **Integration Test Suite (`tests/unit/clickGuidedBenchmark.test.ts`):**
   - Unit tests verifying mathematical correctness of RMSE, relative error, and percentile rank calculations.
   - Synthetic fixture tests ensuring degenerate polygons and zero-division cases are handled gracefully.

4. **QAD Test Case Registration (`docs/qad-glassfit.md`):**
   - Register `QAD-TC76` documenting comparative verification commands and pass/fail thresholds.

## 8. Risks and Rollout Strategy

- **Risk: Users expect click-guided snap to work on paper that is crumpled or heavily curled.**  
  *Mitigation:* Physical planarity is a fundamental requirement of homography (MS54/MS55). When an edge line fit has high residual error ($\text{RMSE} > 3.0$px), the modal flags an alert: *"Paper appears warped or curled; keep paper flat against the wall for accurate measurements"*.
- **Risk: Rollout disruption if CV service endpoint is slow under peak load.**  
  *Mitigation:* Seed-constrained ROI processing is 3x faster than full-image search because it processes only a cropped patch rather than the entire 12-megapixel image, reducing server CPU inference time to under 120ms.
