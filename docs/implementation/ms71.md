## 1. Outcome and Scope

In architectural fabrication for residential and commercial spaces, window security grilles are manufactured from linear metal extrusions (such as 14mm, 16mm, or 25mm aluminum square tubes, round pipes, or flat bars). These raw materials are inventoried and priced strictly per linear meter (PHP/m), rather than by superficial surface area (square meters).

Previously in GlassFit, grille pricing relied on two suboptimal approximations:
1. When mapped as a general component in the admin catalog, infill panels were defaulted to `dimensionBinding = "AREA"`, multiplying opening width by opening height (sqm) against a flat rate. This failed to reflect physical reality because dense grille patterns use far more linear profile material than open patterns of the same overall dimensions.
2. In the add-on pricing engine (`addonPricingEngine.ts`), security grilles utilized a simplified heuristic assuming only vertical pickets (`colCount = width / 140mm; totalLinearM = colCount * height`). This completely ignored horizontal divider bars, intermediate tie bars, and alternative grille styles (such as horizontal louvers with a central vertical mullion, or staggered running-bond brick patterns).

Furthermore, administrators authoring products in `/admin/products/[id]/setup` faced an unreasonable burden: either manually decompose and map 20 to 50 individual bar meshes one by one, or settle for inaccurate area-based pricing.

`IMP-MS71` delivers the foundational mathematical pricing engine and automated 3D sub-bar geometry analyzer for architectural grilles:
- **Specialized Linear Grille Pricing Engine (`grillePricingEngine.ts`):** Calculates precise bill of materials (BOM) based on actual linear meters of material used. Separately measures:
  - Perimeter mounting rails: Top, bottom, left, and right frame extrusions.
  - Vertical structural bars: Individual heights multiplied by vertical bar piece counts.
  - Horizontal structural bars: Individual span lengths multiplied by horizontal bar piece counts.
  - Offcut scrap allowances (12% standard aluminum scrap), fabrication labor floor (`max(PHP 650.00, 0.25 * Materials)`), and contractor gross margin (25%).
- **Automated 3D Sub-Bar Geometry Analyzer (`grilleGeometryAnalyzer.ts`):** Enables administrators to select only the single "Center Grille" component in admin setup. The analyzer automatically inspects the 3D geometry (whether an uploaded GLB file with loose sub-meshes or a procedural pattern definition), decomposes internal bars, classifies their orientation (Horizontal vs Vertical), measures individual cut lengths, and calculates nominal repetition pitch without requiring manual one-by-one part selection.
- **Dynamic Pattern Repetition Metric Engine:** Accurately recalculates piece counts and bar lengths as opening width and height dynamically scale in the 3D workspace across three architectural grille topologies:
  - Style 1: Grid pattern (full-height vertical pickets crossed by continuous horizontal divider rails).
  - Style 2: Horizontal louvers / slats (continuous horizontal slats supported by one or more vertical center mullions).
  - Style 3: Staggered brick / running bond (full-height vertical pickets bridged by alternating staggered horizontal tie bars).
- **Sub-10ms Calculation Performance:** Pure mathematical execution completes in under 10 milliseconds, enabling instantaneous price recalculation during continuous dimension slider dragging.

## 3. Non-Negotiable Invariants

1. **Linear Meter Billed Rate Invariant:** Grille center infills must NEVER be calculated using area multiplication (`width * height * rate`). All grille pricing must derive from total linear meters of metal profile (`sum(bar_length * piece_count)` in meters) multiplied by the assigned raw material linear unit price (`unit_price` in PHP/m).
2. **Per-Piece and Per-Meter Accounting:** Every calculation result must report both the aggregated linear meters and the discrete physical piece count for horizontal bars, vertical bars, and perimeter frame rails.
3. **Automated Orientation Classification:** When analyzing 3D grille geometry:
   - Any bar with bounding box length along the local X-axis greater than its height along the local Y-axis (`dx > dy`) must be classified as `HORIZONTAL`.
   - Any bar with bounding box height along the local Y-axis greater than its length along the local X-axis (`dy > dx`) must be classified as `VERTICAL`.
4. **Single-Selection Admin Authoring:** Administrators must never be forced to map or click individual grille bars one by one. Selecting the single "Center Grille" component and assigning its linear raw material profile must automatically bind and price all constituent bars.
5. **Exact Visualization and Pricing Parity:** The piece count and lengths computed by the pricing engine must match the Three.js 3D visual assembly rendered on canvas to within 0.1mm length and exact integer piece counts.
6. **Zero Em-Dashes:** In strict compliance with `BAN-PUNCT-01`, all user-facing labels, table headers, descriptions, and code comments must use hyphens, colons, or parentheses. Never use em-dashes.
7. **Strict Type Safety:** Zero usage of `any` across TypeScript interfaces, calculation routines, and analyzer utilities per `BAN-TYPE-05`.
8. **Mathematical Determinism:** Calculation outputs must be completely deterministic for identical dimensions and material parameters, rounding currency subtotals to two decimal places.

### 4.2 Automated 3D Sub-Bar Geometry Analyzer (`src/lib/pricing/grilleGeometryAnalyzer.ts`)

Create `src/lib/pricing/grilleGeometryAnalyzer.ts` to inspect uploaded 3D GLB models or procedural geometries:

```typescript
import * as THREE from "three";
import type { GrilleBarOrientation, GrilleBarMetric, GrillePatternType } from "./types";

export interface AnalyzedSubBar {
  meshName: string;
  orientation: GrilleBarOrientation;
  lengthMm: number;
  crossSectionMm: { width: number; depth: number };
  boundingBoxMm: { x: number; y: number; z: number };
  centerMm: { x: number; y: number; z: number };
}

export interface GrilleGeometryAnalysis {
  patternType: GrillePatternType;
  detectedFrameThicknessMm: {
    top: number;
    bottom: number;
    left: number;
    right: number;
  };
  innerApertureMm: {
    width: number;
    height: number;
  };
  nominalPitchMm: {
    columnPitch: number;
    rowPitch: number;
  };
  subBars: AnalyzedSubBar[];
  horizontalSummary: {
    distinctLengthsMm: number[];
    pieceCount: number;
    totalLinearM: number;
  };
  verticalSummary: {
    distinctLengthsMm: number[];
    pieceCount: number;
    totalLinearM: number;
  };
}

/**
 * Analyzes a 3D scene or group representing a center grille infill.
 * Traverses mesh nodes and loose geometry primitives, classifies bar orientations
 * along local X (Horizontal) and Y (Vertical) axes, and measures cut lengths.
 */
export function analyzeGrilleGeometry(
  root: THREE.Object3D,
  targetWidthMm: number,
  targetHeightMm: number
): GrilleGeometryAnalysis {
  root.updateMatrixWorld(true);

  const meshes: THREE.Mesh[] = [];
  root.traverse((child) => {
    if (child instanceof THREE.Mesh && child.geometry) {
      meshes.push(child);
    }
  });

  const analyzedBars: AnalyzedSubBar[] = [];

  for (const mesh of meshes) {
    mesh.geometry.computeBoundingBox();
    const box = mesh.geometry.boundingBox;
    if (!box) continue;

    const size = new THREE.Vector3();
    box.getSize(size);

    // Convert from Three.js meters to millimeters
    const dxMm = Math.round(size.x * 1000);
    const dyMm = Math.round(size.y * 1000);
    const dzMm = Math.round(size.z * 1000);

    // Ignore negligible micro-geometry (below 5mm in all axes)
    if (dxMm < 5 && dyMm < 5 && dzMm < 5) continue;

    // Orientation classification heuristic:
    // If length along X is greater than height along Y: Horizontal bar.
    // If height along Y is greater than length along X: Vertical bar.
    let orientation: GrilleBarOrientation = "VERTICAL";
    let lengthMm = dyMm;
    let crossWidth = dxMm;
    let crossDepth = dzMm;

    if (dxMm > dyMm) {
      orientation = "HORIZONTAL";
      lengthMm = dxMm;
      crossWidth = dyMm;
      crossDepth = dzMm;
    }

    const center = new THREE.Vector3();
    box.getCenter(center);

    analyzedBars.push({
      meshName: mesh.name || "Grille_Bar",
      orientation,
      lengthMm,
      crossSectionMm: { width: crossWidth, depth: crossDepth },
      boundingBoxMm: { x: dxMm, y: dyMm, z: dzMm },
      centerMm: {
        x: Math.round(center.x * 1000),
        y: Math.round(center.y * 1000),
        z: Math.round(center.z * 1000),
      },
    });
  }

  // Aggregate horizontal and vertical summaries
  const horizontalBars = analyzedBars.filter((b) => b.orientation === "HORIZONTAL");
  const verticalBars = analyzedBars.filter((b) => b.orientation === "VERTICAL");

  const hDistinct = Array.from(new Set(horizontalBars.map((b) => b.lengthMm)));
  const vDistinct = Array.from(new Set(verticalBars.map((b) => b.lengthMm)));

  const hTotalM = horizontalBars.reduce((sum, b) => sum + b.lengthMm / 1000, 0);
  const vTotalM = verticalBars.reduce((sum, b) => sum + b.lengthMm / 1000, 0);

  // Pattern type heuristic based on bar distribution:
  let detectedPattern: GrillePatternType = "grid";
  if (horizontalBars.length > verticalBars.length * 3) {
    detectedPattern = "louvers";
  } else if (horizontalBars.length > 0 && hDistinct.length > 1) {
    detectedPattern = "staggered_brick";
  } else if (analyzedBars.length > 0) {
    detectedPattern = "custom_uploaded";
  }

  return {
    patternType: detectedPattern,
    detectedFrameThicknessMm: { top: 20, bottom: 20, left: 20, right: 20 },
    innerApertureMm: {
      width: Math.max(100, targetWidthMm - 40),
      height: Math.max(100, targetHeightMm - 40),
    },
    nominalPitchMm: {
      columnPitch: verticalBars.length > 1 ? Math.round(targetWidthMm / (verticalBars.length + 1)) : 140,
      rowPitch: horizontalBars.length > 1 ? Math.round(targetHeightMm / (horizontalBars.length + 1)) : 191,
    },
    subBars: analyzedBars,
    horizontalSummary: {
      distinctLengthsMm: hDistinct,
      pieceCount: horizontalBars.length,
      totalLinearM: Math.round(hTotalM * 100) / 100,
    },
    verticalSummary: {
      distinctLengthsMm: vDistinct,
      pieceCount: verticalBars.length,
      totalLinearM: Math.round(vTotalM * 100) / 100,
    },
  };
}
```

### 4.3 Dedicated Linear Grille Pricing Engine (`src/lib/pricing/grillePricingEngine.ts`)

Create `src/lib/pricing/grillePricingEngine.ts` implementing the mathematical BOM logic:

```typescript
import type {
  GrilleLinearPricingInput,
  GrilleLinearBOMResult,
  GrilleBarMetric,
  GrilleBarOrientation,
} from "./types";

const DEFAULT_AL_SCRAP = 0.12; // 12% offcut scrap allowance
const DEFAULT_LABOR_FLOOR = 650.0; // Minimum fabrication labor in PHP
const DEFAULT_LABOR_RATE = 0.25; // 25% of material cost
const DEFAULT_CONTRACTOR_MARGIN = 0.25; // 25% gross contractor margin

function round2(val: number): number {
  return Math.round(val * 100) / 100;
}

/**
 * Calculates itemized Bill of Materials (BOM) for an architectural window security grille
 * by computing the exact linear meters and piece count for horizontal bars, vertical bars,
 * and perimeter rails under dynamic dimensional expansion.
 */
export function calculateGrilleLinearBOM(input: GrilleLinearPricingInput): GrilleLinearBOMResult {
  const {
    widthMm,
    heightMm,
    patternType = "staggered_brick",
    nominalPitchColMm = 140,
    nominalPitchRowMm = 191,
    frameProfileWidthMm = 20,
    includePerimeterFrame = true,
    grilleRawMaterial,
    frameRawMaterial,
    laborRate = DEFAULT_LABOR_RATE,
    laborFloor = DEFAULT_LABOR_FLOOR,
    contractorMarginRate = DEFAULT_CONTRACTOR_MARGIN,
  } = input;

  const barRatePerMeter = grilleRawMaterial.unit_price;
  const barScrap = grilleRawMaterial.waste_allowance ?? DEFAULT_AL_SCRAP;
  const frameRatePerMeter = frameRawMaterial ? frameRawMaterial.unit_price : barRatePerMeter;
  const frameScrap = frameRawMaterial?.waste_allowance ?? DEFAULT_AL_SCRAP;

  const widthM = widthMm / 1000;
  const heightM = heightMm / 1000;
  const frameWidthM = frameProfileWidthMm / 1000;

  // Inner aperture dimensions inside the mounting perimeter frame
  const innerWidthM = includePerimeterFrame ? Math.max(0.1, widthM - 2 * frameWidthM) : widthM;
  const innerHeightM = includePerimeterFrame ? Math.max(0.1, heightM - 2 * frameWidthM) : heightM;
  const innerWidthMm = innerWidthM * 1000;
  const innerHeightMm = innerHeightM * 1000;

  // 1. Perimeter Mounting Rails (Top, Bottom, Left, Right)
  let perimeterDetails: GrilleLinearBOMResult["perimeterRails"] = null;
  let perimeterMetersTotal = 0;
  let perimeterCostTotal = 0;

  if (includePerimeterFrame) {
    const topLengthM = widthM;
    const botLengthM = widthM;
    const sideLengthM = Math.max(0, heightM - 2 * frameWidthM);

    const topMetric: GrilleBarMetric = {
      id: "perimeter-top",
      name: "Grille Frame Top Rail",
      orientation: "HORIZONTAL",
      lengthMm: Math.round(topLengthM * 1000),
      lengthM: topLengthM,
      count: 1,
      totalLinearM: topLengthM,
      unitPricePerMeter: frameRatePerMeter,
      subtotalCost: round2(topLengthM * frameRatePerMeter * (1 + frameScrap)),
    };

    const botMetric: GrilleBarMetric = {
      id: "perimeter-bottom",
      name: "Grille Frame Bottom Rail",
      orientation: "HORIZONTAL",
      lengthMm: Math.round(botLengthM * 1000),
      lengthM: botLengthM,
      count: 1,
      totalLinearM: botLengthM,
      unitPricePerMeter: frameRatePerMeter,
      subtotalCost: round2(botLengthM * frameRatePerMeter * (1 + frameScrap)),
    };

    const leftMetric: GrilleBarMetric = {
      id: "perimeter-left",
      name: "Grille Frame Left Jamb",
      orientation: "VERTICAL",
      lengthMm: Math.round(sideLengthM * 1000),
      lengthM: sideLengthM,
      count: 1,
      totalLinearM: sideLengthM,
      unitPricePerMeter: frameRatePerMeter,
      subtotalCost: round2(sideLengthM * frameRatePerMeter * (1 + frameScrap)),
    };

    const rightMetric: GrilleBarMetric = {
      id: "perimeter-right",
      name: "Grille Frame Right Jamb",
      orientation: "VERTICAL",
      lengthMm: Math.round(sideLengthM * 1000),
      lengthM: sideLengthM,
      count: 1,
      totalLinearM: sideLengthM,
      unitPricePerMeter: frameRatePerMeter,
      subtotalCost: round2(sideLengthM * frameRatePerMeter * (1 + frameScrap)),
    };

    perimeterMetersTotal = topLengthM + botLengthM + sideLengthM * 2;
    perimeterCostTotal =
      topMetric.subtotalCost + botMetric.subtotalCost + leftMetric.subtotalCost + rightMetric.subtotalCost;

    perimeterDetails = {
      topRail: topMetric,
      bottomRail: botMetric,
      leftJamb: leftMetric,
      rightJamb: rightMetric,
      totalLinearM: round2(perimeterMetersTotal),
      subtotalCost: round2(perimeterCostTotal),
    };
  }

  // 2. Dynamic Center Infill Bars (Vertical and Horizontal)
  const vMetrics: GrilleBarMetric[] = [];
  const hMetrics: GrilleBarMetric[] = [];

  if (patternType === "grid") {
    // Style 1: Grid pattern (full-height vertical pickets + full-width horizontal divider rails)
    const colCount = innerWidthMm > 0 ? Math.max(1, Math.floor(innerWidthMm / nominalPitchColMm)) : 0;
    const rowCount = innerHeightMm > 0 ? Math.max(1, Math.floor(innerHeightMm / nominalPitchRowMm)) : 0;

    const vBarLengthM = innerHeightM;
    const vTotalLinearM = colCount * vBarLengthM;
    const vCost = round2(vTotalLinearM * barRatePerMeter * (1 + barScrap));

    vMetrics.push({
      id: "grid-v-bars",
      name: `Vertical Grille Bars (${colCount} pickets)`,
      orientation: "VERTICAL",
      lengthMm: Math.round(vBarLengthM * 1000),
      lengthM: vBarLengthM,
      count: colCount,
      totalLinearM: round2(vTotalLinearM),
      unitPricePerMeter: barRatePerMeter,
      subtotalCost: vCost,
    });

    const hBarLengthM = innerWidthM;
    const hTotalLinearM = rowCount * hBarLengthM;
    const hCost = round2(hTotalLinearM * barRatePerMeter * (1 + barScrap));

    hMetrics.push({
      id: "grid-h-bars",
      name: `Horizontal Cross Rails (${rowCount} rails)`,
      orientation: "HORIZONTAL",
      lengthMm: Math.round(hBarLengthM * 1000),
      lengthM: hBarLengthM,
      count: rowCount,
      totalLinearM: round2(hTotalLinearM),
      unitPricePerMeter: barRatePerMeter,
      subtotalCost: hCost,
    });
  } else if (patternType === "louvers") {
    // Style 2: Horizontal louvers / slats with vertical center mullion
    const numSlats = innerHeightMm > 0 ? Math.max(2, Math.floor(innerHeightMm / 45)) : 0; // 45mm slat pitch
    const numMullions = innerWidthMm > 1200 ? 2 : 1; // 1 center mullion up to 1200mm, 2 above

    const hSlatLengthM = innerWidthM;
    const hTotalLinearM = numSlats * hSlatLengthM;
    const hCost = round2(hTotalLinearM * barRatePerMeter * (1 + barScrap));

    hMetrics.push({
      id: "louver-slats",
      name: `Horizontal Grille Slats (${numSlats} slats)`,
      orientation: "HORIZONTAL",
      lengthMm: Math.round(hSlatLengthM * 1000),
      lengthM: hSlatLengthM,
      count: numSlats,
      totalLinearM: round2(hTotalLinearM),
      unitPricePerMeter: barRatePerMeter,
      subtotalCost: hCost,
    });

    const vMullionLengthM = innerHeightM;
    const vTotalLinearM = numMullions * vMullionLengthM;
    const vCost = round2(vTotalLinearM * barRatePerMeter * (1 + barScrap));

    vMetrics.push({
      id: "louver-mullions",
      name: `Center Vertical Mullions (${numMullions} pcs)`,
      orientation: "VERTICAL",
      lengthMm: Math.round(vMullionLengthM * 1000),
      lengthM: vMullionLengthM,
      count: numMullions,
      totalLinearM: round2(vTotalLinearM),
      unitPricePerMeter: barRatePerMeter,
      subtotalCost: vCost,
    });
  } else {
    // Style 3: Staggered brick / running bond (matches Lab_Grill_Middle_Bars.glb and buildDynamicGrillPatternGroup)
    const colCount = innerWidthMm > 0 ? Math.max(1, Math.floor(innerWidthMm / nominalPitchColMm)) : 0;
    const actualPitchM = colCount > 0 ? innerWidthM / (colCount + 1) : 0;
    const vBarLengthM = innerHeightM;
    const vTotalLinearM = colCount * vBarLengthM;
    const vCost = round2(vTotalLinearM * barRatePerMeter * (1 + barScrap));

    vMetrics.push({
      id: "brick-v-bars",
      name: `Vertical Grille Bars (${colCount} pickets)`,
      orientation: "VERTICAL",
      lengthMm: Math.round(vBarLengthM * 1000),
      lengthM: vBarLengthM,
      count: colCount,
      totalLinearM: round2(vTotalLinearM),
      unitPricePerMeter: barRatePerMeter,
      subtotalCost: vCost,
    });

    const totalCols = colCount + 1;
    const numLevels = Math.max(2, Math.round(innerHeightMm / nominalPitchRowMm));
    let horizontalBarCount = 0;

    for (let c = 0; c < totalCols; c++) {
      for (let lvl = 1; lvl < numLevels; lvl++) {
        if ((c + lvl) % 2 === 0) {
          horizontalBarCount++;
        }
      }
    }

    const hSpanLengthM = actualPitchM;
    const hTotalLinearM = horizontalBarCount * hSpanLengthM;
    const hCost = round2(hTotalLinearM * barRatePerMeter * (1 + barScrap));

    hMetrics.push({
      id: "brick-h-ties",
      name: `Staggered Horizontal Tie Bars (${horizontalBarCount} pcs)`,
      orientation: "HORIZONTAL",
      lengthMm: Math.round(hSpanLengthM * 1000),
      lengthM: hSpanLengthM,
      count: horizontalBarCount,
      totalLinearM: round2(hTotalLinearM),
      unitPricePerMeter: barRatePerMeter,
      subtotalCost: hCost,
    });
  }

  // 3. Summaries & Final Totals
  const vPieces = vMetrics.reduce((s, m) => s + m.count, 0);
  const vLinearM = vMetrics.reduce((s, m) => s + m.totalLinearM, 0);
  const vCostTotal = vMetrics.reduce((s, m) => s + m.subtotalCost, 0);

  const hPieces = hMetrics.reduce((s, m) => s + m.count, 0);
  const hLinearM = hMetrics.reduce((s, m) => s + m.totalLinearM, 0);
  const hCostTotal = hMetrics.reduce((s, m) => s + m.subtotalCost, 0);

  const totalPieces = (perimeterDetails ? 4 : 0) + vPieces + hPieces;
  const totalLinearMeters = round2(perimeterMetersTotal + vLinearM + hLinearM);

  // Raw material subtotal without scrap
  const netMaterialCost =
    perimeterMetersTotal * frameRatePerMeter + (vLinearM + hLinearM) * barRatePerMeter;
  const grossMaterialCost = perimeterCostTotal + vCostTotal + hCostTotal;
  const wasteAllowanceCost = round2(grossMaterialCost - netMaterialCost);
  const directMaterialCost = round2(grossMaterialCost);

  // Fabrication labor floor
  const computedLabor = Math.max(laborFloor, directMaterialCost * laborRate);
  const laborCost = round2(computedLabor);

  // Contractor gross margin
  const contractorMargin = round2((directMaterialCost + laborCost) * contractorMarginRate);
  const finalPrice = round2(directMaterialCost + laborCost + contractorMargin);

  // Formulate detailed itemized table
  const itemizedBreakdown: GrilleLinearBOMResult["itemizedBreakdown"] = [];

  if (perimeterDetails) {
    itemizedBreakdown.push({
      item: perimeterDetails.topRail.name,
      orientation: "PERIMETER",
      pieces: 1,
      lengthMm: perimeterDetails.topRail.lengthMm,
      totalMeters: perimeterDetails.topRail.totalLinearM,
      unitRate: frameRatePerMeter,
      subtotal: perimeterDetails.topRail.subtotalCost,
    });
    itemizedBreakdown.push({
      item: perimeterDetails.bottomRail.name,
      orientation: "PERIMETER",
      pieces: 1,
      lengthMm: perimeterDetails.bottomRail.lengthMm,
      totalMeters: perimeterDetails.bottomRail.totalLinearM,
      unitRate: frameRatePerMeter,
      subtotal: perimeterDetails.bottomRail.subtotalCost,
    });
    itemizedBreakdown.push({
      item: "Grille Frame Side Jambs (Left & Right)",
      orientation: "PERIMETER",
      pieces: 2,
      lengthMm: perimeterDetails.leftJamb.lengthMm,
      totalMeters: round2(perimeterDetails.leftJamb.totalLinearM * 2),
      unitRate: frameRatePerMeter,
      subtotal: round2(perimeterDetails.leftJamb.subtotalCost + perimeterDetails.rightJamb.subtotalCost),
    });
  }

  for (const vm of vMetrics) {
    itemizedBreakdown.push({
      item: vm.name,
      orientation: "VERTICAL",
      pieces: vm.count,
      lengthMm: vm.lengthMm,
      totalMeters: vm.totalLinearM,
      unitRate: vm.unitPricePerMeter,
      subtotal: vm.subtotalCost,
    });
  }

  for (const hm of hMetrics) {
    itemizedBreakdown.push({
      item: hm.name,
      orientation: "HORIZONTAL",
      pieces: hm.count,
      lengthMm: hm.lengthMm,
      totalMeters: hm.totalLinearM,
      unitRate: hm.unitPricePerMeter,
      subtotal: hm.subtotalCost,
    });
  }

  return {
    patternType,
    totalPieces,
    totalLinearMeters,
    directMaterialCost,
    wasteAllowanceCost,
    laborCost,
    contractorMargin,
    finalPrice,
    perimeterRails: perimeterDetails,
    verticalBars: {
      barCount: vPieces,
      cutLengthMm: vMetrics[0]?.lengthMm ?? 0,
      totalLinearM: round2(vLinearM),
      subtotalCost: round2(vCostTotal),
      details: vMetrics,
    },
    horizontalBars: {
      barCount: hPieces,
      cutLengthMm: hMetrics[0]?.lengthMm ?? 0,
      totalLinearM: round2(hLinearM),
      subtotalCost: round2(hCostTotal),
      details: hMetrics,
    },
    itemizedBreakdown,
  };
}
```
