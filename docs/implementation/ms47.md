## 1. Outcome and Scope

`IMP-MS47` completes the precision measurement loop designed in `IMP-MS45` (intake mode and paper standard selection) and `IMP-MS46` (FastAPI OpenCV contour detection and homography estimation). It bridges the server-detected paper scale into the Next.js Three.js workspace, provides a robust interactive 4-point pin fallback for low-contrast images, grounds initial 3D model dimensions with high precision (error under ±5%), and updates downstream quotation confirmation.

### 1.1 The Two Operational Paths

1. **Auto-Detected Success Path (Confidence $\ge 0.65$):**
   - The workspace loads with the high-confidence scale factor automatically applied.
   - An informative notification appears in the workspace HUD: *"Calibrated to [Short/A4/Long] Paper (Precision Scale: ±2-5%)"*.
   - A non-intrusive *"Adjust Paper Corners"* button is available in the toolbar if the customer wishes to fine-tune the auto-detected box.

2. **Interactive Fallback Path (Status `"manual_pin_required"`):**
   - When edge contrast is low (e.g., white bond paper taped to an off-white or cream painted wall), the system does not crash or abandon calibration.
   - Before opening the main editor, a focused modal (`FiducialPaperPickerModal`) opens displaying the room image.
   - The customer taps or drags 4 corner handles directly onto the 4 corners of their taped paper sheet.
   - The client calculates the coplanar scale factor directly using the known paper metrics, instantly elevating the session to calibrated precision status.

### 1.2 Dimension Grounding Impact

- **Manual Configuration Flow:** Initial overlay pixel bounds convert directly to real-world centimeters using the calibrated scale factor via `getScaleAwareInitialDimensions()` in `src/lib/visualization/scaleEstimation.ts`, replacing arbitrary 210x150cm starting values with spatially accurate opening measurements.
- **Perspective Plane Picker Flow:** When the user confirms the 4-point perspective quad around the opening, `computeEstimatedDimensions()` applies the coplanar scale factor directly without relying on relative depth ratios or default height heuristics.
- **Measurement Modal Parity:** The Measurement Confirmation Modal (`MeasurementConfirmationModal.tsx`) displays an emerald "Calibrated Visual Estimate" badge, building customer confidence and signaling to fabricator estimators that dimensions were physically referenced.

### 1.3 Non-Negotiable Invariants

1. **Preserve User Autonomy:** The customer always retains final authority. Calibrated dimensions are presented with clear visual cues, but manual tape measurement overrides in the measurement modal are never blocked.
2. **Component & Token Reuse:** The interactive pin tool must reuse established patterns from `PerspectivePlanePicker.tsx` and `ManualOcclusionPointPicker.tsx`, including touch proxies, magnifier loupes, corner clamping, and responsive SVG handles (`BAN-UI-09`).
3. **No Continuous Tracking:** All calculations are static, one-shot geometric evaluations (`BAN-AR-08`).
4. **Zero Type Pollution:** Strict TypeScript interfaces without `any` (`BAN-TYPE-05`).
5. **No Em-Dashes:** In compliance with `BAN-PUNCT-01`, all documentation, code comments, and copy must use hyphens, colons, or parentheses.

### 3.2 Client-Side Scale Computation from User Pins

Given 4 user-confirmed corner points $p_0, p_1, p_2, p_3$ in photo coordinates:

```typescript
export function computeScaleFromPaperCorners(
  corners: [Point2D, Point2D, Point2D, Point2D],
  paperStandard: FiducialPaperStandard,
): { scaleCmPerPx: number; confidence: number } {
  const metrics = PAPER_STANDARD_METRICS[paperStandard];
  const dist = (p1: Point2D, p2: Point2D) => Math.hypot(p2.x - p1.x, p2.y - p1.y);

  const topWidthPx = dist(corners[0], corners[1]);
  const bottomWidthPx = dist(corners[3], corners[2]);
  const leftHeightPx = dist(corners[0], corners[3]);
  const rightHeightPx = dist(corners[1], corners[2]);

  const avgWidthPx = Math.sqrt(topWidthPx * bottomWidthPx);
  const avgHeightPx = Math.sqrt(leftHeightPx * rightHeightPx);

  // Check orientation (upright vs landscape) based on pixel aspect ratio
  const isLandscape = avgWidthPx > avgHeightPx;
  const realWidthCm = isLandscape ? metrics.heightMm / 10 : metrics.widthMm / 10;
  const realHeightCm = isLandscape ? metrics.widthMm / 10 : metrics.heightMm / 10;

  const scaleW = realWidthCm / Math.max(avgWidthPx, 1);
  const scaleH = realHeightCm / Math.max(avgHeightPx, 1);

  const scaleCmPerPx = (scaleW + scaleH) / 2;

  return {
    scaleCmPerPx: Number(scaleCmPerPx.toFixed(6)),
    confidence: 0.95,
  };
}
```

## 4. Precision Dimension Grounding in the Workspace

### 4.1 Enhanced `computeEstimatedDimensions()`

In `src/lib/visualization/scaleEstimation.ts`, update the dimension computation algorithm:

```typescript
export function computeEstimatedDimensions(
  quadWidthPx: number,
  quadHeightPx: number,
  scaleSignal: ScaleEstimationSignal | null | undefined,
  isDoor: boolean,
  templateDefaultHeightCm: number | null | undefined,
  depthAtQuadCenter: number | null | undefined,
): DimensionEstimate {
  // Check if high-precision paper calibration is available
  const isPaperCalibrated =
    scaleSignal?.method?.startsWith("paper_fiducial") &&
    scaleSignal.best_scale_cm_per_px !== null &&
    scaleSignal.confidence >= 0.65;

  if (isPaperCalibrated) {
    const scale = scaleSignal.best_scale_cm_per_px!;
    // Ground directly on coplanar scale: zero depth correction needed!
    const exactWidthCm = Math.round(quadWidthPx * scale);
    const exactHeightCm = Math.round(quadHeightPx * scale);

    return {
      widthCm: Math.max(30, Math.min(600, exactWidthCm)),
      heightCm: Math.max(30, Math.min(400, exactHeightCm)),
      confidence: scaleSignal.confidence,
      method: scaleSignal.method,
    };
  }

}
```

## 8. Risks and Mitigations

| Risk | Severity | Mitigation |
|---|---|---|
| Customer places pins in wrong order (e.g. crossing lines) | Medium | Automatic corner sorting (`_order_corners`) runs before scale calculation, ensuring [TL, TR, BR, BL] canonical ordering regardless of pin placement sequence. |
| Customer clicks "Confirm" without moving pins from default center | Low | Modal checks if corners form a reasonable aspect ratio matching the selected paper standard; warns user if corners remain at initial default rectangle. |
| Customer skips paper calibration and chooses manual pin cancel | Low | Modal includes a "Skip to Quick Preview" button, falling back safely to standard room heuristics without blocking entry. |
